# 盲读：把盲角色当仪器，不当帮手

> 完整协议 = `references/protocols/盲读协议.md` 与 `references/protocols/A-B冷读协议.md`（书工程内还有一份 `editorial/protocols/`）。
> 四个盲角色的**派工提示词全文**在 `references/roles/`（文件名用 ASCII，角色名仍用中文）：
> `dsh-native/plugin-novelist/wb-expert-starter/references/roles/reader.md`（试读员）/ `dsh-native/plugin-novelist/wb-expert-starter/references/roles/calibrator.md`（结构校准员）/ `dsh-native/plugin-novelist/wb-expert-starter/references/roles/proofer.md`（校对员）/ `dsh-native/plugin-novelist/wb-expert-starter/references/roles/dissector.md`（拆书员）；
> 非盲的 `dsh-native/plugin-novelist/wb-expert-starter/references/roles/archivist.md`（档案员）也在同处。派工时把该文件「人格」段全文作为子代理提示词。

## 派工纪律（五条，违者交付无效）

1. **中性命名**——任务名只说"按档案提交读感记录"，禁带答案表述（如"检查逻辑跳跃/验证伏笔"）。
2. **输入隔离**——盲角色只收 读者档案 + 正文包（试读员另收前情事实卡；校准员只见正文）。**无大纲、无写作意图、无旧稿、无检测信息、无预期答案**；包内出现即原样退回并报"输入污染"。
3. **②b 只读派工包**——**盲角色只读派工包里的东西，不得调用任何工具去查账本/大纲/伏笔/事件带**。理由不是防它使坏，是防**测量失真**：盲角色一旦读到"作者想干什么/哪里埋了伏笔/后面要收什么"，就会对真读者看不懂的地方说"清楚"、对断裂说"这是伏笔"——**被污染的盲读不会报错，它会交回一份通顺、有理由、很客气但没有用的数据**。派工包给少了就报"输入不足"，不要自己去取。
4. **诚实降级**——开不出新实例只能标"自审降级"留痕，不得冒充盲读完成。
5. **Owner 反馈撤销制**——Owner 说"看不懂/不好看"= 立即撤销对应通过并回改，冷读漏检**不得**反驳 Owner。

## 投递分层

| 章型 | 包数 | 说明 |
|---|---|---|
| 常规章 | 两包（前半/后半） | 保首读时序：包 1 读完交记录，再开包 2 |
| 风险章（卷首/第 1 章/语义级回改稿/弧审抽查） | 四~六包 | 全协议：每包交记录，包间隔断 |

## 审法要点（试读员）

- **三问分级量表**按**自然叙事单元**逐段打分，**拒绝按字数切片**：看懂（一眼懂/要想一下/没弄懂）、流畅（顺着读/卡了一下/开始扫/想停）、好看（想接着看/还可以/不想看了）。
- **落脚检查**：每进新场景问"谁/在干什么/为什么在此"，并区分"正文直接告诉我的"vs"我顺手猜的"——两栏分开记。
- **首读负面不可抹**：第一次出现的"要想一下/开始扫/想停"永久留档，后文再顺也不洗白。
- **复述核查**：读完全部包用三五句话复述；复述里出现而正文没落地的"她的/为了/所以"=把猜的当懂了，原样标出交主编反查。
- 只交读感记录，**不给写作建议**、不改文、不猜大纲。

## 成对判与趋势线

绝对分只做守门。主判 = **成对判 `anchored_pair`**：与同题材真人锚书章对读，哪版更想追（-1/0/1）。核心产出是**相对判断**，供每批金丝雀冷读聚成**质量趋势线**——"质量在上升吗"是趋势线斜率问题，比"这章几分"可测得多。

**批末金丝雀**：每批随机抽 1 章走 A-B 盲读冷读（生产环路里唯一能报"平"的通道，**不得归零**）。

## 判据降权（不可越界）

量表 / 评分卡 / 锚书 z-score 一律是**守门工具**（一致性/通顺/结构完整）；任何"这章写得好/动人/会上头"的结论**不得引用它们为证据**——"好"的证据唯二：**Owner 裁决记录 + 语料库个体范本**。

## WorkBuddy 形态：软隔离声明（必须如实标注）

DSH 侧靠 `toolFilter.deny`（22 项逐名封死，含 `read`/`novel_*`）在**工具层**隔离；**WorkBuddy 封不住工具名**——子代理继承完整工具面。

所以本条在这里是**纪律条款而非机器约束**。派工与交付说明里必须标注：

> 本次盲读为**软隔离**（无工具层 deny），证据力低于 DSH 形态；读感记录按"软隔离样本"使用。

**闭环办法**（工具拦不住就用账本反证）：交付后主编跑一次 `novel_verify` 与事件带核对，确认盲角色没有写账、没有读账。
