## 1. 题材承诺 — 短篇爽文承诺了什么爽

### 核心承诺类型

**① 代偿性爽感**
- 现实中被压抑的情绪（委屈、不公、被轻视）在故事中得到宣泄
- 案例：《被婆家嫌弃生不出儿子，我转身月入十万》直击生育焦虑与经济独立渴望

**② 身份逆袭**
- 从被轻视到被仰望，从底层到巅峰
- 典型设定：真千金回归、隐藏身份曝光、隐世大佬身份揭露

**③ 智慧碾压**
- 不动声色的智商降维打击，比武力打脸更高级
- 案例：《十日终焉》主角用规则漏洞反杀，全程不动手完成绝杀

**④ 极致偏爱**
- 强者对全世界冷漠，唯独对主角无条件偏爱
- 案例：《千年家族曝光》全球顶级势力单膝跪地迎接家主

**⑤ 自我觉醒**
- 从"证明自己"到"活成自己"，挣脱世俗枷锁
- 最高格局的爽感，能引发强烈共鸣并长久出圈

### 执行技巧
- 选题必须锚定一种核心爽感，不可贪多
- 标题即承诺：如"我月薪3万的文案，被保洁阿姨改了3个字"
- 题材要贴合当下情绪痛点（婚姻焦虑、职场PUA、原生家庭）

## 2. 开头抓手 — 黄金300字/前3段的精确技巧

### 五种高效钩子类型

**① 反差型钩子**
```
公式：身份/地位的反常识冲突
案例："我月薪3万的文案，被保洁阿姨改了3个字，老板当场拍板。"
```
- 用身份反转制造认知冲突
- 前300字内必须出现身份/地位的颠覆性暗示

**② 痛点型钩子**
```
公式：直击读者最敏感的伤口
案例："写短篇三年，我发现死磕文笔的新手，都没抓准痛点的火过。"
```
- 让读者"边看边点头：对，就是这样！"
- 精准触发共鸣，情绪先行

**③ 情感型钩子**
```
公式：情感冲击+悬念留白
案例："她结婚那天，我才知道，当年她撑着红伞等我，根本不是为了躲雨。"
```
- 用情感冲击瞬间抓住读者
- 结尾留白引发好奇

**④ 场景前置型**
```
公式：最紧张/最具冲突的瞬间直接呈现
案例："产房外，丈夫正把离婚协议递给小三。"
```
- 知乎盐选标准格式，首段500字内必须呈现高冲突事件
- 导语前置核心悬念，3行内牵动情绪

**⑤ 身份标签型**
```
公式：职业/身份+异常设定+悬念
案例："夜班护士：我能看见每个人的剩余寿命，唯独自己的却在快速减少"
```
- 强化身份标签，简洁明了交代背景

### 黄金法则
- **3秒法则**：读者划走文章只需3秒，必须在3秒内抓住
- 用"我以为..."开头比平铺直叙完读率高40%
- 开篇禁用大段背景介绍，直接怼冲突

## 3. 读者债设计 — 短篇幅如何快速建债

### 建债核心机制

**① 情绪债务**
```
模式：先压后爽
前3K字建委屈感、憋屈感、不公平感
→ 读者产生"替主角不值"的情绪债务
→ 付费章节释放情绪，获得代偿性满足
```

**② 信息债务**
```
模式：给一半藏一半
案例：男主表面冷漠要离婚（显信息），读者好奇"为什么"
→ 隐藏真相（隐信息），读者必须付费才能解锁
→ 信息差=好奇心=付费动力
```

**③ 选择债务**
```
模式：主角面临关键抉择
"选A意味着XX，选B意味着XX"
→ 读者产生"我要是主角我会怎么选"的代入债务
→ 必须读下去才能知道主角的选择后果
```

**④ 关系债务**
```
模式：暧昧/紧张关系+悬念
"他们之间到底什么关系？"
"他/她会不会原谅对方？"
→ 情感投入形成绑定债务
```

### 建债速度对照
| 字数 | 建债深度 | 适合类型 |
|------|----------|----------|
| 800字 | 单点冲击 | 微小说/闪小说 |
| 2000字 | 单一冲突 | 短故事/知乎回答 |
| 1万字 | 完整弧光 | 知乎盐选/付费短篇 |

## 4. 推进引擎 — 短篇的驱动力设计

### 三大推进引擎

**① 冲突递进引擎**
```
节奏：压制→小反抗→更大压制→更大反抗
公式：每1500字完成一次"压制-反击"循环
案例：《重生后，哥哥亲手送我入炼狱》
- 交换领养家庭（初始压制）
- 男配多次从中搅局引爆矛盾（递进）
- 女主态度自然转变（收束）
```

**② 信息差引擎**
```
原理：读者知道≠角色知道
设计：双视角或多视角叙事
→ 制造"观众视角"的紧张感
→ 读者替角色着急=推进动力
```

**③ 目标追逐引擎**
```
公式：明确目标+多重障碍+倒计时压力
案例：《锁金宫》女主目标：黄金万两开启新生活
- 障碍：资助状元郎失败、开设绣坊受阻
- 悬念：新帝正四处寻妻
```

### 加速技巧
- 每500字设置一个"小钩子"（转折/意外/新信息）
- 每3000字设置一个情绪高潮点
- 章末必须留悬念，促追更

## 5. 情绪波形 — 短篇的压缩节奏

### 呼吸节奏法

**蓄力慢板（慢节奏·吸气）**
- 铺垫氛围、埋设悬念、积累情绪
- 用延宕手法细化环境、神态、心理
- 服务后续冲突与情绪

**爆发快板（快节奏·屏息）**
- 释放张力、推进剧情、制造冲击
- 短句为主，节奏急促
- 留住读者不划走

### 情绪波形模板

```
开篇低区（建债）：委屈/憋屈/不公平感
    ↓
第一个峰值（3000字处）：首次小反转/小爽点
    ↓
低谷（蓄力）：更大困境/危机升级
    ↓
第二个峰值（6000字处）：关键证据到手/身份曝光
    ↓
情绪爆发（8000-10000字）：高潮对决/真相揭示
    ↓
余韵收尾（500字）：情绪沉淀/留白回味
```

### 情绪压缩法则
- 短篇要在最短篇幅内让读者情绪坐过山车
- 愤怒、心疼、爽、感动交替出现
- 情绪越强烈，完读率越高
- 每3000字至少一个情绪高潮点

## 6. 奖励类型分布 — 短篇爽感的分层配比

### 三级爽感体系

**基础层：小爽点（占30%）**
- 配角被打脸
- 小胜利、小确幸
- 让读者"微微爽"

**进阶层：中爽点（占50%）**
- 身份逆转/身份揭露
- 反派认栽/道歉
- 重要目标达成
- 让读者"很爽"

**顶层：大爽点（占20%）**
- 核心仇敌彻底覆灭
- 真爱告白/圆满结局
- 自我价值实现
- 让读者"极度满足"

### 配比公式
```
小爽×3 + 中爽×2 + 大爽×1 = 完美爽感节奏
```

### 爽点间隔
- 小爽点：每1000-1500字出现一次
- 中爽点：每3000-4000字出现一次
- 大爽点：全文1-2次，必须在结尾前2000字

## 7. 节奏配比 — 800字/2000字/万字的不同节奏

### 800字级（微小说/闪小说）

```
结构：导语(100字)+冲突(300字)+反转(300字)+结尾(100字)
节奏：开篇即高潮，全程无喘息
特点：单一冲突、单一情绪、单一大爽点
```

### 2000字级（短故事/知乎回答）

```
结构：钩子(200字)+铺垫(500字)+冲突(800字)+反转(300字)+结尾(200字)
节奏：2-3个小波折，1个核心反转
特点：情绪精准、信息密度高、结尾有钩子
```

### 10000字级（知乎盐选标准）

```
结构：
- 导语(500字)：核心冲突前置
- 事件展开(2000字)：背景+主要矛盾
- 冲突升级(3000字)：情绪叠加+付费点前奏
- 高潮反转(3500字)：大爽点释放
- 结尾(1000字)：情绪收束+留白

节奏：5个以上小钩子，3个以上情绪峰值
特点：完整弧光、多层爽感、付费墙设计
```

## 8. 结构公式 — 短篇可复用叙事结构（5种以上）

### 公式一：逆袭型结构

```
核心：普通人+不公平待遇+逆袭反击
公式：起点低→受压→反击→碾压
案例：《被婆家嫌弃生不出儿子，我转身月入十万》
    起点低：被催生委屈
    不公平：婆家嫌弃+外遇
    反击：偷偷写小说
    碾压：收入碾压婆家
```

### 公式二：反转型结构

```
核心：你以为A，其实是B
公式：表面现象→误导读者→真相揭露
案例：《离婚当天，我才知道老公有多爱我》
    表面：老公冷漠要离婚
    误导：以为变心
    真相：患绝症想留赔偿金
关键：伏笔要埋好，反转要意外又合理
```

### 公式三：成长型结构

```
核心：困境→觉醒→改变→收获
公式：过去困境+觉醒时刻+改变过程+现在收获
适用：个人经历类、职场逆袭类
特点：真实感强，细节越多越好
```

### 公式四：揭秘型结构

```
核心：满足好奇心+提供"值了"感
公式：行业/群体秘密+具体揭秘内容
案例：《我在相亲平台工作3年，告诉你这5个套路》
关键：信息要具体，要让读者觉得"学到了"
```

### 公式五：对比型结构

```
核心：强烈反差+解释原因+启示
公式：A和B的强烈反差+原因解读+读者共鸣
案例：《同样是写小说，为什么她月入过万，你却连签约都过不了？》
```

### 公式六：信息差结构

```
核心：你知道≠他知道
公式：建立双视角→制造期待差→揭露真相
适用：双重生、身份揭秘、幕后真相类
```

### 公式七：三阶升级结构

```
核心：三次尝试，三次失败，最终成功
公式：尝试1（虚惊）→尝试2（更大危机）→尝试3（真相边缘）→成功
适用：悬疑推理、职业逆袭类
```

## 9. 反转机制 — 短篇反转的时机与技巧

### 反转时机设计

**付费点反转（最强）**
```
位置：付费墙后30-50字
效果：读者刚付费就遭遇反转，满意度爆炸
```

**中段反转（稳扎稳打）**
```
位置：全文1/3处
效果：调整叙事方向，制造"意外"
```

**结尾反转（最大冲击）**
```
位置：全文最后500字
效果：颠覆认知，余韵最强
```

### 反转类型

**① 身份反转**
```
表面身份 vs 真实身份
案例：以为他是穷小子，结果是隐藏大佬
```

**② 动机反转**
```
表面动机 vs 真实动机
案例：以为他离婚是变心，实际是为留赔偿金
```

**③ 关系反转**
```
表面关系 vs 真实关系
案例：以为是情敌，实际是亲人
```

**④ 立场反转**
```
读者站队A，揭示B才是正义方
```

**⑤ 因果反转**
```
以为是A导致B，实际B导致A
```

### 反转执行技巧
- 伏笔至少提前2000字埋设
- 反转要有"啊，原来如此"感
- 反转后要给读者情绪缓冲
- 避免为反转而反转

## 10. 结尾设计 — 余韵/爆点/留白三种结尾模式

### 模式一：余韵结尾

```
特点：情绪沉淀、回味悠长
技巧：开放式结局、象征性意象
案例：主角看着空位，面无表情地把冷掉的汤倒进垃圾桶
→ 潜台词：她走了，他还没习惯，他快碎了
```

### 模式二：爆点结尾

```
特点：高潮收尾，情绪最释放
技巧：核心冲突彻底解决、大团圆或大悲剧
案例：《离婚时我才知道丈夫的真实身份》
→ 真相揭露后男主散尽家财守遗物度日，极致虐心
```

### 模式三：留白结尾

```
特点：不说透、引发想象
技巧：关键对话/动作打断、暗示未来
案例："如果你身处泥沼，请记住斩掉荆棘做你的浮木"
→ 戛然而止，读者自己品味
```

### 结尾禁忌
- 不能"就这样结束了"感
- 不能突然泄气
- 不能开启新冲突（新冲突留给续作）
- 必须给情绪一个落点

### 引导互动结尾
```
公式：抛问题+引导评论
"如果是你，你会怎么选择？"
"欢迎在评论区分享你的故事"
```

## 11. 信息预算 — 短篇的信息密度控制

### 密度原则

**开篇（前10%）：高密度**
```
必给信息：核心冲突、主角处境、情绪基调
禁给信息：完整背景、人物履历、历史渊源
```

**中段（60%）：递进释放**
```
每500字释放一个关键信息
信息之间必须有逻辑关联
禁止突然引入与前文无关的新设定
```

**高潮（20%）：信息爆发**
```
回收80%以上伏笔
揭示核心真相
信息量最大、节奏最快
```

**结尾（10%）：信息收束**
```
少量新信息
聚焦情绪和主题
留白空间
```

### 信息取舍标准
- 每一个信息必须服务于：冲突推进/人物塑造/情绪调动
- 无关信息一律删除
- 背景信息通过行动/对话带出，不做单独介绍

### 密度对比
| 类型 | 信息密度 | 节奏 |
|------|----------|------|
| 长篇 | 低-中 | 可缓可急 |
| 短篇 | 中-高 | 必须紧凑 |
| 微小说 | 极高 | 瞬间冲击 |

## 12. 付费墙设计 — 知乎盐选的卡点技巧

### 知乎盐选硬性标准
- 最低字数：10000字整稿
- 免费部分：2000-5000字区间
- 首段500字内必须呈现高冲突事件
- 付费章节起始句必须触发第一次情节反转

### 五大截断模型

**① 主角抉择型**
```
卡点：选A还是选B
效果：读者在等一个结果
案例：救不救仇人？要钱还是要人？
```

**② 真相揭示型**
```
卡点：答案就在嘴边，却突然停下
效果：心理只有一个字——急
案例：身份马上曝光，真凶呼之欲出
```

**③ 情绪中断型**
```
卡点：极致委屈/热血/悲伤时戛然而止
效果：情绪没有出口，必须付费找出口
```

**④ 情节反转型**
```
卡点：反转发生的瞬间
效果：反转是悬念的放大器
```

**⑤ 行为/对话打断型**
```
卡点：关键质问没等到回答/冲突即将爆发
效果：读者被迫想知道"接下来呢"
```

### 付费点布局
```
第1-3章：免费钩子，让读者点进来
第4-20章：免费铺垫，让读者想看下一章
第20-30章：第一个大付费节点
后续：每10-15章安排"小高潮"
```

### 收益公式
```
盐选收益 = 会员完读率 × 分成比例
关键：1000个读到最后的人 > 10000个只看前三段的人
```

## 13. 近年新趋势 — 2024-2026短篇爽文新手法

### 趋势一：智慧碾压取代武力打脸

**旧套路（已过时）**
```
主角受气→憋大招爆发→反派下跪认错
→ 平台重点打压，写多少毙多少
```

**新趋势**
```
绝境规则困局+冷静细节拆解+利用漏洞反杀
案例：《十日终焉》主角靠规则漏洞完成绝杀
```

## 14. 长篇vs短篇差异 — 结构/节奏/爽感设计的核心区别

### 结构差异

| 维度 | 长篇网文 | 短篇爽文 |
|------|----------|----------|
| 字数 | 10万字+ | 8000-15000字 |
| 主线 | 多条线索交织 | 单一核心冲突 |
| 副线 | 可独立成篇 | 全部服务主线 |
| 世界观 | 需完整构建 | 随用随给 |
| 人物 | 众多需成长弧光 | 聚焦核心角色 |
| 章节 | 多章连载 | 完整单篇 |

### 节奏差异

**长篇节奏**
```
慢热期（前5-10万字）：世界观建立、人物出场、伏笔铺设
高潮期（每30-50章）：大高潮
持续期：高潮→小低谷→新高潮循环
特点：可缓可急，有充足铺垫空间
```

**短篇节奏**
```
快热（300字内）：核心冲突必须前置
持续高压：全程高浓度情绪
急速收束：1-2个大高潮完成闭环
特点：每300-500字必须有冲突或转折
```

### 爽感设计差异

**长篇爽感**
```
爽感类型：多层次、长期积累
爽感节奏：章节级高潮（每10-20章）
爽感密度：稀疏但强烈
代表爽感：逆天改命、登顶世界
```

**短篇爽感**
```
爽感类型：集中爆发、高浓度
爽感节奏：段落级小爽（每500-1500字）
爽感密度：密集且递进
代表爽感：瞬间逆袭、身份曝光、极致打脸
```

### 核心能力差异

**长篇需要**
```
- 世界观构建能力
- 长期人物弧光设计
- 多线叙事管理
- 持续创作体力
```

**短篇需要**
```
- 核心冲突提炼能力
- 高密度情绪设计
- 精准信息取舍
- 一次性完整闭环
```

### 创作心法差异

**长篇心法**
```
"慢即是快，铺垫决定高潮强度"
"人物成长需要时间"
"让读者追更100章还保持期待"
```

**短篇心法**
```
"快准狠，一击必中"
"在最短篇幅内完成情绪闭环"
"让读者3秒入坑、3分钟爽到"
```

## 15. 三分钟留存链 — 爆款短篇六法则

> 读者点开短篇只给三分钟。本节六条是留存链的六个环——链条不断，读者不走；读完还会把链接发给下一个人。各环只收本文件其他节没有的净新增机制，已有工艺以交叉引用衔接。

### 15.1 牵挂开场（§2黄金300字的目标校准）

开篇的目标不是"信息"是"牵挂"：让读者对一个人产生**"他怎么了/他会不会有事"**的关心——注意不是"他好厉害"。仰视不会让读者把自己放进去，牵挂才会。
- **反常制造关心，信息不会**：让一个人在开篇做一件"不太对劲"的事（藏一个东西/说一句不该说的话/正常场合一个不正常反应）。读者不需要知道他是谁，感觉到"这个人有事"就已经开始关心了。
- 与 55字测试的叠加检验：第一句触发的2个读者问题里，**至少1个必须是关于"人"的牵挂**（他怎么了），不能2个都是关于"事"的好奇（发生了什么）。

### 15.2 删除检验与密度铁律（§11信息预算的操作面）

- **删除检验**：一个段落/句子/词，删掉之后读者读下一段完全不受影响 = "不看也行" = 删。短篇的节奏不一定快，但一定**密**——每段给出新信息、新情绪或新进展，三者必居其一。
- **事件不重要，反应才重要**：不是让主角从A走到B，是让他在路上遇到一个必须做出反应的意外。
- **对话是改变距离，不是交换信息**：每次开口都在改变两人之间的距离（与 `craft/reference/narrative-ecology.md` 第7条分工：那条管"这句话像不像他说的"，本条管"这句话推没推动关系"）。
- **每页情绪必变检验**：一整页没有让读者情绪发生任何变化（紧张/好奇/心疼/期待都算）= 重写这一页。短篇不能让读者在任何一页休息，休息=离开。
- **闲笔尺度边界（与 narrative-ecology 第1条的兼容）**：闲笔原则"每章留几处"是**长篇章节工艺**。微小说（800-2200字）闲笔预算 0-1 处且 ≤15 字，由怪异预算兼任，且必须同时产生情绪功能（违和感/好奇）——短篇里连闲笔都要过删除检验的情绪分支；盐选短篇 ≤2-3 处。

### 15.3 双故事转折构造法（§9"原来如此"的机制层）

§9已确立目标：反转要有"啊，原来如此"感。本条给构造方法——
**双故事原理**：读者以为自己读的是故事A，结尾发现其实是故事B；回头再看，作者从来没骗过他，**是他自己选择了相信故事A**。
- 构造三步：① 同一组细节写成"既能被A解释、又都指向B"；② A的解释必须是读者的**默认脑补**，作者绝不明说（作者明说了A再翻B=欺骗，读者反应是"什么鬼"不是"好厉害"）；③ 回读检验：逐个关键细节问——它指向B吗？它被A自然掩护了吗？两问全"是"才合格。
- 铺垫不足的"突然变了"制造的是懵，不是震撼。**"我居然没发现"的震惊才是分享的心理引擎**——读者觉得这个发现值得让别人也体验一次。

### 15.4 余震三器（§10留白结尾的具体弹药）

结尾不需要圆满，需要**"还在振动"**——事情解决了，情绪还在晃。三件武器任选其一收尾：
① 一句没说完的话；② 一个没解释的动作；③ 一个不知道该怎么解读的表情。
读者不会转发一个"完整的故事"，他转发的是"让他心里有事放不下"的故事——那个没说完的东西就是放不下的原因。

### 15.5 一细节记角色

短篇没有篇幅展开人物，读者能记住角色的唯一方式是**1-2个精确到放不下的画面细节**：不是"她很温柔"（标签，读完即忘），是"她接电话时会无意识用手挡住听筒，好像怕吵到旁边的人"（画面，被转发）。
- 执行：调用 `craft/reference/character-aura-engine.md` 第六节记忆钉（四类选1-2）+ 第九节9.6短篇速造流程；本条的增量是硬标准——**微小说全篇人物预算 = 1个底层逻辑 + 1-2个画面细节，没有第三样**。

### 15.6 终句击中工艺（§10三种结尾的最后一句）

合格标准：读者读完最后一句，**停顿超过3秒**——不是急着翻下一篇，是停在那里让那句话再转一圈。停顿是比点赞更高的评价；被击中的感觉，人本能地想让别人也体验，停顿即分享。
终句三来源（按§10结尾模式适配）：
① **后背发凉的精准观察**（适配留白结尾）；② **像早就埋伏好的台词**——前文出现过的一句话在终句换义重响（适配余韵结尾，与15.3双故事联动）；③ **让全篇升一级的话**——把个体故事顶到普遍处境（适配爆点结尾之后的收束）。
与 `zhihu-salt-story.md`〔仓外〕〔仓外〕 "最后一句制造'为什么'"并用不冲突：制造"为什么"是钩，本条三来源是击中——盐选投稿两者取一即可，微小说优先击中。

## 16. 欧·亨利工序 — 预期锚定与精准打碎

> §15.3 已建立双故事的**结构原理**（同组细节既能被A解释又指向B）。本节建立**工序**：如何一步步把读者的预期锚定在A，再在最后一刻把它打碎。两节是不同切面，配合使用。

### 16.1 核心命题："意料之外，情理之中"

反转的力量不来自"惊不惊"，来自"惊了之后的心服口服"。读者被转懵的第一反应是"什么鬼"，被转服的第一反应是"原来如此"——后者才是分享的引擎。
- **伏笔不是彩蛋，是炸弹的引线**：结尾的力量来自第一页起每个字的积蓄，回读时每个"不起眼的细节"都指向终点。检验标准：读者读完能说出"原来第X行那句话就是在说这件事"，则引线合格。
- **反转 = 揭开真相，不是改变现实**：事情的真相一直如此，只是读者一直被蒙在鼓里。《最后一片叶子》那片叶子从头到尾是画的，结尾只是让读者知道了真相。改变的是读者的认知，不是故事里的现实。

### 16.2 四步工序（单篇闭环）

**工序一：开篇建立"日常目标"（30秒内完成）**
读者必须在开篇立刻知道"这个人在干嘛、想要什么"——不解释设定，直接给出人物正在追求的具体目标。目标必须清晰到读者能用一句话复述。模糊的目标无法被后续打碎，因为读者对它的预期本就不牢固。

**工序二：失败序列锚定预期**
用一系列"失败/阻碍/误会"把读者的判断锚定在一个方向：他今天得不到他想要的，或者他一定会得到他想要的。关键：**锚定越牢，打碎越响**。不要急着给反转，先把读者的预期养肥。
- 与§5情绪波形联动：失败序列=压阶段；预期被养肥=读者债到顶。

**工序三：在"似乎已经结束"处给最后一击**
时机选在读者以为故事即将圆满收尾、情绪刚刚松弛的瞬间——然后给出那个新信息。这个信息必须满足两个条件：① 它从一开始就藏在故事里（回读能找到）；② 它彻底推翻了工序二建立的全部预期。
- 与§15.3双故事构造法联动：工序三给出的"新信息"就是B故事的揭幕时刻；而B的细节在工序一、二里已经按双故事原理埋好。

**工序四：反转必须是"人物自己的选择"造成的**
结尾的逆转不是天降意外，是因为人物的某个选择/性格/行为在最后一刻产生了连锁反应。没有人性根基的反转是炫技，读者不会共鸣。
- 与character-aura-engine.md第九节9.1底层行为逻辑联动：反转=人物底层逻辑在极端处境下的必然推演，而非作者强加。读者事后感到"他就是这样的人，他当然会这么做"，才是人性根基立住了。

### 16.3 只学皮毛的五个死法

1. **为反转而反转**：结尾硬逆转，前文无引线，读者反应是"什么鬼"而非"原来如此"——跳过工序一、二直接切工序三。
2. **预期没养肥就打碎**：失败序列太短，读者预期还没形成牢固判断，反转就来了——打碎的只是空气。
3. **反转改变了现实**：事情真的突然变了，而不是揭开了一直存在的真相——违反16.1第二条。
4. **反转无人性根基**：逆转来自巧合或外力，不是人物自己的选择造成的——工序四缺位。
5. **结尾把话说完了**：反转揭晓后继续解释、交代、总结——消耗了余震。应在"揭开真相"的瞬间或一句话之内收刀，余震留给读者自己去震。

### 16.4 微小说适配（800-2200字约束下的工序压缩）

四步工序在微小说里必须极度压缩：工序一不超过2句；工序二最多2次失败（字数预算不够养更多）；工序三=全文最后1-3句；工序四必须在工序一里已经埋好性格根基，不可临时补充。
- 压缩优先级：工序一（30字内）> 工序四（性格根基必须在工序一里）> 工序三（最后一击）> 工序二（能省则省，但至少1次失败）。
- 终句即工序三：微小说的"最后一击"和§15.6终句击中工艺同时发生，两套标准同时过——既是打碎预期的时刻，又必须让读者停顿3秒。

### 书名三任务（全赛道通用，0.3秒完成三件事）

好书名必须在读者看到它的0.3秒内同时完成：
1. **交代题材**：让读者立刻知道这是什么类型的故事
2. **制造悬念**：用反常/冲突/意外触发"这怎么可能"的第一反应
3. **给出承诺**：隐约告知"这本书会有什么体验"

**判断标准**：读者看完书名，能否在脑子里自动产生"什么？这怎么可能？"的反应？能→合格；不能→改。

**禁忌**：
- 文艺意象类（"云与梦""彼岸花开"）：读者不知道题材/爽点在哪，等于无效书名
- 无冲突描述类：信息有但无张力
- 夸张虚假词：掉信任

**自查**：用"身份+核心冲突+爽点/悬念"公式套一遍，字数12-20字为宜。盐选赛道详见 `zhihu-salt-story.md`〔仓外〕〔仓外〕 第十八节标题公式。


### 标题公式
```
职业/身份 + 异常设定 + 悬念
例："殡葬化妆师：昨晚给前女友化妆时，她突然睁开了眼睛"
```

### 开头公式
```
3秒法则 + 强冲突/悬念/痛点 + 情绪先行
```

### 付费点公式
```
主角抉择/真相揭露/情绪巅峰 + 戛然而止
```

### 结尾公式

```
余韵：意象收束 / 爆点：大高潮释放 / 留白：开放式暗示
```
