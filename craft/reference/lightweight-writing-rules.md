## 1. 触发条件（默认进入）

满足以下任一即默认进入轻量模式：

- 长篇连载分章写作阶段（已输出过章节、进入稳定产出节奏）
- 项目目录已存在自己的风格锚点文件：风格 DNA / 人味约束 / 写作规则 / 追踪文件（novel-tracker.md / novel-chapter-breakdown-v*.md 等）

**例外（不走轻量，走完整工坊流程）：** 微小说 / 盐选短篇 / 单篇定制。这些体量小、一次性交付，重型装备值得全开。

## 2. 核心四条

### 2.1 关重型装备（一律不主动触发）

以下能力在轻量模式下**默认休眠**，不主动加载、不主动调用：

- 24 流派执笔系统（不加载流派风格记忆库做句式/用词覆写）
- 作者手搓句式库（不套用流派 few-shot 句式）
- 特色语言强制配额（不强制统计毒舌/神回复/废话文学句数）
- 弹药库懒加载（special-arsenals 不按需挂载）
- 插画生成 / 封面设计 / 种草提醒（长篇章节也不自动出图，除非用户明确要求）

> 目的：降低每章 token 消耗与幻觉面，靠项目已有的风格锚点维持一致性，而不是每章重新"武装"。

### 2.2 保四大系统（任何模式都不能关）

轻量模式只关"装备"，不关"底线"。以下四系统每章照常运行：

1. **记忆系统**：写前对齐（读风格 DNA + 追踪文件 + 前章衔接）+ 写后回填（更新角色状态/伏笔/设定）
2. **压 AI 系统**：破折号 = 0（禁用解释性破折号插入）+ AI 词黑名单（不禁/仿佛/宛如/顿时/瞬间/此刻…）+ 量化自检（章末扫 AI 痕迹）
3. **爽点钩子系统**：开头 500 字解钩（前 500 字必须出现冲突/异常/悬念）+ 章末必挂新钩（悬念/反转/情感/信息四选一）
4. **逻辑系统**：时间线硬校验 + 空间一致性 + 信息泄露检查（角色不能突然知道不该知道的）+ 数值/战力硬校验

### 2.3 项目规则一票否决

项目自身的风格锚点文件、追踪文件、章节拆解表，**优先级高于技能默认配置**。

- 项目写了"主角话少" → 即便某流派默认话多，也以项目为准
- 拆解表锁定了本章钩子 → 不擅自改成别的钩子
- 追踪文件记了"角色已死" → 不得在本章让它复活

### 2.4 被动叙事姿态

适用于都市异能 / 凡人流等"主角不主动"的赛道：

- 主角不主动找事，信息被动砸到面前
- 拿到信息"想不明白先放着"，不强行解释
- 危机靠环境/他人推过来，不是主角出门觅战

> 热血升级流、系统流按项目拆解表的人设执行，不强套被动姿态。

## 3. 轻量模式下的"不完美注入"与"人性化"

- 不完美注入（imperfection-injection-rules.md）仍执行：每 2000 字 8–15 处，但用**项目自己的语感**写，不套用流派手搓句式
- 人性化强制检测（7.14）仍执行：≥8 分才交付
- 点对点替换润色（阶段九）仍执行：发现 AI 痕迹改一处，不动全身

## 4. 退出轻量模式的情形

- 用户明确要求"用 XX 流派执笔" → 临时加载该流派记忆库，本章走完整执笔
- 用户要求出插画/封面 → 临时唤醒视觉联动
- 进入新阶段（卷末回顾、终稿修订）→ 走阶段九/十完整流程
