## 一、创作前配额分配预规划（必须在动笔前完成）

> 动笔前，在内部完成以下规划，不向用户输出：

### 1.1 角色特色语言适配表

根据本篇/本章出场角色的气质身份证，为每个角色分配最适合的特色语言类型：

| 角色气质类型 | 最适配语言类型 | 说明 |
|------------|--------------|------|
| 冷情/克制/算计型 | **毒舌** | 短句、一针见血、不废话 |
| 幽默/世故/见过世面型 | **神回复** | 反应出人意料但极度准确 |
| 佛系/躺平/丧文化型 | **废话文学** | 绕圈子说直白的事，荒诞美感 |
| 毒舌吐槽型（明面） | **毒舌** | 直接攻击 |
| 外表正经/内心崩溃型 | **废话文学** + **神回复** 混搭 | 表面正常说话，实则荒诞 |
| 反派（自我认知型） | **毒舌** | 反派的毒舌是"他认为自己在陈述事实" |
| 旁白/叙事者视角 | 三类均可 | 旁白的特色语言制造叙事距离感和喜剧/悲剧张力 |

### 1.2 场景节点预规划

> 识别本篇/本章中适合植入的场景节点，提前锁定位置：

**A类场景（最适合植入，每次必须利用）**：
- 角色A刚说了一句话，角色B需要回应 → **神回复**或**毒舌**
- 叙事者总结某个角色/情况 → **毒舌**（旁白视角）
- 角色面对荒诞处境发出感叹 → **废话文学**
- 两个角色意见对立时的一句交锋 → **毒舌**

**B类场景（可以植入，择机利用）**：
- 角色独自思考某个问题 → **废话文学**（内心旁白）
- 叙事者用一句话描述某个角色的本质 → **毒舌**
- 高压场景后的一句降压喘息 → **神回复**或**废话文学**
- 角色对某件"本来很正经的事"的反应 → **废话文学**

**C类场景（不适合植入）**：
- 正在处理死亡/重大失去的情绪高峰
- 打斗/追逐的动作密集段落（节奏不允许）
- 重大秘密揭露的核心瞬间（需要保持分量）

### 1.3 配额预分配示例（长篇章节，目标7句）

```
预规划（内部，不输出）：
开场段（~500字）：毒舌×1（旁白描述某角色）
第一个对话场景：神回复×1 + 毒舌×1
中段过渡叙事：废话文学×1（角色内心）
第二个对话场景：毒舌×1 + 神回复×1
高潮段对话：毒舌×1
结尾悬念段：废话文学×1
合计：毒舌4 + 神回复2 + 废话文学2 = 8句 ✅
```

## 二、场景植入判断器（写到某个节点时实时执行）

> 当正在写某个对话/叙事节点时，用以下流程判断如何植入：

### Step 1：识别植入类型

```
当前场景性质是什么？
→ 有人说了句话，另一个人需要接 → 走「对话植入路径」（2.1节）
→ 叙事者在描述某人或某情况 → 走「旁白植入路径」（2.2节）
→ 角色内心独白 → 走「内心独白植入路径」（2.3节）
```

### 2.1 对话植入路径

**执行步骤**：
1. 看上一句话（A说了什么）
2. 判断这句话有没有「可以被毒舌/神回复/废话攻击」的空间：
   - A说了一句"正确废话"→ B的神回复应该打破这个正确
   - A说了一句"暴露了自己的弱点/逻辑漏洞"→ B的毒舌应该精准刺入
   - A说了一句"严肃的话"→ B可以用废话文学制造荒诞落差
3. 选择类型后，执行对应的「生成流程」（第四节）

**对话植入示例**：

> A说："我只是想知道，你到底还爱不爱我。"
>
> ❌ 普通回应："我不知道。"（平淡，无张力）
>
> ✅ 毒舌回应："你问这个问题的方式，已经告诉了你答案。"（精准刺入，≤21字）
>
> ✅ 神回复："我昨天还爱，今天你问了这句话，我在想。"（出人意料，但极度准确地描述了现实）
>
> ✅ 废话文学："爱不爱这种事，其实问出来就已经不重要了，重要的是你问了。"（绕圈子，但说出了真相）

---

> A说："你怎么能这么冷静？"
>
> ✅ 毒舌："因为慌张解决不了你，解决不了事，也解决不了我自己。"
>
> ✅ 神回复："我慌的时候比你厉害，只是慌完了。"（时态反转，暗藏真实）
>
> ✅ 废话文学："冷静这个东西，本质上是没有多余的力气去不冷静了。"

---

> A说："你这人真的没救了。"
>
> ✅ 毒舌（反派视角）："我知道。但你来救我这件事，本身就说明你也没救了。"
>
> ✅ 神回复："被谁救这件事，选对人比选对方法更重要。"
>
> ✅ 废话文学："没救其实也挺好的，至少不用等救援了，省时间。"

### 2.2 旁白植入路径

**执行步骤**：
1. 确认正在描述的对象（某个角色的本质/某种处境/某段关系）
2. 提取这个对象最核心的荒诞/矛盾/讽刺之处
3. 用一句话把这个荒诞点精准说出来

**旁白植入示例**：

> 描述一个虚伪的职场上司：
> ❌ 普通叙事："他总是表现出一副关心下属的样子。"
> ✅ 毒舌旁白："他关心下属的方式，是在会议室当着所有人的面问你'最近还好吗'。"

> 描述一段名存实亡的婚姻：
> ❌ 普通叙事："他们之间已经没有什么话可说了。"
> ✅ 废话文学旁白："他们每天说很多话，只是这些话加起来，都不如沉默说的多。"

> 描述一个自以为聪明的反派：
> ❌ 普通叙事："他觉得一切都在自己掌控之中。"
> ✅ 毒舌旁白："他掌控全局的感觉，和一个人在迷宫里自信地走着、忘了自己不知道出口的感觉，大概差不多。"

### 2.3 内心独白植入路径

**执行步骤**：
1. 角色正在经历什么处境/情绪
2. 找到这个处境里最荒诞/最讽刺/最真实的那个层面
3. 让角色用废话文学或神回复的语气"自我总结"

**内心独白植入示例**：

> 角色刚刚被上司当众羞辱后：
> ❌ 普通独白："我感到很屈辱，但我忍住了。"
> ✅ 废话文学独白："忍这个字，其实就是把火压着，等一个更好的场合烧。"

> 角色意识到自己爱上了不该爱的人：
> ❌ 普通独白："我知道这是不对的，但我控制不了。"
> ✅ 神回复独白："喜欢一个人的问题不在于喜欢，在于喜欢了还要想为什么喜欢。"

> 角色面对敌人却意外发现对方有一点可怜：
> ✅ 毒舌独白："可怜和可恨这两件事，从来不是非此即彼的，这才是最烦的地方。"

## 三、配额核查与补写流程

> 创作完成后，执行以下核查，未达标必须补写才能输出正文：

### 3.1 核查步骤

```
1. 扫描全文，标记所有特色语言句子
2. 分类统计：毒舌[N]句 / 神回复[N]句 / 废话文学[N]句 / 合计[N]句
3. 对照配额要求：
   - 微小说：5-8句 → 合计[N]句 ✅/❌
   - 短篇：13-15句 → 合计[N]句 ✅/❌
   - 长篇章节：7-12句 → 合计[N]句 ✅/❌
4. 检查分布：有无超过1000字（长篇）/500字（短篇）的段落完全没有特色语言？
5. 未达标 → 执行3.2节补写流程
```

### 3.2 补写流程

1. **定位补写位置**：找到最合适的A类或B类场景节点（见1.2节）
2. **判断缺少哪种类型**：优先补充最少的那种，保持三类均有呈现
3. **执行生成流程**（第四节）生成新句子
4. **植入位置**：补写句必须自然融入对话/叙事，不能是硬插入
5. **重新核查**：补写后重新执行3.1节

## 四、三类特色语言原创生成流程

> 每次需要生成特色语言时，必须参照语料库精神原创生成，禁止直接抄录：

### 4.1 毒舌原创生成流程

**参照语料**：`craft/corpus/毒舌知识库.md` + `craft/corpus/毒舌AI示例库.md`（学习神韵，禁止直抄）

**生成步骤**：
1. 确认攻击对象：攻击的是什么（行为/逻辑/状态/自我认知）？
2. 找到最刺眼的那个点：这件事最荒诞/最虚伪/最可笑的本质是什么？
3. 用≤21字精准说出：不铺垫，不解释，直接戳穿
4. 检查：读完是否有"刀刀到肉"的感觉？是否带着隐含的幽默？

**毒舌生成模式速查**：
- 模式A「反问刺入」："你[行为]，但你知道这说明了什么吗？"→ 省略答案，让对方自己意识到
- 模式B「归因翻转」："[结果]，不是因为[表面原因]，是因为[更深的真相]。"
- 模式C「平行比较」："[A的行为]和[某个荒诞的事]，区别只在于[一点细节]。"
- 模式D「陈述即攻击」：用极平静的口吻直接说出对方不想承认的真相

### 4.2 神回复原创生成流程

**参照语料**：`craft/corpus/110个神回复示例.md` + `craft/corpus/315条神回复.md`（内化逻辑，禁止直抄）

**生成步骤**：
1. 确认上一句话（要回应的内容）
2. 找到这句话里的隐含假设/情感压力/逻辑预期
3. 用一句话打破这个预期——答案必须出人意料，但回头想想又极度准确
4. 检查：读完有没有"就该这么说"+"没想到"的双重感？

**神回复生成模式速查**：
- 模式A「时态错位」：用过去或未来时态回应现在时的问题（"我昨天还X，今天在想。"）
- 模式B「视角跳跃」：回应的不是对方问的事，而是问这件事这个行为本身
- 模式C「归纳降级」：把对方认为重大的事，用更底层的逻辑归纳成一件小事
- 模式D「承认+转向」：先承认对方说的，然后把重量转移到另一个更核心的点

### 4.3 废话文学原创生成流程

**参照语料**：`craft/corpus/话废菩萨语料.md`（学习绕圈子的节奏，禁止直抄）

**生成步骤**：
1. 确认要表达的核心真相（一句直白的话）
2. 用绕圈子的方式把这句话说出来，但绕完还是能听明白
3. 加入荒诞感：用看似无意义的逻辑链把一个简单事实说得像个哲学命题
4. 检查：读完有没有"说了等于没说，但好像又说了什么"的感觉？

**废话文学生成模式速查**：
- 模式A「循环定义」："A这个东西，其实就是当你没有A的时候才能感觉到A的存在。"
- 模式B「因果绕回」："[结果]的原因，是因为[原因]，而[原因]本身就是[结果]的另一种说法。"
- 模式C「正确废话升华」：说一句所有人都知道是真的话，但说出来的方式让它变成了一种洞见
- 模式D「行动/感受错位」："想[X]这件事，最好的办法是先做完[完全不相关的Y]，然后就不想[X]了。"

## 五、特色语言与角色气质的匹配禁忌

> 特色语言必须符合角色气质，以下组合会让角色崩气质：

| 角色类型 | 绝对不能用的语言类型 | 原因 |
|---------|-------------------|------|
| 冷情谋士（话少型） | 超过30字的废话文学 | 与"话少/精炼"气质直接冲突 |
| 严肃武将/正义感强型 | 刻薄毒舌（对弱者） | 与其价值观冲突，会OOC |
| 真诚/纯粹型主角 | 过于世故的神回复 | 显得油滑，失去真诚感 |
| 高傲型反派 | 自嘲式废话文学 | 反派的废话文学应是"傲慢的废话"不是"自嘲的废话" |
| 场景：主角正在经历真正的崩溃 | 任何类型 | 这是情绪高峰，特色语言会稀释分量 |

**反派的特色语言规则**：
反派的毒舌≠普通角色的毒舌。反派说毒舌时，他认为自己在说真理，不是在攻击——这个细微差别决定了反派毒舌的独特质感：
- 普通角色毒舌："你以为你很聪明。"（带着攻击意图）
- 反派毒舌："你们都以为自己很聪明，所以才需要我来告诉你们事实。"（他认为这是善意的）

## 六、特色语言质量自检标准

每句特色语言生成后，在内部执行以下检测，不通过则重写：

**毒舌质检**：
- [ ] 字数 ≤21字？（超出则精炼）
- [ ] 去掉所有铺垫，核心刺点还在吗？
- [ ] 读完有没有想说"好狠"的感觉？
- [ ] 符合该角色的气质和内在逻辑吗？

**神回复质检**：
- [ ] 有没有打破预期？（如果回应是"显而易见"的，就不是神回复）
- [ ] 回头想想，准不准确？（神回复必须是后劲型的，想完才意识到很准）
- [ ] 有没有意外触到某个真实？

**废话文学质检**：
- [ ] 绕了一圈，最后说出真相了吗？（纯废话不等于废话文学）
- [ ] 有荒诞感吗？（不是散文，不是心灵鸡汤，是荒诞中带着洞见）
- [ ] 读完有没有"有点道理但又说了等于没说"的感觉？

**通用质检**：
- [ ] 这句话是原创的，不是语料库原句？
- [ ] 这句话换到另一个完全不同性格的角色身上说，会违和吗？（会违和=有专属性=合格）
