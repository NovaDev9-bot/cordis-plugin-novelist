## 1. 主线脊柱定义

立项第一件事，不是想设定、不是想金手指，而是**定主线脊柱**：

> 开头就有冲突 + 一个贯穿全书的主线任务。

主线脊柱是整本书的承重墙。所有冲突、弧光、因果、场景都**挂**在这条脊柱上。没有脊柱，书就是事件堆砌，读者记不住"这本书在讲什么"。

## 2. 八种主线任务类型（任选其一或组合）

| 类型 | 含义 | 典型开头冲突 |
|---|---|---|
| 找人 | 寻找失散/失踪/被掳走的人 | 亲人突然消失，线索指向危险 |
| 报仇 | 血仇/背叛之仇/灭门之仇 | 家族被灭，凶手逍遥 |
| 回家 | 穿越者想回去/被困者想逃离/流放者想归乡 | 穿越即绝境，归途被封 |
| 承诺 | 对逝者诺言/对恩人誓言/对自己约定 | 恩人死前托付，主角接下 |
| 求生 | 绝境/末日/囚禁求生 | 落入死局，活下去是唯一目标 |
| 解谜 | 身世/阴谋/世界真相之谜 | 发现自己的记忆被人动过 |
| 证明 | 证明自己/证他人清白/证一条路通 | 被全网耻笑，要用结果打脸 |
| 守护 | 守护某人/某地/某信念 | 要保护的人被盯上 |

## 3. 铁律

1. **开头就有冲突**：前 3 章必须出现与主线脊柱直接相关的冲突，不能先铺设定再慢慢来。
2. **偏离主线 ≤ 2 章必须拉回**：任何支线/日常章，偏离主线超过 2 章，第 3 章必须回到脊柱（推进主线任务 / 暴露新阻碍 / 回收一个相关伏笔）。
3. **所有元素挂脊柱**：
   - 冲突 → 是否阻碍或推进主线任务？
   - 弧光 → 主角改变是否为了完成主线任务？
   - 因果 → 因是否源于脊柱、果是否回馈脊柱？
   - 场景 → 是否在推进脊柱或埋/收相关伏笔？
4. **脊柱可变，但需明示**：中段可升级脊柱（如"报仇"升为"终结整个冤案体系"），但必须写清转折，不能无声漂移。

## 4. 与冲突引擎的关系

- 不要用"事件数量"衡量进度，用"脊柱推进量"衡量。一章没推进脊柱 = 该章重写（见 chapter-breakdown-table.md 剧情目标铁律）。
- 爽点（打脸/升级）必须服务脊柱：打脸是为了扫清通往主线的障碍，不是为爽而爽。
- 反派是脊柱的"对立力"：反派每进一步，脊柱就难一步（见 villain-engine.md）。
