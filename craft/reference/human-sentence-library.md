## 一、大神手搓句式库（按风格分类）

### 1. 文雅细腻系（猫腻/关心则乱/顾漫）

#### 标志性句式模板

**①猫腻·认真处突然幽默句式**
- 结构：[严肃描写2-3句] → [突然插入一句俏皮/调侃/自嘲]
- 示例："他坐在廊下看雪，看了很久。雪落满肩头，他也没有拂去。——倒不是有意装深沉，纯粹是冻得懒得动手。"
- 适用：日常场景、人物独白、过渡段落

**②猫腻·慢下来留空间句式**
- 结构：[叙述暂停] → [用2-3句写环境/光线/声音/物件] → [人物一个小动作收束]
- 示例："屋里安静了一阵。窗外的梧桐叶被风吹得翻过来，露出底下灰白色的叶脉。范闲端起茶杯，发现茶凉了，又放下了。"
- 适用：对话间隙、情绪转折前、重大决定前的静默

**③关心则乱·家常白描体**
- 结构：[一个具体生活细节] → [人物随口一句话] → [暗示人情关系]
- 示例："老太太叹了口气，叫人把燕窝端给六姑娘——昨儿又没好好吃饭。大娘子在旁边笑着应了，转身就吩咐自己的丫鬟：'去库房看看，还有没有上次的血燕。'"
- 适用：家族场景、日常互动、关系暗示

**④关心则乱·反讽温柔体**
- 结构：[表面客气温和的话] → [动作/细节出卖真实态度]
- 示例："'妹妹身子不好，可要多吃些。'大姐姐笑着夹了一筷子菜放到她碗里。明兰低头看了一眼——是一筷子肥肉。"
- 适用：宅斗场景、暗流涌动、表面和气

**⑤顾漫·冷面情话体**
- 结构：[男主用最平淡的语气] → [说最深情的话] → [女主反应用一个可爱细节]
- 示例："'嗯，记得。'他翻了一页文件，头也没抬。她愣了三秒，然后默默把桌上那杯已经凉了的奶茶推到他手边——他记得她三个月前随口说喜欢喝这个。"
- 适用：甜宠互动、感情升温

**⑥顾漫·反差萌描写**
- 结构：[严肃/高冷场景1-2句] → [一个可爱/笨拙的细节打破]
- 示例："他面无表情地签完最后一份合同，合上钢笔，对秘书说了句'可以了'。然后弯腰从办公桌底下捡起一颗糖——草莓味的，早上她偷偷放在那里的。"
- 适用：甜文互动、人物魅力展现

**⑦猫腻·选择后的余波句式**
- 结构：[重大决定已做完] → [不写决定本身] → [写决定之后一个极小的日常动作]
- 示例："他没有回答。过了很久，他把碗里的饭吃完了，一粒也没剩。然后站起来，去厨房把碗洗了。"
- 适用：重大转折后、感情确认后、分别前

#### 标志性对话风格

1. **猫腻式·机锋对话**：两人说话像在打太极，每句话都有两层意思。"你今天来得挺早。""不早来，怕你走了。""我不太可能走。""我知道，所以怕。"
2. **关心则乱式·话里藏刀**：表面客气到极致。"妹妹操持家务辛苦了，回头我让人送两匹绸子给你做衣裳。"——意思是"你别管太多了，拿点好处闭嘴吧"。
3. **顾漫式·废话甜蜜**：全是日常废话但全是糖。"吃了吗？""吃了。""吃的什么？""泡面。""……你等我，我还有十分钟到。"

#### 标志性描写手法

1. **器物传情法**：不写"他爱她"，写他把她的杯子从桌上拿到自己这边放好。
2. **饮食叙事法**：一碗燕窝的温度、一杯凉了的奶茶、一盘被挑出来的肥肉——用人物怎么吃、吃什么来写关系。
3. **光线情绪法**：高兴时"阳光落在她身上"，难过时"窗帘拉上了，屋里暗了一层"。

#### 反AI特征总结
- 猫腻：认真叙事中突然幽默打断——AI极难模拟这种"节奏破坏"
- 关心则乱：潜台词密度极高，对话表面意思与实际意思完全相反——AI倾向直给
- 顾漫：用最简单的句子说最甜的话——AI倾向堆砌华丽辞藻表达情感

### 2. 精密克制系（乌贼/远瞳）

#### 标志性句式模板

**①乌贼·口语化陈述+内心独白交替**
- 结构：[大白话平铺直叙1-2句] → [角色第一人称式碎碎念] → [回到叙述]
- 示例："庄远坐在食堂角落，面前摆着一碗没怎么动过的面条。他想着这事儿怎么就这么操蛋呢，明明昨天还好好的。旁边的哥们儿还在聊球赛，他没搭话。"
- 适用：日常场景、情绪低沉时

**②乌贼·一句话就是一段**
- 结构：[极短独立成段，1-5字]
- 示例："他没回头。""成。""算了。"
- 适用：情绪爆发点、转折、对话中的停顿

**③乌贼·省略号+破折号欲言又止**
- 结构：[角色想说什么] → [最后只是——算了/没说出来/换了句话]
- 示例："她看着他，嘴张了张。他想问你怎么了，话到嘴边变成了——'饿不饿？我给你下碗面。'"
- 适用：情感关键节点、角色克制时

**④乌贼·细节构建世界法**
- 结构：[不正面描写某个场景] → [通过散落各处的零散细节让它在读者脑中自然成型]
- 示例：不写食堂多大、多吵，而是写"他打了份鱼香肉丝，找了半天才在二楼靠窗的位置坐下来。旁边那桌在吵架，为了谁多刷了两块钱。"
- 适用：世界观构建、场景交代

**⑤乌贼·伤痕藏在日常缝隙**
- 结构：[看似正常的日常行为] → [一个微妙的回避/过度反应泄露心理创伤]
- 示例："打雷的时候他若无其事地打开了音乐，音量拧到最大。她没问为什么。——她只是注意到，从那以后每次下雨天，他的耳机就没摘下来过。"
- 适用：角色塑造、心理创伤暗示

#### 标志性对话风格

1. **相声式互怼**：一个捧哏一个逗哏。"你昨天又没睡？""你怎么知道？""你黑眼圈都快掉地上了。""……谢谢你的观察力。"
2. **90%废话+10%致命真情**：今天吃什么聊了五段，突然来一句"你还好吗"——这五个字比什么都重。
3. **口语化到骨头里**：小混混说"操，烦死了"，学霸说"你能不能别在我看书的时候呼吸这么响"——每个角色有自己的语言指纹。

#### 标志性描写手法

1. **白描替代抒情**："他蹲在路边，把烟掐了。又点了一根。抽了两口，又掐了。"——不写焦虑，写反复掐烟的动作。
2. **穷得真实**：角色的每一分钱都有来路。"他数了数口袋里的钱，还差三块。最后把公交卡押在那儿，说下次来补。"
3. **生活细节即世界观**：买菜、做饭、打工、挤公交——这些琐碎日常不是填充物，是世界的质地。

#### 反AI特征总结
- 乌贼：句长极度不均匀（1字到50字交替），AI写不出这种"呼吸感"
- 乌贼：对话占比40-60%且90%是废话，AI倾向每句话都有"信息量"
- 乌贼：省略号、破折号、碎碎念大量使用，AI倾向写完整通顺的句子

### 3. 诗意江湖系（烽火/priest/木苏里）

#### 标志性句式模板

**①烽火·对仗式金句**
- 结构：[前后两句形成呼应，上句写景下句写情/上句写事下句写理]
- 示例："世间文字八万个，唯有情字最杀人。""最苦不过相思，最远不过是阴阳。""肝胆相照，君臣共分秋月。意气相投，兄弟共坐春风。"
- 适用：名场面、章末金句、角色定性

**②烽火·数字递进式**
- 结构：[用数字排列制造节奏感+情感层层递进]
- 示例："一两愿你江南多雨带油伞。二两愿你酷暑可以轻摇扇。三两愿你入冬莫忘添衣衫。……六两三。余下三。我在西北，一关接一关。与你相隔，一山又一山。最后只愿我，知道你平安。"
- 适用：深情独白、离别、书信体

**③烽火·短句叠加收束法**
- 结构：[3字+5字+7字，节奏越来越快] → [最后一句收束]
- 示例："风起了。雪落满长街。他提剑走出门去，再没回头。"
- 适用：名场面、角色赴死、离别

**④priest·长句铺陈→短句定锤→更短一击**
- 结构：[长句铺情绪] → [短句收束] → [极短一击（1-4字）]
- 示例："他用了很长时间才明白，那些他以为早已愈合的伤口，其实只是被小心翼翼地藏在了别人看不见的地方。但他不后悔。从未。"
- 适用：内心独白、情感高潮、角色决心

**⑤priest·"不是……而是……"理性拆解句**
- 结构：[否定表面解读] → [给出更深层的真实]
- 示例："不是他不想说，是说出来也没有人能听懂那种感觉——像被关在一个透明的盒子里，外面所有人都在笑，你拍得手掌生疼，没人听见。"
- 适用：心理描写、角色自我认知

**⑥木苏里·环境收束句（以景结情）**
- 结构：[动作/心理短句] → [环境意象长句，含通感或隐喻]
- 示例："夜色沉寂，不知哪棵树上的蝉突然拖长调子叫了一声，明明是夏末，却像仲春的一场惊蛰。盛望心里倏地跳了一下。"
- 适用：暧昧时刻、心动、离别后

**⑦木苏里·反差并列句（温柔刀子）**
- 结构：[美好意象] → [却/偏偏/只是]+[克制/遗憾/距离感的落点]
- 示例："人间骄阳正好，风过林梢，彼时他们正当年少。"——越美好越让人心疼后面的分离。
- 适用：回忆段落、伏笔、对比现在与过去

**⑧烽火·哲理凝缩句**
- 结构：[前半句说常理] → [后半句翻出新意/转折]
- 示例："故事故事，便是故去的事情了，多说无益。""我喝过很烈的酒，也放过不该放的手，从前不会回头，往后不会将就。""人心本炎凉，非世态过错。"
- 适用：角色感慨、章末收尾、人生感悟

#### 标志性对话风格

1. **烽火式·一人一声口**：齐静春温润含蓄"出门在外，小心道士和尚"；阿良玩世不恭"我叫阿良，善良的良"；温华质朴直白"不练剑了"。每个角色说话方式严格匹配身份。
2. **priest式·冷幽默+潜台词**：表面波澜不惊，内心吐槽翻涌。用最随意的语气说最重的话。"你运气不错"（实际意思是"我为你担心死了"）。
3. **木苏里式·互怼即亲密**：关系越近怼得越自然。"你为什么这么慌？"——表面疑问，实际"我注意到你了"。"半天了，还没输完？"——表面调侃，实际"我一直在等你消息"。
4. **priest式·话少的人一句顶十句**：寡言角色台词极短但精准有力。不解释、不告白、不抒情，用行动替代语言。一个推纸条的动作就是全部态度。

#### 标志性描写手法

1. **烽火·自然意象承载哲理**：雪=命运沉重，酒=江湖豪情，剑=精神锋芒，月=离别思念。不直说道理，让意象自己说话。
2. **priest·理工科思维构造比喻**：用物理、工程、数学概念类比情感。把心理创伤比作"无法自愈的沉疴"，把精神崩溃比作"精密仪器的脱节"。
3. **木苏里·延迟引爆法**：不在事件发生时写情绪爆发，在事件过去后、在看似无关的场景里突然引爆。"后来他路过那家奶茶店，下意识买了两杯。"
4. **烽火·器物定人**：用标志性器物定义人物——木剑=纯粹，绿蚁酒=忠义，红衣=执念。

#### 反AI特征总结
- 烽火：文言韵味与现代白话无缝衔接——AI写文言要么太生硬要么太现代
- 烽火：金句可脱离上下文独立成立——AI的句子离开上下文就没有力量
- priest：长句铺陈后极短收束的节奏感——AI句长过于均匀
- priest：翻译腔与纯正中文的切换——AI不会做这种有意识的语体混搭
- 木苏里：环境即情绪，细节即告白——AI倾向直抒情感而非以景结情
- 木苏里：极少用感叹号，情绪越重越用句号——AI倾向用感叹号标记情感

### 4. 说书人/市井系（当年明月/孔二狗/月关/牧童归去）

#### 标志性句式模板

**①当年明月·说书人开场句式**
- 结构：[时间锚点] + [人物从普通人视角切入] + [悬念预告]
- 示例："1344年，淮河两岸。旱灾，蝗灾，瘟疫。朱元璋他爹妈他大哥，在半个月之内，全死了。十六岁的朱元璋站在村口，身上只剩一条破裤子。——大家都知道了，这个人后来做了皇帝。但此刻，他只想找口饭吃。"
- 适用：章节开头、人物出场、命运预告

**②当年明月·反常识陈述句式**
- 结构：[颠覆读者已有认知] → [给出有说服力的新解释]
- 示例："这不是我们以为的那个朱元璋。教科书上说他天生英武、雄才大略。我认为，他只是被饿怕了——一个从小饿到骨子里的人，长大以后最害怕的事情就是没饭吃。"
- 适用：人物重新定位、观点翻转

**③孔二狗·东北方言双层叙事**
- 结构：[对白层用方言/口语/黑话，浓度60-80%] + [叙述层克制简练，浓度20-30%]
- 示例（对白层）："你他妈再说一遍？""说咋了？你赵红兵今天就是不好使！"
- 示例（叙述层）："他站起来的时候，桌子晃了一下。烟灰缸掉在地上，没碎。"
- 适用：社会叙事、地域文学、底层人物

**④孔二狗·第一人称亲历感**
- 结构：["我"的视角制造在场感，但"我"不是主角，而是见证者]
- 示例："后来我再也没见过小北京。听人说他去了深圳，又听人说他回来了，再后来就没人提他了。只有老照片里还留着他的影子——站在二姐身后，笑得没心没肺。"
- 适用：回忆叙事、人物退场、时间流逝

**⑤当年明月·档案反差式**
- 结构：[简历格式的信息] → [最低身份→最高成就的反差] → [括号补充制造幽默]
- 示例："朱元璋，原名朱重八。学历：无。家庭出身：贫农（准确地说，是赤贫）。座右铭：我要活下去。——后来他成了大明开国皇帝。"
- 适用：人物出场、传记式开头

#### 标志性对话风格

1. **当年明月式·现代词汇讲历史**："朱元璋同志""陈友谅先生的战略部署"——用现代人熟悉的语感讲古代故事，制造亲切感。
2. **孔二狗式·方言即性格**：赵红兵说话干脆利落不带脏字；小北京满嘴跑火车；二姐说话带刺但句句在理。方言浓度区分角色。
3. **当年明月式·作者旁白插话**：叙事中突然插入作者的评价。"说实话，我觉得这哥们儿挺不容易的。搁现在也就是个高中毕业生，没房没车没工作。"

#### 标志性描写手法

1. **日常突变法**（孔二狗）：[极日常的东北生活场景] → [一个小摩擦突然升级为暴力冲突]。"二姐在门口炸油条。隔壁老李头过来借酱油。两个人聊了两句。三分钟后，油条摊子翻了。"
2. **暴力场景短句爆发**（孔二狗）：暴力场景用3-8字短句连击。"他动手了。一刀。血溅出来。旁边的人愣了一秒，然后全散了。"
3. **历史人物祛魅法**（当年明月）：把帝王将相当普通人写。"皇帝也是人，也会拉肚子，也会被老婆骂。"
4. **双层叙事落差**（孔二狗）：对白层的粗粝与叙述层的诗意形成落差，制造"日常中的文学性"。

#### 反AI特征总结
- 当年明月：现代口语与历史叙事的混搭——AI写历史要么太古要么太正经
- 当年明月：作者旁白频繁插入打断叙事——AI不会做这种"出戏"的处理
- 孔二狗：方言浓度精确控制——AI要么全用方言要么完全不用
- 孔二狗：暴力场景后的长余波沉淀——AI写完暴力就结束，不会写"打完之后人变了"

### 5. 热血爽文系（肘子/辰东/天蚕土豆/唐家三少/老鹰）

#### 标志性句式模板

**①肘子·系统提示体**
- 结构：["来自XXX的负面情绪，+X"] → [机械冰冷的标准化句式反复出现形成荒诞韵律]
- 示例："来自王教授的负面情绪，+666。""来自张可爱的负面情绪，+327。"——吕树面不改色，内心已经在算这个月能兑换什么了。
- 适用：系统流、轻松搞笑、爽点标记

**②肘子·反讽转折体**
- 结构：[前半句正经] → [逗号] → [后半句突然拉胯]
- 示例："少年意气的豪情宣言刚出口，下一秒接了一句'但在那之前，你能不能先把欠我的二十块钱还了？'"
- 适用：消解严肃、制造笑点、人物魅力

**③辰东·苍茫咏叹体**
- 结构：[以"万古""纪元""沧桑"等时间意象构建史诗感]
- 示例："一粒尘可填海，一根草斩尽日月星辰。""岁月如刀斩天骄，长生路上叹妖娆。"
- 适用：史诗场景、大帝出场、远古秘辛

**④辰东·长句造势→短句定锤**
- 结构：[恢弘长句铺陈天地异象] → [极短断句收束]
- 示例："亿万道光华交织成一片浩瀚的仙道画卷，整个天地都在震颤。崩了。"
- 适用：战斗高潮、世界观展示、力量碾压

**⑤老鹰·数据化修辞**
- 结构：[用精确数值替代模糊描述]
- 示例："气血113卡""淬炼了36根骨骼""全身骨骼都变成了金色，就练成了'金身不坏'"
- 适用：升级描写、战力展示、修炼突破

**⑥老鹰·欲扬先抑句**
- 结构：[大段篇幅渲染对手之强] → [一句短句完成反杀]
- 示例："那人修炼了三十年铁布衫，刀枪不入，方圆百里无人能敌。方平一拳轰出。对方倒了。"
- 适用：打脸场景、实力展示、爽点爆发

**⑦肘子·碰瓷式调侃句**
- 结构：[主角用商人思维/现代人视角吐槽异世界规则]
- 示例："穷人没资格变强。""破产才是动力。""打架不一定赢，但吵架从来没输过。"
- 适用：轻松日常、主角人设塑造

#### 标志性对话风格

1. **肘子式·毒舌连环**：专戳对方认知盲区和逻辑漏洞。短促、密集、不给喘息空间。一句毒舌=一句精准事实+一层荒诞包装。
2. **肘子式·怼-收循环**：先怼到对方血压飙升→突然正经/暖心→再调侃一句。"贱中有暖"。
3. **辰东式·强者台词极简**：大帝级角色台词往往只有寥寥数字却气场惊人。"帝有帝威，言出法随。"
4. **老鹰式·对话即叙事引擎**：通过角色对话不经意间带出设定和下一段剧情，对话占比超40%。

#### 标志性描写手法

1. **肘子·吐槽式旁白**：叙述者不是全知视角，而是"带态度的观察者"。正经叙事中频繁插入吐槽性评论，"讲故事的人自己也在笑"。
2. **辰东·大帝群像侧面烘托**：不直接写主角多强，通过众人的反应来衬托。"围观者的脸色比战斗本身更重要。"
3. **老鹰·战斗与设定融合**：绝不单独好几章都是打斗，在打斗中穿插背景设定抛出。以"破坏力反馈直接"为核心——不写花哨招式，写拳头碰到地面的坑洞。
4. **肘子·数据嵌入叙事**：系统数值、倒计时、百分比直接嵌入正文，形成"游戏化阅读"体验。

#### 反AI特征总结
- 肘子：吐槽旁白打破叙事正经感——AI不会"自己讲着讲着自己笑了"
- 肘子：正经→突然拉胯的反转——AI的反转太规律
- 辰东：四字命名体系自带意境——AI命名太泛化（"九天神雷诀"vs"九龙拉棺"）
- 老鹰：数据化描写替代模糊形容词——AI倾向写"强大无比"而非"气血113卡"

### 6. 悬疑/社会派系（核融炉/点灯/半裁明月/六如和尚/梦溪石）

#### 标志性句式模板

**①核融炉·自述供述体**
- 结构：[第一人称"我"的叙述] → [突然自曝"前面讲的可能都是假的"]
- 示例："其实故事发展到现在，前面我所讲述的亲身经历，大半都是假的。都是为了最后应对警察，编写的剧本。"
- 适用：悬疑反转、不可靠叙述者

**②核融炉·对话推进体**
- 结构：[几乎完全依赖对话推进剧情] → [每句话表面说A实际隐瞒B暗示C]
- 示例："'那天你在哪？''在家。''一个人？''……是。''几点回的？''忘了。'"——每句回答都在撒谎，但读者要读到后面才知道。
- 适用：审讯场景、罗生门叙事

**③点灯·平实引入体**
- 结构：[开头刻意不渲染戏剧性] → [力求平实地引入情节] → [越往后越震撼]
- 示例："我哥是今年三月出去的。走的时候跟我说，等赚了钱就回来盖房。他没回来。我去工地上找，工地的人说他早就不干了。"
- 适用：社会派悬疑开头、底层人物叙事

**④半裁明月·逆境独白体**
- 结构：[第一人称或紧贴主角] → [绝境中内心独白] → [短促有力如刀刻]
- 示例："我没有金手指。我只有一条命，和拼到底的决心。""你卖我的那天，我记得清清楚楚。"
- 适用：大女主觉醒、逆袭宣言

**⑤半裁明月·乱世白描体**
- 结构：[用最朴素的语言描写最残酷的现实]
- 示例："菜人。按斤两卖。屠户挑肥瘦。"
- 适用：残酷现实展示、底层苦难

**⑥点灯·极短定锤句**
- 结构：[在看似"铁证"的案件中] → [用一个极短的句子"定锤"]
- 示例："他不是凶手。""他也是受害者。""人是我杀的。"
- 适用：反转节点、真相揭示

#### 标志性对话风格

1. **核融炉式·对话即线索**：表面在说A，实际隐瞒B、暗示C。不同版本叙述中同一事件的对话有微妙差异——差异就是线索。
2. **点灯式·底层人物直白对话**：工地工人说工人的话，律师说律师的话。"我哥失踪了。工地说不知道。我去报了警，警察说不够立案标准。"
3. **半裁明月式·话少有分量**：女主每句话都是从困境中淬炼出来的。"你说我是菜人？那你看清楚，菜人坐在龙椅上了。"

#### 标志性描写手法

1. **核融炉·最终版本倒推法**：先确定完整真相，再逐层减少细节线索构筑每个"假版本"。所有"假版本"都"合情合理"。
2. **点灯·低开高走**：开头平实到近乎无聊，越往后越震撼。"平实引入"是前提，"高走"是结果。
3. **半裁明月·金手指源自苦难**：女主天赋不是外挂，是"被逼出来的生存本能"。"能靠银器声响辨人心"本质上是"乱世中一个孩子被迫练出来的危险敏感"。
4. **点灯·留白艺术**：只向读者透露与剧情相关的最基础信息——剩下的让读者自己填补。

#### 反AI特征总结
- 核融炉：叙述者本身就是骗子——AI不会设计"不可靠叙述者"
- 核融炉：对话即叙事的纯对话驱动——AI倾向在对话间加大量描写
- 点灯：开篇刻意不渲染——AI写悬疑开头就急着制造悬念
- 半裁明月：残酷不需要修辞——AI写苦难会加太多形容词

### 7. 仙侠/修真系（耳根）

#### 标志性句式模板

**①耳根·以身证道式**
- 结构：[修炼突破不只是数值变化] → [用一句哲理或感悟收束]
- 示例："他闭上眼，感受灵力在经脉中流转。不是灵力变强了，是他终于不再害怕失去。——道，在心上。"
- 适用：修炼突破、心性提升

**②耳根·宿命轮回式**
- 结构：[前世/前世的意象反复出现] → [今生的某个瞬间与之重叠]
- 示例："千年前的那场大雨，他也曾站在同样的位置。那时候他是谁？他记不清了。只是这雨声，怎么听都像是在哭。"
- 适用：宿命揭秘、前世线索、角色觉醒

**③耳根·苍凉孤独式**
- 结构：[宏大场景] → [一个人的渺小/孤独]
- 示例："仙界万千，仙山如林。他站在云海边上，忽然觉得自己又变成了那个村口的少年，什么都不懂，什么都留不住。"
- 适用：境界提升后的回望、角色孤独时刻

#### 标志性对话风格

1. **师徒式对话**：师父说话半藏半露，弟子追问不得。"你问我什么是道？你先告诉我，你怕什么。"
2. **大道至简**：最强者说的往往是最朴素的话。"活着就好。别的，慢慢来。"

#### 标志性描写手法

1. **修炼与人体对应**：修炼体系对应人体脏腑骨骼，让修炼有生理学"真实感"。
2. **以心证道**：力量根源是心性修炼——"练拳百万"实为"磨心中万古刀"。

#### 反AI特征总结
- 修炼突破用心性而非数值描写——AI写修炼太"数值化"
- 宿命感通过意象重叠而非旁白说明——AI倾向直给"原来他们是前世"

### 8. 其他风格

#### 纷舞妖姬（军事写实）

**标志性句式**：短句+军事术语+冷硬白描。"三点钟方向，两个哨兵。换岗间隔九十分钟。他数过了。"
**反AI特征**：军事细节考据到分钟级别——AI编不出"换岗间隔九十分钟"这种具体数字。

#### 孑与2（历史种田）

**标志性句式**：用现代视角吐槽古代生活。"大唐什么都好，就是没有马桶。第一次用的时候我整个人都不好了。"
**反AI特征**：现代梗与古代背景的碰撞——AI不会在历史文里写"没有WiFi"。

#### 恩养（世情小说）

**标志性句式**：用人物习惯动作定义性格。"她每次心虚就转戒指。转得快就是在撒谎，转得慢就是在想怎么圆。"
**反AI特征**：观察式的人物速写——AI的人物缺少这种"长期观察"才能得出的细节。

### D. 节奏打断器（20种）

**1. 突然插入极短句**
- 大段描写后突然来一句："操。""崩了。""算了。""他走了。"

**2. 括号自言自语**
- "他把门推开（后来他回想起来，那扇门其实没锁）——走了进去。"

**3. 无关细节打断**
- 正写到紧张的对话，插入一句："桌上的苍蝇搓了搓前腿，飞走了。"

**4. 时间跳跃**
- "后来的事情，三天后才有了结果。"——跳过等待过程。

**5. 视角忽然切到物件**
- 正在写两人争吵，突然写一句："那个杯子从桌边掉下去，碎成了三块。"

**6. 声音描写打断**
- 关键时刻插入环境音："远处传来一声狗叫。""楼下有人在吵架。""水龙头在滴水。"

**7. 气味锚点**
- "屋里有一股子潮湿的味道，像老房子的地下室。"——用气味把读者拽进场景。

**8. 叙述者忽然插话**
- "这事搁现在想想也挺离谱的。"——叙述者从故事里探出头来说一句话。

**9. 数字锚定**
- "那年她23岁，存款4200块，距离月底还有11天。"

**10. 身体小动作打断**
- 对话中间插入："他挠了一下后脑勺。""她把头发别到耳后。""他抖了一下腿。"

**11. 食物/饮料打断**
- 紧张场景里忽然写："她端起杯子喝了口水，发现水没了。"

**12. 手机/消息打断**
- "正要说重要的话，手机亮了——一个快递通知。"

**13. 天气突变打断**
- "话没说完，外面忽然下起了雨。"

**14. 回忆闪回打断**
- "他看着她的脸，忽然想起十年前在车站的那个下午——"

**15. 动物/小孩闯入**
- "两人正僵持着，一只猫从窗户跳了进来。"

**16. 邻居/路人打断**
- "楼上忽然传来拖椅子的声音。""隔壁在放电视剧，声音开得很大。"

**17. 身体感觉打断**
- "说着说着他打了个喷嚏。""她忽然饿了。""他的胃叫了一声。"

**18. 段落结尾不句号**
- 非正式写作中段落结尾不加标点，或者用省略号：
- "他说会来的，但是……"

**19. 自我否定打断**
- "他决定明天去找她。——算了，还是后天吧。"

**20. 读者对话打断**
- "你猜怎么着？""说出来你可能不信。""这事要是搁在小说里，读者肯定骂作者瞎编。"

### E. 叙述者人味碎片（30+条）

以下句式可以穿插在叙述中，给文本注入"人在讲故事"的气息：

**说书人类：**
1. "这事搁现在想想也挺离谱的。"

## 三、去AI实战对照（大段落级）

### 对照1：悲伤场景

**AI版本：**

**真人版本（乌贼式白描）：**
> 电话挂了很久了，屏幕已经黑了。李明还举着手机，保持着那个姿势。旁边的同事问他怎么了，他没回答。他把手机放下来，放在桌上，又拿起来，看了看通话记录——3分27秒。他把手机翻过去扣在桌上。过了一阵，他站起来，走到窗边。楼下有个老太太在遛狗。他看了很久。然后他回到座位上，开始收拾东西——他得回老家了。

**真人版本（辰东式短促爆发）：**

>

>

**真人版本（木苏里式以景结情）：**

> 
> 屏幕亮了又暗了，她什么也没看。
>

>

>

>

## 五、使用指南

### 替换优先级

1. **第一优先**：用当前选定大神的DNA句式替换（如选了猫腻风格，优先用猫腻系句式）
2. **第二优先**：用同风格系的其他大神句式（如猫腻不够用，用关心则乱/顾漫的）
3. **第三优先**：用第二部分"句式级替换词典"中的通用替换库
4. **第四优先**：用第三部分的大段落对照作为改写参考

### 密度控制（硬性指标）

| 指标 | 最低要求 | 理想密度 |
|------|----------|----------|
| 每500字真人句式特征 | ≥3个 | ≥5个 |
| 每章括号自言自语/叙述者插话 | ≥1处 | ≥2处 |
| 每章节奏打断（短句/碎片句） | ≥2处 | ≥4处 |
| 对话碎片化率 | ≥40% | ≥60% |
| 极短句（≤10字）占比 | ≥10% | ≥15% |
| 感官锚点（五感描写） | 每场景≥1个 | 每场景≥2个 |

### 检测清单（交付前必过）

- [ ] 搜索并删除"意识到""终于明白""心中涌起"等AI高频词
- [ ] 检查句长均匀性：是否有极短句打断节奏
- [ ] 检查对话：是否有碎片化特征（省略、打断、词不达意）
- [ ] 检查情绪表达：是否有用白描/生理反应/环境映射替代直抒
- [ ] 检查段落结构：是否有段落不遵循"总分总"模板
- [ ] 检查叙述者：是否有人味碎片（"说白了""你猜怎么着"）
- [ ] 检查场景结尾：是否落在动作/对话/画面而非叙述者感慨
- [ ] 检查排比句：叙述层是否出现"是XX，是XX，更是XX"
- [ ] 检查形容词：是否单主体修饰词≤1个
- [ ] 检查感官锚点：每个场景是否有至少一个五感描写

### 核心心法

> **AI写作的本质特征是什么？**
> 1. 句长太均匀 → 打碎它
> 2. 情绪太直给 → 藏起来
> 3. 结构太规整 → 破坏它
> 4. 描写太泛泛 → 具体化
> 5. 对话太完整 → 碎片化
> 6. 叙述太客观 → 加人味
> 
> **大神为什么100%通过AI检测？**
> 因为他们写作靠的是直觉、习惯、经验和脾气——这些东西没法被模型化。猫腻在认真处突然幽默，乌贼用废话构建亲密，烽火用短句造势——这些不是"技巧"，是"人格"。
> 
> **你的目标不是"像某位大神"，而是"像一个有脾气的人"。**
