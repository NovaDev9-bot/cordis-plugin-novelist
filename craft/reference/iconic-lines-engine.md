# 经典台词/金句创作引擎（Iconic Lines Engine）

> **移植件 · 外部来源（未经本仓校对）**
> 来源 = 外部技能包 novel-workshop-pro（WorkBuddy 专家，上架名「网文主编」）；原始路径 = references/iconic-lines-engine.md；移植日 2026-09-26。
> **取用边界**：本件可能含指标式表述（百分比／密度／配额／占比）。那类量归**审校侧与主编参考**用；
> **不得整段复制进写手派工包**——口径见 craft/author-cards/_模板与建卡纪律.md 的四分界表（进包只许「结构节拍」与「形态上限」两种形状）。
> **取用方式**：按本章场景功能取相应小节，**上限 2 节**；「相关的都塞」是禁止项（guide v7.14）。

> **文件定位**：解决「角色金句缺失」问题。当角色需要在关键时刻说出让人记住一辈子的那句话——霸气宣言、信念宣告、身份定义级台词——本引擎提供系统化的创作方法论。
>
> **与「特色语言系统」的关系**：特色语言（毒舌/神回复/废话文学）解决的是日常对话的辨识度和趣味性；本引擎解决的是**关键时刻的爆发力**——那种读者会截图、会抄下来、会放在社交媒体签名里的句子。
>
> **强制触发时机**：
> - 大纲阶段：标记每卷/每篇的「金句锚点」（角色在哪个时刻需要一句定义级台词）
> - 写作阶段：到达金句锚点时，执行「金句生成流程」
> - 修订阶段：检查金句是否达到「可独立传播」标准
>
> **强制配额**（金句是稀缺资源，宁缺毋滥）：
> | 篇幅 | 最高配额 | 说明 |
> |------|---------|------|
> | 微小说（800-2200字） | 0-1句 | 有合适的名场面才出，没有就不硬塞 |
> | 短篇（含盐选，8000-15000字） | 1-2句 | 整篇最多2句，必须间隔≥3000字 |
> | 长篇（单卷3-5万字） | 1-3句 | 一卷里最多3句，不是每章都有 |
> | 长篇（全书） | 不超过10句 | 全书级别的定义金句，每10万字最多2-3句 |
>
> **核心原则**：金句的力量来自稀缺。读者记住的永远是那1-2句反复咀嚼的话，不是一页冒出一句的口号。写不出来就硬凑=廉价。

## 一、经典台词的六大修辞结构

### 1.1 霸气宣言型

**核心公式**：`[极端动作/数量] + [绝对化结果/状态]`

**结构特征**：
- 用极大的数字、极广的空间、极强的动作堆叠气势
- 结果必须是绝对的、不可逆的、排他的
- 语感：像一把刀劈下来，干脆利落

**经典范式**：
- "杀到世间无人敢称尊"（极端动作 + 绝对结果）
- "亿万生灵为兵，百万神魔为将，待到逆乱阴阳时，以我魔血染青天"（数量堆叠 + 时间转折 + 核心宣言）
- "赤锋矛，不朽盾，斩尽仙王灭九天"（意象列举 + 极端结果）

**创作步骤**：
1. 确定角色此刻要证明的「绝对」是什么（力量？决心？意志？）
2. 选择一个极端动作词（斩、灭、碎、裂、焚、踏、碾、屠……）
3. 选择一个绝对化结果（无人、万古、九天、苍穹、乾坤……）
4. 用节奏感串联：先铺（列举/堆叠），后收（一句定论）

**生成模板**：
```
模板A：[动词]尽[对象]，[绝对化结果]
  → 斩尽天下负我者，世间再无[某物]
  → 踏碎凌霄万里云，谁敢拦我[某事]

模板B：[大数量/大范围]为[工具]，待到[转折时机]，以我[代价]染[宏大意象]
  → 千山万水为棋，待到风云变色时，以我残局定乾坤

模板C：[具体意象1]，[具体意象2]，[极端动作]+[宏大对象]
  → 铁甲寒，战鼓鸣，杀穿三界九万里
```

### 1.2 天地对立型

**核心公式**：`[宏大宇宙意象A] + [对比/对抗] + [宏大宇宙意象B] + [角色立场/姿态]`

**结构特征**：
- 用天地、日月、古今、阴阳等宇宙级意象对立
- 角色站在对立的一端，表明立场
- 语感：天地为棋盘，角色落子

**经典范式**：
- "仙路尽头谁为峰，一见无始道成空"（仙路尽头=空间极致 vs 无始=时间起源，角色是那个让一切归零的人）
- "若天压我，劈开那天，若地拘我，踏碎那地"（天/地对举，角色是打破天地束缚的人）
- "手握日月摘星辰，世间无我这般人"（日月星辰 vs 独一无二的"我"）

**创作步骤**：
1. 确定对立的两极：天/地、古/今、仙/魔、生/死、道/逆
2. 角色站在哪一极？还是站在对立的交汇点上？
3. 用对仗或排比构建两极张力
4. 最后一句收束到角色的姿态/宣言

**生成模板**：
```
模板A：若[宇宙力量]压我，[极端反抗动作]那[宇宙力量]
  → 若天道压我，焚尽那天道（简洁版）
  → 若天命拘我，逆天改命；若因果锁我，碎因断果（对仗版）

模板B：[宇宙意象A]尽头谁为[角色定位]，一见[角色名/特质][一切]成空
  → 剑道尽头谁为峰，一剑既出万法空
  → 武道巅峰谁是主，我若不允谁敢登

模板C：手握[宇宙意象]，世间无我这般[角色身份]
  → 脚踏阴阳掌乾坤，三界无我这般人
  → 口含天宪手执笔，万古无我这般仙
```

### 1.3 身份悖论型

**核心公式**：`[角色本应/本是XX] + [却/偏偏+反常行为] + [暗示深层力量/选择]`

**结构特征**：
- 用「应然」与「实然」的矛盾制造张力
- 表面的"委屈/收敛/隐忍"暗示着更深层的力量或选择
- 语感：像一潭深水，表面平静，底下是万丈深渊

**经典范式**：
- "你本是该咆哮世间的怪物，却非要收敛爪牙做个废物"（怪物→废物，反差极大，暗示角色有咆哮世间的能力却选择隐忍）
- "我本楚狂人，凤歌笑孔丘"（身份反差+行为反差）

**创作步骤**：
1. 确定角色的「真实本质」：他/她骨子里是什么？（怪物、王者、神明、疯子……）
2. 确定角色的「表面状态」：他/她此刻在做什么？（隐忍、伪装、低调、平凡……）
3. 用"本是/本该...却..."的结构制造反差
4. 反差越大，金句越有力量

**生成模板**：
```
模板A：你本是该[极端行为]的[身份]，却非要[反常行为]做个[低微身份]
  → 你本是该吞噬星空的凶兽，却收敛獠牙做条家犬
  → 你本是该令万界颤抖的暴君，却敛去杀意做个凡人

模板B：[表面身份]不过是[真实身份]的伪装，[揭露信号]时，[真相爆发]
  → 三年的废物不过是龙困浅滩，鳞甲初现时，方知何为天威
```

### 1.4 时空跨越型

**核心公式**：`[时间跨度/空间跨度] + [不变的核心/剧变的结果]`

**结构特征**：
- 用"三十年""万古""千秋""九天""三界"等超大时空尺度
- 在巨大尺度中锚定一个不变的核心（信念/身份/承诺）
- 语感：时间的重量压在一句话上

**经典范式**：
- "三十年河东，三十年河西，莫欺少年穷"（时间跨度+命运翻转+核心宣言）
- "天不生我李淳罡，剑道万古如长夜"（假设+时间极致+角色定义）

**创作步骤**：
1. 确定时间/空间跨度（三十年、万古、千秋、九万里……）
2. 在这个跨度中，什么变了？什么没变？
3. 用跨度制造「命运感」：时间改变了一切，但改变不了XX
4. 最后落在一个不可动摇的核心上

**生成模板**：
```
模板A：[时间]前[状态A]，[时间]后[状态B]，莫[否定词][当前弱势身份][贬义词]
  → 二十年前困于牢，二十年后困龙升，莫笑阶下囚无志
  → 百年前无名小卒，百年后万界共主，莫欺今朝身微贱

模板B：天不生我[角色名/身份]，[领域]万古如[黑暗/空虚意象]
  → 世无此子持剑立，剑道万古如长夜（变体）
  → 若无此人守边关，人间万古皆荒原（变体）

模板C：[时间跨度]不过[轻描淡写的比喻]，我[核心动作/承诺]不改
  → 三千年不过弹指间，我诺不改
  → 万古千秋一场梦，唯我剑意永长存
```

### 1.5 排比递进型

**核心公式**：`[动词A+对象A]，[动词B+对象B]，...，[终极动词+终极对象]`

**结构特征**：
- 3-9个递进式动宾结构
- 每个后续动作/对象比前一个更宏大/更极端
- 最后一击收束，达到气势巅峰
- 语感：像海浪，一浪高过一浪

**经典范式**：
- "我陈平安，唯有一剑，可搬山，断江，倒海，降妖，镇魔，敕神，摘星，摧城，开天"（一剑贯穿，动作从小到大递进：搬山→开天）

**创作步骤**：
1. 确定核心载体（一剑、一枪、一刀、一念、一字……）
2. 列举5-9个递进式动作，从具体到宏大
3. 排列节奏：短-短-短-长-更长-最长（或均匀递进）
4. 最后一个动作必须是"极致"——超越前面所有动作的量级

**递进参考序列**：
```
力量递进：碎石→裂地→崩山→断江→翻海→裂天→开天
范围递进：一城→一国→一域→一界→万界→诸天→混沌
时间递进：一时→一日→一年→十年→百年→千年→万古
数量递进：一人→十人→百人→千人→万人→百万→亿万→无尽
情感递进：护身→护家→护国→护苍生→护天下→护万世太平
```

**生成模板**：
```
模板：我[角色名]，唯有[载体]，可[动作1]，[动作2]，...，[终极动作]
  → 我林远，唯有一拳，可碎甲，裂盾，崩城，裂地，断天，灭世，开混沌
  → 我苏暮，唯有一笔，可画骨，描心，写魂，定命，改天，换日，重塑轮回
```

### 1.6 诗意宣言型

**核心公式**：`[对仗/韵律结构] + [核心宣言/意象] + [角色姿态]`

**结构特征**：
- 有明确的韵律感（押韵或对仗）
- 兼具诗意和力量，不是单纯的喊口号
- 语感：像一首短诗，但每个字都带着血性或悲壮

**经典范式**：
- "笑望沧溟千军破，策定乾坤算因果。无觉无惧轻生死，非鬼非神似疯魔"（七言四句，押韵，每句一个态度层次）
- "待到阴阳逆乱时，以我魔血染青天"（对仗+极端意象+角色献身）

**创作步骤**：
1. 确定情感基调：豪迈？悲壮？洒脱？疯狂？冷冽？
2. 选择韵脚（ang/iang, ong, an/ian, u/ou, e/ie……）
3. 构建2-4句，每句一个意象层次
4. 最后一句是核心宣言/角色姿态的收束

**生成模板**：
```
四句式（适合角色登场/大高潮）：
  [动作+意象]，[动作+意象]。
  [态度+哲理]，[角色定义]。
  
  示例：
  踏破凌霄三千界，笑看苍生百万年。
  不问天道不问命，我命由我不由天。

两句式（适合关键时刻的一句话）：
  [上句铺势]，[下句收束/宣言]。
  
  示例：
  纵有千万人阻挡，我亦往矣。
  天道不仁，我便替天行道。
```

## 二、金句植入时机矩阵

### 2.1 S级时机（必须使用，不植金句=浪费名场面）

| 时机 | 适用结构 | 金句性质 | 示例情境 |
|------|---------|---------|---------|
| **角色首次展露真正实力** | 霸气宣言/排比递进 | 震撼全场 | 主角一直隐藏实力，第一次认真出手 |
| **绝境中的宣言** | 天地对立/时空跨越 | 不屈/信念 | 面对碾压级敌人，所有人绝望时主角站起来 |
| **身份揭露/觉醒瞬间** | 身份悖论/天地对立 | 定义级 | "你们一直看不起的那个人，其实是……" |
| **大高潮对决的最后一击** | 排比递进/霸气宣言 | 终结级 | 最终决战的制胜一击 |

### 2.2 A级时机（强烈推荐）

| 时机 | 适用结构 | 金句性质 |
|------|---------|---------|
| **师徒/前辈传承** | 诗意宣言/时空跨越 | 传承级/嘱托级 |
| **反派终极宣言** | 霸气宣言/天地对立 | 压迫级/理念级 |
| **角色做出重大牺牲** | 诗意宣言/时空跨越 | 悲壮级/告别级 |
| **卷末/大段落收束** | 时空跨越/诗意宣言 | 总结级/展望级 |

### 2.3 B级时机（择机使用）

| 时机 | 适用结构 | 金句性质 |
|------|---------|---------|
| **角色对后辈的点评** | 身份悖论 | 点醒级 |
| **日常中的突然认真** | 诗意宣言 | 反差级 |
| **旁白的总结性一句** | 时空跨越 | 史诗级旁白 |

### 2.4 禁忌时机（严禁植入金句）

- 日常轻松对话中（会显得中二）
- 悲伤/悼念场景的核心瞬间（会破坏情绪分量）
- 连续打斗动作中（节奏不允许，金句需要"停顿感"）
- 一章中出现超过2次（金句会通货膨胀）

## 三、金句质量检验标准（四维测试）

每句金句完成后，必须通过以下四维测试：

### 3.1 独立传播测试
**标准**：这句话脱离上下文，单独发在社交媒体上，读者能否感受到力量？
- ✅ 通过："天不生我李淳罡，剑道万古如长夜"——即使没看过《雪中》，也能感受到这个人的分量
- ❌ 不通过："我一定要打败你"——脱离上下文毫无意义

### 3.2 角色唯一性测试
**标准**：这句话换成其他角色说，是否违和？
- ✅ 通过："你本是该咆哮世间的怪物，却非要收敛爪牙做个废物"——只有了解这个角色的人才能说出/被这样评价
- ❌ 不通过："我永远不会放弃"——任何角色都能说，没有辨识度

### 3.3 节奏记忆测试
**标准**：读者读一遍后，是否能凭记忆复述出核心结构？
- ✅ 通过："三十年河东，三十年河西，莫欺少年穷"——节奏清晰，容易记住
- ❌ 不通过："就算命运对我再不公平，我也要坚持不懈地努力下去"——没有节奏，记不住

### 3.4 情感锚点测试
**标准**：这句话是否承载了一个明确的情感/态度/信念？
- ✅ 通过："莫欺少年穷"——承载了"弱者不甘被轻视"的情感
- ❌ 不通过："天地之间唯我独尊"——有气势但没有情感锚点，空洞

### 3.5 原创性查重测试（⚠️ 最关键，不通过直接废弃重写）

**标准**：这句话与任何已有的知名金句/名台词的相似度是否低于「撞车线」？

**五维查重清单**（逐条自检，命中任意一条=不合格，必须重写）：

| 查重维度 | 撞车判定 | 示例 |
|---------|---------|------|
| **骨架相似度** | 句式骨架与他人名篇相同，仅替换了个别词汇 | ❌ "天不生我[角色名]，XX万古如长夜" —— 直接套用了《雪中》的骨架 |
| **意象组合重复** | 核心意象组合与他人高度重合 | ❌ "以我魔血染苍穹" vs "以我魔血染青天" —— 只换了最后一个字 |
| **标志性开头撞车** | 开头词组/句式是某名句的标志性开头 | ❌ "三十年河东，三十年河西，莫欺XX穷" —— 标志性开头+结构完全一样 |
| **节奏指纹相同** | 断句节奏、音节数与名句几乎一致，读起来像同一首歌 | ❌ "手握日月摘星辰，世间无我这般人" → "脚踏山河破苍穹，天下谁人敢争锋" —— 节奏完全一样 |
| **核心语义等价** | 表达的核心意思与名句相同，只是换了说法 | ❌ "我命由我不由天" → "我的命运我自己说了算" —— 意思完全一样 |

**原创性底线规则**：
1. **禁止套用名篇骨架**：不能用"天不生我XX"、"XX尽头谁为峰"、"XX谁为主"这类已被名篇占有的标志性骨架
2. **禁止换字洗稿**：不能只替换名句中的1-3个字就当作原创
3. **禁止复用标志性意象组合**：如"以我XX染青天"、"一剑可搬山断江"这类组合已被绑定到具体作品
4. **必须绑定角色独有信息**：金句的核心词汇必须来自当前角色的独特经历、能力、信念，而不是从公共意象库中随意组合

**原创性达标示例**：
- ✅ "从今往后，我身后的人，谁都不用再低头" —— 没有任何名篇骨架，绑定角色「守护者」身份，意象（低头）是日常动作而非公共意象
- ✅ "你本是该咆哮世间的怪物，却非要收敛爪牙做个废物" —— 绑定角色「隐藏实力」的具体处境，反差结构服务于角色弧光
- ✅ "天道不仁，我便替天行道；苍生有劫，我以一身当之" —— 虽有对仗但不套用任何名篇骨架，意象组合（天道/苍生/一身当之）是为当前角色量身打造

**原创性不合格示例**：
- ❌ "天不生我沈临川，谋道万古如长夜" —— 套用《雪中》骨架，一眼假
- ❌ "一剑可碎山裂地翻海灭世" —— 跟《剑来》陈平安的递进结构一样，只是换了动词
- ❌ "三十年前你看不起我，三十年后你高攀不起" —— 跟"莫欺少年穷"结构完全撞车

## 四、金句与角色气质匹配规则

### 4.1 角色类型→金句风格对照表

| 角色气质类型 | 最适配金句结构 | 金句调性 | 禁忌 |
|------------|--------------|---------|------|
| 冷情/克制/隐忍型 | 身份悖论 + 诗意宣言 | 冷冽、内敛、暗流涌动 | 禁止喊口号式宣言 |
| 霸道/王者型 | 霸气宣言 + 排比递进 | 绝对、排他、碾压 | 禁止犹豫或自我怀疑 |
| 热血/成长型 | 时空跨越 + 霸气宣言 | 不屈、向上、打破极限 | 禁止居高临下 |
| 智谋/算计型 | 诗意宣言 + 天地对立 | 棋局感、运筹帷幄 | 禁止纯武力宣言 |
| 反派（理念型） | 天地对立 + 诗意宣言 | 宏大叙事、扭曲但自洽 | 禁止单纯邪恶/疯狂 |
| 反派（霸权型） | 霸气宣言 + 排比递进 | 绝对压制、不可违抗 | 禁止啰嗦 |
| 旁白/叙述者 | 时空跨越 + 诗意宣言 | 史诗感、命运感、苍凉感 | 禁止口语化 |

### 4.2 金句密度控制

**铁律：金句不是台词，是雕塑。一座花园里最多放三座雕塑，放多了就成建材市场了。**

**全书维度**：
- 一本小说的「定义级金句」总量不超过10句
- 每10万字最多2-3句
- 金句必须是全书「名场面」的标记点，不是日常对话

**卷维度**：
- 每卷（3-5万字）最多1-3句
- 多数章节不应该有金句，没有金句的章节才是正常的
- 一卷3句已经是极限密度

**角色维度**：
- 主角全书最多3-5句金句
- 重要配角/反派全书最多1-2句
- 同一角色的金句之间必须间隔足够远（至少2-3万字），形成"回忆杀"式的呼应

**场景维度**：
- 同一场景最多1句金句（S级时机才出）
- 连续3章不得各有金句（必须冷却）
- 连续5章以上不出金句才是正常状态

## 五、金句创作的禁区与常见错误

### 5.1 六大禁区

1. **空洞霸气流**：只有气势没有内容。"我是最强的！谁都打不过我！"——这不是金句，是中二喊话
2. **堆砌辞藻流**：用了很多华丽词汇但没有核心。"璀璨星河万古长空无垠大漠苍茫九天……"——读者记不住重点
3. **万能通用流**：放在任何角色身上都成立。"我永远不会退缩"——没有角色辨识度
4. **强行押韵流**：为了押韵牺牲语义。"我心如铁意志坚，天地之间任我翩"——像打油诗
5. **过度堆叠流**：一句话塞了太多信息。"我以我血我剑我命我魂守护这苍生万世不灭的誓言"——需要断句和节奏
6. **时机错位流**：在日常场景突然来一句霸气的——读者会尴尬而不是燃

### 5.2 修改前 vs 修改后示例

| 修改前（❌） | 修改后（✅） | 问题诊断 |
|-------------|-------------|---------|
| "我是天下第一，谁都不如我" | "天下英雄入我眼，不过草芥" | 原句空洞直白；改后有意象+态度 |
| "我要变强保护所有人" | "从今往后，我身后的人，谁都不用再低头" | 原句是愿望不是金句；改后有画面+承诺 |
| "这个天地，由我来主宰" | "天道不仁，我便替天行道；苍生有劫，我以一身当之" | 原句是反派套话；改后有对立+立场+担当 |
| "我的剑很厉害，能杀很多人" | "一剑在手，管他仙魔神佛，来一个杀一个，来两个杀一双" | 原句无节奏无气势；改后有递进+态度 |

## 六、语料库（经典金句素材索引）

> ⚠️ **严重警告**：以下金句仅用于学习修辞结构和激发灵感，**严禁任何形式的照搬、套用、换字改写**。
> 
> 这些金句已与原作深度绑定，读者看到类似结构会立刻联想到原作。如果写出来的东西跟它们"撞脸"，等同于抄袭翻车。
> 
> 正确用法：学金句的**修辞手法**（对仗、递进、反差），然后用自己的角色信息、自己的意象、自己的节奏去**原创**全新的句子。

### 6.1 按类型分类的标杆金句

**霸气宣言类**：
- "杀到世间无人敢称尊"——《完美世界》（极简极致）
- "亿万生灵为兵，百万神魔为将，待到逆乱阴阳时，以我魔血染青天"——《神墓》（排比+终极宣言）
- "赤锋矛，不朽盾，斩尽仙王灭九天！仙之巅，傲世间，有我安澜便有天！"——《完美世界》（意象堆叠+绝对自信）

**天地对立类**：
- "仙路尽头谁为峰，一见无始道成空"——《遮天》（时空对立+角色定义）
- "若天压我，劈开那天；若地拘我，踏碎那地"——《悟空传》（反抗+对仗）
- "天不生我李淳罡，剑道万古如长夜"——《雪中悍刀行》（假设+时空极致）

**身份悖论类**：
- "你本是该咆哮世间的怪物，却非要收敛爪牙做个废物"——《龙族》（巨大反差）

**排比递进类**：
- "我陈平安，唯有一剑，可搬山，断江，倒海，降妖，镇魔，敕神，摘星，摧城，开天"——《剑来》（单一载体+极致递进）

**时空跨越类**：
- "三十年河东，三十年河西，莫欺少年穷"——《斗破苍穹》（时间跨度+命运翻转）

**诗意宣言类**：
- "笑望沧溟千军破，策定乾坤算因果。无觉无惧轻生死，非鬼非神似疯魔"——《惊悚乐园》（四句诗+四层态度）

### 6.2 金句常用意象库

**天象类**：苍穹、九天、凌霄、天道、天渊、星河、日月、雷霆、风云
**地理类**：山河、乾坤、沧溟、四海、八荒、三界、九州、万里
**时间类**：万古、千秋、万世、长夜、亘古、洪荒、岁月、流年
**兵器类**：剑、刀、枪、拳、笔、棋、琴、钟、印
**动作类**：斩、碎、踏、裂、焚、碾、破、断、灭、开、定、染
**身份类**：仙、魔、神、佛、圣、王、帝、尊、主、君
**情感类**：血、骨、泪、笑、狂、疯、傲、痴、念、诺

## 七、金句创作执行流程（写作时使用）

### Step 1：判断是否需要金句
- 当前场景是否在「金句植入时机矩阵」中？
- 本章金句配额是否还有余量？
- 如果两者都满足 → 继续

### Step 2：确定金句参数
```
- 金句类型：从六大结构中选择最匹配的
- 角色气质：对照「角色类型→金句风格对照表」
- 情感锚点：这句金句承载的核心情感/态度是什么？
- 场景上下文：前因后果是什么？金句出现前后各是什么情绪？
```

### Step 3：生成候选句（至少3个候选）
- 按选定的结构类型和模板，生成3个以上候选句
- 每个候选句必须通过四维测试的初步筛选
- ⚠️ 每个候选句必须通过「3.5原创性查重测试」的五维清单逐条自检，命中任意一条直接废弃

### Step 4：选择与打磨
- 从候选中选最优的1句
- 打磨节奏：读出声，感受韵律
- 检查是否与角色气质匹配
- 检查是否与前文情绪衔接自然
- 检查是否能在独立传播时仍有力量
- ⚠️ 最终原创性复核：将选定的金句与第六节「标杆金句」对照，确认骨架、意象、节奏、语义均无撞车
- ⚠️ 核心词汇来源检查：确认金句中的核心词汇来自角色独有经历/能力/信念，而非公共意象库的随意组合

### Step 5：上下文铺垫
- 金句出现前，必须有足够的「势」的铺垫（至少2-3段的情绪/紧张度递进）
- 金句出现时，要有「停顿感」（前后用短句或留白包围）
- 金句出现后，要有「回响」（其他角色的反应/环境的变化/叙事节奏的变化）
