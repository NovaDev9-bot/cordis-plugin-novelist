## 1. 核心规则：弧光挂钩主线任务

角色弧光**必须挂钩主线任务**（见 conflict-engine.md）。

- 主角的核心缺陷**不是随便选的性格缺点**，而是**阻碍完成主线任务的内在障碍**。
- 弧光的本质：主角为了完成主线任务，被迫面对并改变自己的核心缺陷。
- 反例：主角"怕黑"但主线是"商战复仇" → 怕黑与主线无关，弧光不成立。应改为"过度信任熟人"这类直接害他失败的内在缺陷。

## 2. 六段弧光（锚定章节区间）

| 段 | 位置 | 状态 |
|---|---|---|
| 舒适区 | 开篇 | 缺陷在日常中运转，主角不觉得有问题 |
| 触发事件 | 1–3 章 | 主线任务出现，缺陷首次造成失败/代价 |
| 抗拒与挣扎 | 前期 | 主角试图用旧方式解决新问题，反复碰壁 |
| 中点转向 | 中段 | 一次重大打击迫使主角承认缺陷，开始尝试改变 |
| 蜕变考验 | 后期 | 主角用新方式面对最终挑战，旧我与新我交战 |
| 整合 | 结局 | 缺陷被整合而非消灭，主角以新状态完成主线任务 |

> 关键：缺陷被**整合**而非消灭。主角不是变成完人，而是学会与缺陷共处并带它完成任务。

## 3. 角色声音档案（语言 DNA）

每个主要角色建立独立语言 DNA 档案，确保全书对话"蒙名可辨"：

- **用词偏好**：高雅/口语/粗犷；是否有口头禅
- **句式节奏**：长句控诉型 / 短句硬汉型 / 碎句犹豫型
- **禁忌话题**：哪个角色绝不会提某类事（泄露即 OOC）
- **压力下的语言变化**：被逼急时语速/用词如何变
- **撒谎时的语言特征**：眼神？结巴？过度解释？还是面不改色编得更圆？

## 4. 与章节拆解表挂钩

在 novel-chapter-breakdown-v*.md 的「角色变化」维度，标注本章推进了六段弧光中的哪一段。若某章涉及弧光节点，必须在章纲「弧光节点」字段写明对应段名。
