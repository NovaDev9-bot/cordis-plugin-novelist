## 渠道含金量排序（采集优先级）

| 级别 | 渠道 | 为什么可信 |
|------|------|----------|
| **S·最硬** | 改编信号（短剧/剧集/有声/动画改编新闻与官宣） | 被改编=市场已验证它爆，且是公开可交叉验证的新闻；2025-2026短剧改编是网文头部变现主战场 |
| **A·高** | 平台官方榜/权威媒体行业盘点（番茄畅销榜、起点月票榜、晋江积分榜的公开报道） | 官方或权威背书 |
| **B·中高** | 行业媒体/出版机构的年度榜单文章 | 有编辑筛选 |
| **C·中** | 社媒追捧数据（微博话题、抖音/小红书话题播放量与笔记量、读者讨论密度） | 真实热度信号，但需防营销刷量 |
| **D·低（仅辅证）** | 单一论坛帖、来源不明的聚合站、疑似营销软文 | 不可单独采信 |

> **关键认知**：番茄/起点 App 内的实时榜很多不被搜索引擎索引。因此本引擎靠"**改编新闻 + 媒体盘点 + 社媒热度**"三路实采交叉验证，**不假装能直连 App 内部实时榜**。

## 五段式管线

### 第0段·分流
- **场景A（用户指定题材/方向）**：定向采"同类·近半年"爆款 → DNA作为该方向当前最优解
- **场景B（用户没想法）**：宽口径采当前爆款 → 蒸馏后种草3方向给用户选，每方向附"为什么现在会爆"的真实依据

### 第1段·多路实采（限定时间窗）
按渠道含金量从S到C多路搜，每路记录来源URL与发布时间：
1. **改编线（S级优先搜）**：`[题材]改编短剧 2026`、`[题材]爆款小说 影视化`、`番茄/起点 短剧改编 上半年`
2. **榜单线（A/B级）**：`番茄小说畅销榜 [题材] 2026`、`起点月票榜 上半年`、`晋江[题材]榜 2026`、`[题材]网文 年度盘点`
3. **社媒线（C级）**：`[书名] 微博话题`、`[题材]小说 抖音`、`[书名] 小红书 讨论`
- 时间窗：近半年爆款锁6个月；半爆款/今年爆款锁当年
- 用户指定题材→全部查询拼接该题材；用户没想法→查询当前全平台热门题材

### 第2段·真实性核验（本引擎的灵魂，不可省）
对第1段抓到的每一本，过四道核验：
1. **交叉验证门**：同一书名必须在 **≥2个独立来源**出现才采信；仅单一来源→进"存疑区"，不进DNA
2. **可信度分级**：按渠道表给每本标 `[来源数 × 最高可信级]`，如`[3来源×S级]`
3. **在榜≠爆款门**：必须有**追捧数据支撑**（订阅/月票/收藏增速/话题量级/明确改编），只是"出现在某文章列表里"不算爆款
4. **反幻觉硬门**：书名、数字、排名、改编信息**逐项要有来源**；任一项无来源即丢弃该数据点（不是丢整本，是丢无源的那个字段）
- 核验产出：**核验通过清单**（可进DNA）+ **存疑区**（来源不足，标注待补）
- 若整体搜不到可信数据：**如实告知用户"实时未检索到足够可核验的爆款数据"**，不编造

### 第3段·DNA蒸馏（爆的理由 + 多路DNA）
对每本核验通过的爆款，提两层：

**A. 为什么爆 / 为什么被改（"原因"层）**
- 核心钩子是什么、戳中什么情绪红利、踩中什么题材时机、付费/追读结构如何设计
- 若被改编：改编方看中它什么（强冲突/强人设/强场景/话题性）

**B. 多路DNA（"元素"层）**
- 题材组合 / 黄金开局写法 / 核心爽点范式 / 情绪锚点 / 节奏特征 / 人设标签 / 书名公式 / 封面风格

**C. 跨本比对**
- 多本共性 = 当前赛道红利方向（应跟）
- 本本差异/空白 = 创新空隙（可抢）

### 第4段·与用户需求 + 自进化数据融合
- **场景A**：DNA作为"该方向当前最优解"喂给步骤2/3创作
- **场景B**：用核验后的爆款生成**3个方向种草卡**（每卡：方向名 + 一句话卖点 + 为什么现在会爆的真实依据 + 来源可信度），喂给步骤1.2，用户选
- **叠加自进化（关键）**：调用 self-evolution-engine 通道②的该用户跨作品偏好，对DNA做**过滤/加权**——
  - 用户已知厌恶项（如讨厌第一人称/讨厌虐文）→ 即便爆款普遍如此也自动避开
  - 用户已验证偏好（如偏好快节奏）→ 优先选同特征的DNA
  - 让"行业爆款共性"与"这个用户的个性"合流，而非盲从榜单

## 输出契约（喂给下游）
- **给步骤1.2种草**（场景B）：3方向种草卡，每卡带真实依据与来源可信度标注
- **给步骤2/3创作**：核验通过的DNA清单（原因层+元素层+跨本比对），作为本赛道当前红利参考
- **存疑区**：单独保留，不参与创作，必要时告知用户"这些待进一步核实"

## 安全与边界
- 不抓取、不复制爆款正文原文（版权）；只蒸馏方法论层面的DNA
- 不编造书名/数据/排名；无源即弃
- 社媒热度数据警惕营销刷量，需多路印证
- 真实性存疑时如实告知，把判断权交还用户
