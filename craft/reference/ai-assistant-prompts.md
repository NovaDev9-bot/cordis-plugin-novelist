## 一、大纲策划提示词

### 1.1 短篇小说大纲生成

```markdown
你是一位深谙知乎盐言故事模式的顶级网文策划。请为我构思一个具有高付费潜力的短篇故事大纲。

【故事定位】
- 核心类型：[填入：现代言情/都市职场/悬疑/重生复仇]
- 核心冲突：[填入一句话冲突，如：女主重生后向前世背叛自己的闺蜜和丈夫复仇]
- 主角设定：[填入核心人设，如：表面人畜无害实则手腕狠毒的职场新人]
- 目标读者：[填入读者画像，如：渴望看到主角智商在线、节奏明快、有仇必报的年轻女性]

【大纲要求】
1. 总章节：15-20章，预估5-8万字
2. 开篇钩子（第1-2章）：前1000字内制造强烈悬念或冲突
3. 爽点布局：每1-2章设计一个明确的"爽点"或"打脸"情节
4. 节奏控制：情节推进迅速，每章结尾留小钩子
5. 付费节点（关键）：在免费章节最后一章（第3或4章）设计极致悬念
6. 高潮与结局：所有伏笔回收，情绪极大满足

【输出格式】
以"章节序号：一句话核心内容 + 本章爽点/悬念"格式输出
```

### 1.2 长篇小说大纲生成

```markdown
你是一位资深网文编辑，请为我设计一个长篇网文的大纲框架。

【基本信息】
- 题材：[填入：玄幻/仙侠/都市/历史]
- 核心卖点：[填入核心吸引力]
- 主角人设：[填入主角标签]
- 预计字数：[填入：100万字/300万字/500万字]

【结构要求】
1. 使用"七步法"设计主线：目的→阻碍→行动→结果→意外→高潮→结局
2. 分卷规划：按"升级地图"划分3-5个阶段
3. 每卷包含：核心目标→关键反派→爽点事件→伏笔回收
4. 节奏控制：3章小高潮、10章大转折、30章大高潮

【输出格式】
1. 一句话卖点
2. 三幕式结构概览
3. 分卷大纲（每卷包含5-10个关键节点）
4. 主要人物关系图
5. 核心伏笔清单
```

## 二、黄金开头提示词

### 2.1 知乎盐选风格开头

```markdown
你是一位知乎盐选故事写手，擅长用极具张力的文字在开篇抓住读者。

【故事设定】
- 背景：[填入：如一场豪门晚宴上]
- 主角：[填入：如我是被众人嘲笑的假千金，刚刚重生回来]
- 核心事件：[填入：如未婚夫当众宣布要和我退婚]

【写作要求】
1. 开篇3句话内出现冲突或反常
2. 使用第一人称，带身体反应（如手抖、心跳）
3. 禁用静态介绍（如"我叫XX，今年XX岁"）
4. 制造信息差（如重生者视角）
5. 结尾埋钩子（让读者想问"接下来呢"）
6. 字数控制在1500字左右

【风格参考】
- 盐选风格：快节奏、强情绪、信息密度高
- 黄金三章：300字入戏+1500字推进+200字钩子

请开始创作第一章。
```

### 2.2 网文黄金三章开头

```markdown
你是一位网文大神，请为我创作小说前三章，要求符合"黄金三章"法则。

【故事设定】
- 题材：[填入题材]
- 主角：[填入主角身份]
- 金手指：[填入金手指设定]
- 初始冲突：[填入第一章核心冲突]

【黄金三章要求】
第一章（入戏）：
- 300字内：主角身份+当前困境+核心冲突
- 展示主角性格特点
- 结尾埋钩子

第二章（推进）：
- 触发首个爽点（打脸/突破/获得）
- 引入金手指或金手指觉醒
- 展示世界规则

第三章（钩子）：
- 小高潮或反转
- 新人物登场或新危机出现
- 付费卡点悬念（如果是付费章节）

【每章结构】
- 开篇：直接切入冲突
- 中段：推进+小反转
- 结尾：钩子

请输出前三章内容。
```

## 三、人设生成提示词

### 3.1 无CP大女主人设

```markdown
请为我设计一个无CP大女主的人设。

【基本要求】
- 核心驱动力：[填入：事业/复仇/成长]
- 故事背景：[填入：古代/现代/末世]
- 能力方向：[填入：商业/武力/智谋/医术]

【人设要素】
1. 外在标签（3-5个）：外貌、服饰、道具、习惯性动作
2. 能力特长：核心技能+专业程度
3. 性格特征：表面+内在+反差
4. 背景故事：关键经历+情感创伤+成长动机
5. 人际关系：盟友+对手+反派
6. 成长弧光：起点→转折点→终点

【输出格式】
- 一句话人设定位
- 详细人设卡（上述6个要素）
- 3个标志性场景示例
- 与其他角色的互动模式
```

### 3.2 狠女+真实情感人设

```markdown
请为我设计一个"狠女+真实情感"的立体人设。

【基本要求】
- 狠的类型：[填入：毒医/杀手/权臣/黑莲花]
- 表面特征：[填入：冷漠/疯批/笑里藏刀]
- 真实情感内核：[填入：被背叛/孤独/责任重压]

【人设要素】
1. 强标签设计：外貌+能力+性格+身份
2. 狠的外在表现：对待敌人+处理问题+行为习惯
3. 真实情感创伤：过去经历+心理阴影+防御机制
4. 柔软时刻触发条件：特定对象+特定场景+特定行为
5. 成长线：从完全封闭→逐渐敞开心扉

【输出格式】
- 人设标签云
- 外在狠厉的具体表现（5个场景）
- 内在柔软的触发点（3个场景）
- 经典台词（5句）
- 与其他角色的化学反应
```

### 3.3 专业流人设

```markdown
请为我设计一个专业流男主/女主的人设。

【基本要求】
- 专业领域：[填入：法律/医学/刑侦/金融/编程]
- 应用场景：[填入：穿越古代/现代职场/悬疑探案]
- 专业水平：[填入：业内顶尖/天才新人/经验丰富]

【人设要素】
1. 专业背景：学历+从业经历+代表作品/案例
2. 核心能力：专业技能+独特方法论+标志性技术
3. 行业地位：同行评价+社会地位+影响力
4. 知识展示场景：3个典型场景展示专业能力
5. 专业与剧情的结合：如何用专业推动剧情

【输出格式】
- 专业履历表
- 3个知识展示场景详细设计
- 专业术语词汇表（20个核心术语）
- 行业内幕/潜规则（3-5条）
- 用专业能力打脸的场景设计（3个）
```

## 四、章节续写提示词

### 4.1 续写单章

```markdown
请根据已有内容续写下一章。

【前文概要】
[粘贴前文关键情节]

【本章任务】
- 章节定位：[填入：铺垫/推进/高潮/转折]
- 核心事件：[填入本章要发生的事]
- 情绪目标：[填入：压抑/释放/悬疑/爽感]
- 结尾钩子：[填入留给下章的悬念]

【写作要求】
1. 承接前文逻辑，不突兀
2. 字数控制在2000-3000字
3. 每500字一个小推进
4. 结尾必须留钩子
5. 符合整体风格和节奏

【输出格式】
直接输出章节正文。
```

### 4.2 批量生成细纲

```markdown
请为已有大纲批量生成章节细纲。

【整体大纲】
[粘贴整体大纲]

【当前卷】
- 卷数：第X卷
- 核心任务：[填入本卷核心目标]
- 章节数：[填入本章节目数，如10章]

【细纲要求】
每章包含：
1. 章节标题
2. 一句话核心内容
3. 出场人物
4. 核心冲突/事件
5. 爽点/情绪点
6. 结尾钩子
7. 伏笔（埋设/回收）

【输出格式】
第X章：
- 标题：
- 内容：
- 人物：
- 冲突：
- 爽点：
- 钩子：
- 伏笔：
```

## 五、短剧改编提示词

### 5.1 短剧改编方案

```markdown
请为现有小说设计短剧改编方案。

【小说信息】
- 小说名称：[填入]
- 核心卖点：[填入]
- 总章节数：[填入]
- 主要人物：[填入]

【改编要求】
1. 集数规划：30集/60集/90集
2. 每集时长：1-3分钟
3. 付费卡点：第3、6、9...集
4. 改编重点：强视觉场景+情绪爆点+反转节点

【输出内容】
1. 短剧卖点提炼（一句话）
2. 分集大纲（每集包含：场景+冲突+反转+钩子）
3. 强视觉场景设计（5个）
4. 付费卡点详细设计
5. 演员人设标签（便于选角）
6. 经典台词提炼（10句）
```

## 六、使用建议

### 6.1 提示词使用流程
1. **复制模板**：复制对应场景的提示词
2. **填空内容**：将方括号[]内容替换为具体信息
3. **发送AI**：发送给AI工具（ChatGPT/Claude等）
4. **人工筛选**：从AI生成结果中筛选可用内容
5. **精修打磨**：人工修改，注入灵魂

### 6.2 注意事项
- AI生成内容是参考，不是最终稿
- 必须人工检查逻辑一致性
- 避免直接使用AI生成的套路化内容
- 保持个人创作风格

### 6.3 推荐AI工具
- **ChatGPT**：通用创作辅助
- **Claude**：长文本处理能力强
- **文心一言**：中文语境理解好
- **通义千问**：网文场景优化较好
