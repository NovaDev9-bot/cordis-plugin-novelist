## 1. 题材承诺 — 女频爽文承诺了什么爽

### 核心爽感类型

| 类型 | 承诺爽点 | 代表题材 |
|------|----------|----------|
| **逆袭翻盘** | 从被欺压到掌控命运 | 重生复仇、穿书女配逆袭、假千金真千金 |
| **认知碾压** | 主角知道读者也知道的信息差 | 重生预知、穿书剧本、弹幕吐槽 |
| **情感补偿** | 被爱、被珍惜、被坚定选择 | 先婚后爱、追妻火葬场、男二上位 |
| **能力彰显** | 智慧/医术/马甲碾压对手 | 马甲文、系统锦鲤、大女主搞事业 |
| **情绪宣泄** | 发疯、怼人、不憋屈 | 癫文、发疯文学、反套路爽文 |

### 具体可执行技巧

1. **开篇即承诺核心爽点**：标题/导语必须出现核心矛盾（如"被休后我带着三个缩小版反派逆袭了"），让读者0.5秒内决定是否点开
2. **爽点前置原则**：番茄平台300字内出冲突，第一章必须有核心冲突爆发点
3. **差异化承诺**：同类型题材要找微创新点，如"女主不靠男人，只靠自己去打破困境"（《我于深渊时见你》）
4. **情绪痛点精准命中**：
   - 女性身份困境（生育焦虑、职场歧视、婚姻依附）
   - 情感背叛创伤（渣男出轨、闺蜜挖墙脚）
   - 原生家庭压迫（扶弟魔、重男轻女）
5. **2025-2026新兴承诺**：
   - "反雌竞"（女性互助而非雌竞）
   - "清醒搞钱"（事业脑取代恋爱脑）
   - "极致反差"（疯批但有底线、腹黑但有逻辑）

## 2. 开头抓手 — 黄金三章/黄金300字技巧

### 三章结构公式

| 章节 | 核心任务 | 关键动作 |
|------|----------|----------|
| **第一章** | 绝境虐点拉满 | 女主被按在最惨境地，10行内抓住读者 |
| **第二章** | 亮底牌反击 | 身份曝光/金手指激活，打脸第一个反派 |
| **第三章** | 埋钩引新冲突 | 留悬念，让读者忍不住点下一章 |

### 300字黄金开头模板

**模板1：冲突前置型**
```
开篇1-5行：女主绝境（被背叛/被羞辱/被陷害）
开篇6-10行：雪上加霜+伏笔
伏笔方向：女主隐藏身份、神秘人脉、金手指线索
```

**模板2：身份落差型**
```
"我嫁入豪门三年，做了顾少三年的替身，
今天他带着白月光回国，当众撕碎我的婚书：
'苏晚，你连她的一根头发都比不上，滚出顾家'"
```

**模板3：钩子悬念型**
```
"她冷笑一声：'这婚，我不替了'"
"推开门的瞬间，她看清了里面的人——"
"直到后来她才知道，那天晚上救她的人是谁"
```

### 具体可执行技巧

1. **严禁**：大段背景介绍、景物描写、慢热铺垫
2. **必须**：每段≤3行，短句为主，对话独立成行
3. **黄金法则**：第一章前500字必须出现核心冲突（穿书死亡结局/捉奸在床/收到离婚协议/被逼替嫁）
4. **代入感构建**：用"第二人称你"或"我"的直接叙述，而非旁白介绍
5. **情绪启动**：第一句话就要让读者产生"代入愤怒"或"代入心疼"

## 3. 读者债设计 — 如何让女读者走不了

### 债务类型

| 债务类型 | 触发机制 | 读者心理 |
|----------|----------|----------|
| **仇恨债** | 反派欺负女主，读者想看打脸 | "她怎么还不反击？！" |
| **好奇债** | 埋下悬念，读者想知道答案 | "到底是谁？" |
| **情感债** | 男女主有张力，读者想看在一起 | "他们什么时候和好？" |
| **命运债** | 主角命运未卜，读者想看结局 | "她会死还是会活？" |
| **认知债** | 智斗/推理，读者想验证猜测 | "我想到了！作者怎么写的？" |

### 具体可执行技巧

1. **第一章埋长线钩子**：恶毒女配/渣男欺负女主，这是"长线债务"，能让读者忍耐很多章只为看反派粉身碎骨
2. **每章埋短线钩子**：白衣身影是谁/神秘人身份/金手指何时激活，驱动读者立刻点下一章
3. **制造"认知缺口"**：
   - 女主知道反派要陷害她，读者不知道她如何反击
   - 读者和女主同时看到反转，比女主单独知道更有爽感
4. **情感债务叠加**：
   - 先婚后爱的拉扯感（他爱她但嘴硬）
   - 追妻火葬场的酸涩（她心死了他才后悔）
   - 男二上位的期待（男二温柔守护）
5. **"看到停不下来"的物理机制**：
   - 一章故事只写80%，结果放在下一章
   - 主角被追杀→技能爆发→本章结束，威力如何下一章见
   - 主角拿起证据走向会场→推开门那一刻→本章结束

## 4. 推进引擎 — 复仇/逆袭/甜宠的驱动力

### 三大引擎类型

| 引擎 | 驱动力来源 | 爽感来源 |
|------|------------|----------|
| **复仇引擎** | 仇恨/不甘/前世遗憾 | 以彼之道还施彼身，恶有恶报 |
| **成长引擎** | 能力提升/地位跃迁 | 从被轻视到被仰望 |
| **情感引擎** | 爱意萌发/追妻火葬场 | 上位者低头/被坚定选择 |

### 具体可执行技巧

1. **复仇引擎设计**：
   - 仇人必须有具体恶行（杀害家人/夺走一切），不能只是态度不好
   - 复仇手段要有智谋感（将计就计/借刀杀人/舆论反杀），而非单纯金手指碾压
   - 复仇节奏：3章一小爽（打脸小喽啰），10章一大爽（打脸大BOSS）
2. **成长引擎设计**：
   - 技能必须有前置铺垫，不能"突然开挂"
   - 成长路径可视化：丫鬟→管事→当家主母
   - 马甲层层掉落，每掉一层爽一次
3. **情感引擎设计**：
   - 拉扯期必须有具体事件（他帮她挡了一次暗算/她看到他藏起来的礼物）
   - 追妻火葬场：男主前期越冷漠，后期追妻的反差爽感越强
   - "男二上位"：温柔男二的存在让读者对男主产生危机感
4. **复合引擎**：《恶毒女配，带残疾老公杀疯了！》展示从离婚→合作逆袭→破镜重圆的复合路径，每阶段都有新看点

## 5. 情绪波形 — 爽感节奏设计

### 情绪波形公式

```
压抑期(30%) → 蓄力期(20%) → 爆发期(10%) → 余韵期(10%) → 新的压抑期(30%)
```

### 具体可执行技巧

1. **高位女主（嫡女/公主/主母）**：
   - 减少迂回试探，多用阶级差/权力差直接碾压
   - 爽点间隔≤300字，满足及时爽感体验
2. **底层逆袭女主**：
   - 侧重智斗，用将计就计、借刀杀人替代蛮力
   - 突出"以弱胜强"的智力爽感
3. **情绪释放节奏**：
   - 每3章一个小高潮（掌嘴丫鬟/怒怼亲戚）
   - 每10章一个大反转（身份曝光/真相揭露）
4. **"甜虐交织"法则**：
   - 甜后必有小虐（甜蜜时刻突然发现危机）
   - 虐后必有大甜（女主反击后男主心疼/守护）
5. **番茄平台特殊要求**：
   - 节奏快（3章1小高潮、10章1大反转）
   - 情绪正向，拒绝冗长铺垫
   - 轻爽点、解压无虐是主流

## 6. 奖励类型分布 — 爽感的分层配比

### 奖励金字塔

| 层次 | 奖励类型 | 出现频率 | 爽感强度 |
|------|----------|----------|----------|
| **顶层** | 终极目标达成（复仇成功/登顶权势/真爱相守） | 1次（高潮/结局） | ★★★★★ |
| **中层** | 中期胜利（打脸大反派/身份曝光/感情突破） | 每10-20章 | ★★★★ |
| **底层** | 即时奖励（打脸小喽啰/被夸赞/小恩小惠） | 每3-5章 | ★★★ |
| **点缀** | 微小成就（获得物品/解决小问题） | 随时穿插 | ★★ |

### 具体可执行技巧

1. **即时奖励（每500字1个小爽点）**：
   - 反派说了难听话→主角用聪明话怼回去
   - 获得一个新物品/认识一个新盟友
   - 被人认可/夸奖/刮目相看
2. **中期奖励（每章1次打脸/逆袭）**：
   - 掌嘴丫鬟、怒怼亲戚
   - 身份曝光、实力展示
   - 感情突破、牵手/亲吻/表白
3. **终极奖励**：
   - 复仇完成/渣男下场凄惨
   - 事业大成/年薪千万/公司上市
   - 有情人终成眷属/幸福结局
4. **奖励密度公式**（番茄平台）：
   - 每500字1个小爽点
   - 每章1次打脸或逆袭
   - 每10章1次大反转

## 7. 节奏配比 — 压抑/爆发/铺垫的精确比例

### 黄金比例

| 阶段 | 字数占比 | 内容 |
|------|----------|------|
| **压抑铺垫** | 40% | 女主被打压、被轻视、被欺负 |
| **蓄力反击** | 30% | 女主暗中准备、收集证据、等待时机 |
| **爆发打脸** | 20% | 反击、反杀、爽感释放 |
| **余韵回味** | 10% | 反派崩溃/旁观者震惊/下一个小目标出现 |

### 具体可执行技巧

1. **压抑期技巧**：
   - 反派必须嚣张到令读者愤怒的程度
   - 女主必须看起来毫无胜算
   - 加入"帮凶"（不明真相的旁观者指责女主）增加憋屈感
2. **蓄力期技巧**：
   - 女主私下行动读者可见（"她没有哭，而是……"）
   - 埋下伏笔（金手指线索/盟友出现/证据收集）
   - 保持紧张感（反派随时可能再次出手）
3. **爆发期技巧**：
   - 打脸必须精准（针对反派之前的嘲讽一句句还回去）
   - 旁观者反应必须写（"所有人都愣住了"）
   - 留一个小尾巴（更大的危机/更深的水）
4. **时间节奏**（番茄平台）：
   - 古代背景：每章推进一件事
   - 现代背景：快节奏、碎片化、多事件
   - 年代文：田园牧歌+女主搞事业

## 8. 结构公式 — 可复用叙事结构

### 七大经典结构

| 结构 | 适用题材 | 核心公式 |
|------|----------|----------|
| **破-立-掌-治** | 大女主权谋 | 破旧我→建基业→掌权力→定秩序 |
| **绝境-激活-逆袭-掌控** | 重生复仇 | 回到过去→激活金手指→打脸仇人→新人生 |
| **认错-追-挽回-在一起** | 追妻火葬场 | 她离开→他后悔→追妻→HE |
| **暗恋-试探-表白-在一起** | 甜宠文 | 她喜欢他→各种试探→表白→撒糖 |
| **被欺负-反击-再欺负-再反击** | 逆袭打脸 | 压抑→爆发→更大压抑→更大爆发 |
| **谜团-线索-推理-真相** | 女性悬疑 | 案发→调查→推理→真相揭露 |
| **层层剥洋葱** | 马甲文 | 掉一个马甲→新谜团→再掉→真相大白 |

### 具体可执行技巧

1. **大女主"破-立-掌-治"公式**（以《重生之再嫁》为例）：
   - 破（1-15章）：以重生为刃，斩断旧我
   - 立（16-73章）：以庶女为盾，构筑基业
   - 掌（74-226章）：以智谋为剑，执掌全局
   - 治（227-285章）：以天下为局，定义秩序
2. **重生复仇"三层爽"公式**：
   - 第一阶段：器物层爽（打具体人）
   - 第二阶段：制度层爽（改规则）
   - 第三阶段：哲学层爽（重新定义价值）
3. **宫斗宅斗"七幕剧"公式**（以《重生后，嫡长女她稳拿复仇剧本》为例）：
   - 第1-3章：死亡-重生-立威
   - 第4-7章：器物破局
   - 第8-11章：语言博弈
   - 第12-14章：空间夺权
   - 第15-17章：社交升维
   - 第18-19章：符号重构
   - 第20章：价值确认

## 9. 主角承诺 — 女频主角人设的爽感锚点

### 人设标签体系

| 标签类型 | 正面标签 | 负面标签（需反转） |
|----------|----------|-------------------|
| **性格** | 清醒独立、杀伐果断、黑莲花 | 软包子（需觉醒） |
| **能力** | 马甲大佬、神医、黑客 | 废柴（需逆袭） |
| **身份** | 真千金、嫡女、公主 | 假千金、庶女（需翻盘） |
| **处境** | 被抛弃、被背叛 | 隐忍（需爆发） |

### 具体可执行技巧

1. **核心标签必须明确**：
   - 女主人设要有1个核心标签（清醒独美/黑莲花/扮猪吃虎）
   - 避免"什么都沾一点"导致人设模糊
2. **反差感是爽感来源**：
   - 高冷掌权者偏爱甜食
   - 底层复仇者性格温柔
   - 女强人怕毛毛虫
   - 杀伐果断者对男主心软
3. **2025-2026人设新趋势**：
   - "清醒搞钱"：事业脑取代恋爱脑
   - "发疯但有底线"：与其精神内耗自己，不如发疯外耗别人
   - "不靠男人"：没有男主依然闪闪发光
   - "女性互助"：女主帮女主，反派也可能被洗白
4. **人设避坑**：
   - 不可写"圣母"（被欺负了不反击）
   - 不可写"恋爱脑"（为了男人放弃一切）
   - 不可写"拖后腿"（需要其他角色救）
5. **马甲设计**：
   - 每掉一层马甲爽一次
   - 身份曝光→打脸围观者→下一个小目标
   - 常见马甲：神医、黑客、设计师、隐藏千金

## 10. 金手指机制 — 重生/穿越/系统如何服务女频爽感

### 金手指类型与爽感对应

| 金手指类型 | 核心爽感 | 服务题材 |
|------------|----------|----------|
| **重生预知** | 信息差碾压 | 复仇文、豪门文 |
| **系统任务** | 目标明确、奖励即时 | 逆袭文、搞事业文 |
| **空间物资** | 解决困境、发财致富 | 年代文、种田文 |
| **技能系统** | 专业能力碾压 | 职场文、神医文 |
| **弹幕吐槽** | 读者视角参与、认知同步爽感 | 穿书文 |
| **读心术/鉴渣眼** | 识破伪装、一眼看穿 | 豪门文、宫斗文 |

### 具体可执行技巧

1. **金手指设计原则**：
   - 必须"易懂"：不能用玄学/模糊设定
   - 必须"直接"：效果可视化，读者能看懂
   - 必须"服务剧情"：不是开挂碾压，而是解决核心矛盾
2. **重生金手指运用**：
   - 女主识人不清→特定复仇对象→复仇目标
   - 直接点明前世关键遗憾+今生复仇目标
   - 快速推进剧情，方便读者入戏
3. **系统金手指运用**：
   - 任务目标清晰（赚够100万/攻略5个人）
   - 奖励即时可见（技能/物品/属性提升）
   - 失败惩罚明确（生命威胁/属性下降）
4. **信息差金手指运用**：
   - 穿越女/穿书女知道剧情走向
   - 利用信息差设局/反杀
   - 读者和女主同步知道，形成"认知同步爽感"
5. **2025-2026金手指新玩法**：
   - 《捡漏穿越女不要的系统签到奖励》：穿越女选什么，主角就捡剩下的
   - 锦鲤系统/鉴渣系统等轻量化系统

## 11. 世界升级逻辑 — 从受压迫到翻身的路径设计

### 升级路径类型

| 路径类型 | 起点 | 中点 | 终点 |
|----------|------|------|------|
| **身份升级** | 庶女/假千金 | 嫡女/真千金 | 当家主母/女帝 |
| **能力升级** | 废柴/普通人 | 有一技之长 | 行业顶尖/大佬 |
| **地位升级** | 被轻视 | 被认可 | 被仰望/被求 |
| **财富升级** | 贫穷 | 小康 | 富甲一方/首富 |
| **情感升级** | 被抛弃 | 被追求 | 被坚定选择 |

### 具体可执行技巧

1. **台阶式升级**：
   - 每个台阶必须有明确标志（事件/成就/身份变化）
   - 台阶之间要有过渡（能力积累/资源积累）
   - 每个台阶要能打一次小爽
2. **身份升级设计**：
   - 穿越/重生→暴露身份一角→被质疑→再暴露→彻底翻盘
   - 每次身份曝光打一次爽
3. **能力升级设计**：
   - 废柴期→遇到师父/系统→学习成长→小试牛刀→大放异彩
   - 能力必须有具体展示场景
4. **世界观的"压迫-翻身"结构**：
   - 压迫源：渣男/恶婆婆/嫡母/制度/社会
   - 反抗方式：智斗/金手指/结盟/自我提升
   - 翻身标志：压迫者下场/女主获得权力/建立新秩序

## 12. 配角功能位 — 渣男/闺蜜/霸总/白月光的戏剧功能

### 配角功能位详解

| 角色类型 | 核心功能 | 爽感来源 |
|----------|----------|----------|
| **渣男** | 提供仇恨/触发愤怒 | 被打脸/下场凄惨 |
| **绿茶闺蜜** | 背叛刺激/雌竞对立 | 反目/看清真面目 |
| **霸总男主** | 爱情线/守护 | 被坚定选择/上位者低头 |
| **白月光** | 对照/刺激 | 真爱曝光/反成笑话 |
| **忠犬男二** | 替代选项/读者期望 | 男二上位/温柔守护 |
| **恶婆婆/嫡母** | 压迫来源 | 被反击/下场凄惨 |
| **金手指系统/师父** | 帮助成长 | 能力提升/获得资源 |

### 具体可执行技巧

1. **渣男设计原则**：
   - 必须有具体恶行（杀家人/夺财产/背叛感情）
   - 必须先嚣张后惨（爽感来自反差）
   - 死法要解气（社会性死亡/众叛亲离/锒铛入狱）
2. **女主闺蜜设计**：
   - 背叛要有铺垫（"她平时对我很好"→反转时更震惊）
   - 背叛理由要合理（嫉妒/利益/被威胁）
   - 看清真相后女主的反应要干脆
3. **男主设计原则**：
   - 前期要"欠"（冷漠/误会/伤害女主）
   - 后期要"还"（追妻/守护/救赎）
   - 追妻火葬场的爽感来自"活该"
4. **男二设计原则**：
   - 温柔守护、始终站在女主身边
   - 增加读者对男主的危机感
   - 男二上位是2025年新趋势
5. **女性配角新趋势**：
   - "反雌竞"：女主和另一个女主联手
   - 恶女洗白：反派有自己的故事线
   - 女性互助：嫡女帮庶女、姐姐护妹妹

## 13. 章节结尾机制 — 每章钩子设计

### 钩子类型与位置

| 钩子类型 | 出现位置 | 效果 |
|----------|----------|------|
| **章首钩** | 每章开头 | 无缝衔接，让读者来不及退出 |
| **章中钩** | 每1000字 | 小悬念锁住阅读视线 |
| **章尾钩** | 每章结尾 | 高潮前停笔，制造追更动力 |

### 具体可执行技巧

1. **章首钩公式**：
   - 精准承接上一章悬念
   - "冰冷的刀锋擦着脖颈划过，身后的脚步声越来越近"
   - 让读者从"悬着"直接跌入"紧张"
2. **章中钩技巧**：
   - 每千字埋一个小钩子
   - 丹炉突然发出异常红光
   - 电脑突然黑屏，弹出陌生警告
   - 戒指盒被撞掉，滚到陌生女人脚边
3. **章尾钩公式**：
   - 停在最揪心、最期待、最未知的瞬间
   - 绝对不能把事情讲完、不能让情绪落地
   - 只留问题，不给答案；只铺线索，不揭真相
4. **章尾钩五大切入点**：
   - 主角陷入必死绝境，刀剑已架脖子（停在抬手反击前）
   - 查到幕后黑手，对方面具被掀开一角（停在看清脸前）
   - 即将逆袭打脸，主角拿起证据走向会场（停在推开门前）
   - 金手指即将升级，能量汇聚（停在生效前）
   - 最信任的人背后捅刀（停在回头看清对方脸前）
5. **钩子避坑**：
   - 不能话只说一半，剧情毫无高潮
   - 不能停在无意义剧情（吃饭/走路/聊天）
   - 不能一章埋十个悬念，十万字不解释

## 14. 连续快感设计 — 爽感不断档技巧

### 快感连续性公式

```
小爽（500字）→ 中爽（3章）→ 大爽（10章）→ 更大爽（20-30章）→ 终极爽（高潮）
```

### 具体可执行技巧

1. **"一环扣一环"设计**：
   - 解决一个问题→立刻出现新问题
   - 打脸一个反派→更大的反派出现
   - 感情甜蜜→突然出现误会/危机
2. **"糖葫芦"结构**：
   - 每3章一个小山头（打一个反派）
   - 每10章翻一座山（解决一个核心问题）
   - 整体是一个更大的山（复仇/登顶/圆满结局）
3. **"甜虐交替"节奏**：
   - 甜2章→虐1章→甜3章→虐1章
   - 每次甜要甜到位（撒糖场景）
   - 每次虐要虐到痛（但不憋屈，要有反击预期）
4. **"悬念叠加"技巧**：
   - 解开一个悬念→立刻抛出新悬念
   - 读者永远有一个"答案"在等着
5. **番茄平台特殊要求**：
   - 3章1小爽、10章1大反转
   - 拒绝冗长铺垫、拒绝憋屈
   - 轻量化、正向情绪是主流

## 15. 信息预算 — 何时透露、何时压住

### 信息释放节奏

| 阶段 | 信息类型 | 释放时机 |
|------|----------|----------|
| **开篇** | 基本设定、女主身份、核心冲突 | 立即释放 |
| **前期** | 敌人是谁、女主困境 | 快速释放 |
| **中期** | 女主的秘密/金手指/能力 | 分层释放（马甲层层掉） |
| **后期** | 最终真相、反派动机 | 集中释放 |
| **高潮** | 女主身份/实力/感情归属 | 完全释放 |

### 具体可执行技巧

1. **信息差设计原则**：
   - 读者知道的 = 女主知道的 = 比反派多一点
   - 这样读者和女主同步爽（认知同步爽感）
2. **马甲掉落节奏**：
   - 第一层：暴露一个小秘密
   - 第二层：暴露一个中等秘密
   - 第三层：暴露核心身份
   - 每掉一层打一次爽
3. **悬念压住技巧**：
   - 反派不知道女主有金手指
   - 男主不知道女主的真实身份
   - 读者知道反派要陷害女主，女主也在布局
4. **信息透露避坑**：
   - 不能一次性全盘托出
   - 不能该解释时不解释（读者一脸懵）
   - 不能解释得太早（失去悬念）
5. **伏笔回收技巧**：
   - 伏笔必须在后文有呼应
   - 早期细节→中后期成为关键线索
   - "看到答案后回头看伏笔"的双重爽感

## 16. 追更燃料 — 什么让女读者每天回来

### 追更驱动力类型

| 驱动力 | 读者心理 | 实现方式 |
|--------|----------|----------|
| **仇恨未消** | "渣男还没死！" | 反派还没被打脸 |
| **悬念未解** | "到底是谁？" | 身份/动机/关系未揭露 |
| **感情未明** | "他们会在一起吗？" | 感情拉扯/三角关系 |
| **命运未知** | "她会怎么应对？" | 主角陷入危机/面临选择 |
| **习惯养成** | "每天就看这个" | 固定更新+情节连续 |

### 具体可执行技巧

1. **仇恨驱动**：
   - 反派的恶行要具体、可恨
   - 打脸要有铺垫，让读者"憋着气等"
   - 第一次打脸不能太爽（留更大的仇）
2. **悬念驱动**：
   - 身份悬念：她到底是谁？
   - 动机悬念：她为什么要这么做？
   - 关系悬念：他爱她吗？她爱他吗？
3. **感情驱动**：
   - 先婚后爱的拉扯
   - 追妻火葬场的酸涩
   - 男二上位的可能性
4. **更新机制**：
   - 固定更新时间（让读者养成习惯）
   - 不能断更（断一天追读率砍半）
   - 没内容也要"糊弄两千字"续命
5. **社群运营**：
   - 评论区互动（让读者有参与感）
   - 读者猜测剧情走向
   - 读者预测被打脸（越打越上头）

## 18. 反套路/逆向爽 — 女频反套路技巧

### 反套路类型与爽感

| 反套路类型 | 具体表现 | 爽感来源 |
|------------|----------|----------|

### 具体可执行技巧

1. **身份反套路**：
   - 女主穿书成恶毒女配
   - 女主重生是"坏人"
   - 女主是反派设定的"恶役"
2. **感情反套路**：
   - "她冷笑一声：'这婚，我不替了'"

   - 男二上位（男二比男主更圈粉）

   - 男主病娇/疯批但女主不怕
   - "他爱她爱到疯，她只想搞钱"
