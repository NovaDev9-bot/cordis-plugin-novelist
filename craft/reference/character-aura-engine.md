## 一、核心认知：气质为何会跑

### 1.1 AI 创作的气质崩坏四大根源

**根源A：AI 语言均质化**
AI 倾向于生成流畅、对称、"正确"的句子，导致所有角色说话都像同一个"写作AI"在发言，而非各自不同的人。

**根源B：只记设定，不记行为逻辑**
档案里写了"主角冷静克制"，但创作时AI忘记了冷静的人面对惊吓时具体会有什么反应——会先停顿三秒？还是无表情地问"然后呢"？

**根源C：情绪压力下的气质失守**
突发事件、高压场景下，AI 最容易让角色"说废话"——说那种"任何人在这种情况下都可能说"的话，而不是"只有这个角色才会这样说"的话。

**根源D：只有表征性格，没有内在性格**
设定了表面的"高冷"，但没有定义表面之下的内在——为什么高冷？哪件事会穿透高冷？内外落差才是角色最有魅力的地方，也是气质稳定的真正锚点。

## 二、气质身份证（每个主要角色必须建立）

> 大纲完成后、第一章创作前，为每个主要角色填写以下「气质身份证」。长篇续写时，每次读取追踪文件都要同时读取该角色的身份证。

### 模板结构

```
【角色气质身份证】

== 基础定义层 ==
角色名：
核心欲望（深层驱动力，一句话）：
核心伤口（哪件具体的过去事件塑造了这个人）：

== 表征/内在双层性格 ==
表征性格（在大多数人面前的样子）：
内在性格（在极度压力/亲近者面前才会显现的样子）：
内外落差触发条件（什么情况下内在会穿透表征）：

== 气质锚三件套 ==
标志性动作（1-2个，此角色特有的习惯性肢体语言）：
标志性语言节奏（说话方式：句子长短、用词偏好、停顿习惯、口头禅或禁忌词）：
标志性世界观过滤器（看待同一事件，这个角色的第一反应和角度）：

== 声线参数 ==
词汇层（偏书面/偏口语；偏古典/偏现代；偏专业/偏民间）：
句式偏好（短句冲击型/长句铺陈型/反问型/陈述型/沉默型）：
情绪显露度（内敛指数1-10，10=完全不露情绪，1=情绪全在脸上/话里）：
对话密度（话少寡言型/适中型/话多型/滔滔不绝型）：
禁忌表达（这个角色绝对不会说的话/绝对不会有的反应）：

== 压力测试场景 ==
遇到不公平时，这个角色会___：
被人看穿/触碰软肋时，这个角色会___：
面对巨大惊喜时，这个角色会___：
极度疲倦/崩溃边缘时，这个角色会___：

== 弧光轨迹（长篇专用）==
第一幕的状态（章节范围+关键词）：
第二幕的变化（章节范围+触发事件+性格偏移方向）：
第三幕的状态（章节范围+与第一幕的对比）：
```

### 填写示例（「冷情谋士」型）

```
【角色气质身份证：沈临川】

== 基础定义层 ==
核心欲望：掌控局面——因为他曾经最重要的事在他毫无准备时失控，他发誓再也不允许这种事发生。
核心伤口：十七岁时，父亲在他眼前被诬陷处决，他当时一句话都没说出来。

== 表征/内在双层性格 ==
表征性格：冷静、算计、不动声色、轻描淡写
内在性格：偏执、极度不安全感、对"失控"有隐性恐惧
内外落差触发条件：当有人以他父亲为要挟，或他意识到自己真的失控时——表征壳子会出现细小裂缝

== 气质锚三件套 ==
标志性动作：沉默时会用食指轻叩桌面，像在计时，也像在计算
标志性语言节奏：短句为主，从不解释，偶尔反问，不用感叹句；沉默本身是他最常见的回应
标志性世界观过滤器：看任何事件，先看谁获益，再看谁受损，情感是他最后才处理的维度

== 声线参数 ==
词汇层：书面、克制，拒绝俗语
句式偏好：短句陈述型；越重要的话，说得越平静
情绪显露度：9（极内敛；唯一的例外是轻微的冷笑，算是极限）
对话密度：话少——"够用就停"是他的原则
禁忌表达：绝不用感叹词；绝不主动解释自己的动机；绝不说"我不知道"

== 压力测试场景 ==
遇到不公平时：冷眼旁观，记下来，等时机
被人看穿/触碰软肋时：沉默3秒，然后换个话题——绝不正面承认
面对巨大惊喜时：微微停顿，然后说"还有什么我不知道的？"（把惊喜立刻转化为信息核查）
极度疲倦/崩溃边缘时：更安静，动作更慢，眼神变得有点茫然——唯一可见的失控信号

== 弧光轨迹 ==
第一幕（1-20章）：绝对的掌控者，所有棋都在手里
第二幕（21-60章）：遇到一个他算不准的人/局面，开始出现小的判断失误，内心偏执加剧
第三幕（61章后）：接受"不是所有事都可以被算计"——这对他是一种释放，也是一种失去
```

## 三、声线区分矩阵（多角色场景必用）

> 每个对话场景创作前，列出本场景的出场角色，在内部完成以下矩阵对比，确保区分度达标。

### 快速区分度检测表

| 维度 | 角色A | 角色B | 角色C |
|------|-------|-------|-------|
| 说话密度 | 少 | 多 | 适中 |
| 句式长度 | 短 | 长 | 混合 |
| 情绪显露度 | 低 | 高 | 中 |
| 用词风格 | 书面 | 口语 | 专业术语 |
| 冲突应对方式 | 沉默/反问 | 正面爆发 | 迂回调解 |
| 独特标志 | 叩桌 | 笑声先于话 | 先问"为什么" |

**最低要求**：同场景中，任意两个角色在上表6个维度中，至少有4个维度明显不同。

### 常见"声音趋同"警报（任一出现→强制重写该角色该段对话）

- 两个角色都用了超过15字的完整表达句说同一性质的话
- 两个角色的情绪反应节奏完全相同（都是"先愣，后反应"）
- 角色A说的话，用角色B的名字替换也完全成立
- 对话中出现三个连续句，任何角色的说话方式都可以互换

## 四、气质不跑的核心机制：三锚点执行法

> 每次写到某角色出场，创作前先在内部完成三锚点复述，耗时不超过15秒：

**锚1：标志性动作**
"他/她会有什么动作？"——在这个场景的情境压力下，他的身体会先做什么？

**锚2：声线参数**
"他/她这句话会用几个字说？"——少言型的角色，超过15字就要重审；话多型的角色，少于30字就不够自然。

**锚3：世界观过滤器**
"他/她对这件事的第一个念头是什么？"——不是"正确的角色应该想什么"，而是"这个具体的人、带着这段具体的历史、面对这个具体的场景，会先想到什么"。

## 五、气质演变规则（不跑 ≠ 固定不变）

### 5.1 气质可以因以下原因合理演变

| 演变触发器 | 演变方向 | 演变速度 |
|-----------|---------|---------|
| 重大失去（亲人/信念/身份） | 内敛↑ 或 情绪失控↑ | 慢（3-5章渐变） |
| 重大胜利/达成目标 | 短暂松弛→新的紧张 | 1-2章 |
| 被另一个角色深度影响 | 局部语言习惯改变 | 极慢（10章以上） |
| 极度压力/崩溃临界点 | 表征脱落，内在短暂裸露 | 瞬间，但必须迅速恢复或转型 |
| 时间跨度（数年） | 全面性格成熟/腐化 | 须有具体事件链支撑 |

### 5.2 气质演变的写法要点

- **演变必须有具体事件作为节点**，不能因为"过了很多章"就自然演变
- **演变是局部的**：一个角色的标志性动作基本不变，变的是情绪显露度或词汇偏好
- **演变要对读者可见**：通过另一个角色的"注意到了变化"来呈现，而不是直接叙述"他变了"
- **OOC 与演变的区别**：演变是有原因的渐变；OOC 是无原因的跳变——前者合理，后者违禁

### 5.3 突发事件下的气质压力处理

突发事件会让角色短暂失常，但失常的方式必须符合其内在性格：

| 角色类型 | 突发惊吓时的第一反应 | 突发巨大失去时的第一反应 |
|---------|-------------------|----------------------|
| 冷情型（内敛9-10） | 身体先静止，然后才有语言 | 更安静，拒绝接触 |
| 情绪型（内敛1-3） | 立刻反应，声音先于思维 | 当场崩溃或爆发 |
| 算计型 | 立刻开始评估局面 | 短暂空白后进入过度分析模式 |
| 保护型 | 先看周围的人是否安全 | 转移注意力到可以做的事 |
| 逃避型 | 假装没看见/笑着说无所谓 | 消失（物理或心理上的离开） |

## 六、令人记忆深刻的角色塑造：「记忆钉」技法

> 最容易被读者记住的角色，不是设定最复杂的，而是有1-2个**强记忆钉**的。

### 6.1 四类记忆钉（选1-2个植入每个主要角色）

**记忆钉A：标志性动作/习惯**
每次出现时都有，但不显刻意。读者潜意识里会把这个动作与这个角色绑定。
- 优秀示例：食指叩桌 / 总是先低头看脚再抬头说话 / 握拳时拇指压在食指上（不同于常见的握拳方式）
- 劣质示例：总是"轻笑"（太泛，任何角色都可以） / 眼神深邃（不可见，没有记忆点）

**记忆钉B：反差场景**
在读者预期A的地方，这个角色给了B。这个落差本身成为记忆。
- 优秀示例：满屋杀气的谈判结束，他问的第一句话是"附近哪家面馆好吃"
- 劣质示例：冷酷反派突然哭泣（太常见，无记忆点）

**记忆钉C：标志性台词/口头禅**
不能太刻意，最好是这个角色世界观的浓缩，且只有这个角色才会这样说。
- 优秀示例："你不必告诉我原因。原因通常没有结果重要。"（算计型+简洁型+世界观）
- 劣质示例："哼，就这？"（任何傲娇角色都能说，无专属性）

**记忆钉D：一个"非设定"细节**
一个与角色主要人设不一致的细节——正因为不一致，所以令人难忘。
- 优秀示例：冷酷谋士的书架上有一本褪色的童话故事，书脊磨损，显然读过很多次
- 劣质示例：强壮男人喜欢养猫（太套路，已经是标配）

### 6.2 记忆钉植入规则

- 每个主要角色：1-2个记忆钉，不超过3个（太多会互相稀释）
- 记忆钉第一次出现：在该角色首次出场的章节，且不解释——让读者自己发现
- 记忆钉后续出现：每3-5章强化一次，不能超过10章没有任何呼应
- 记忆钉演变：长篇后期，记忆钉可以因角色成长而发生微妙变化（如：原来叩桌是他算计时，后来叩桌是他想你时）

## 七、名字遮盖测试（OOC 检查工具）

> 章节完成后，对任意有对话的段落执行以下测试：

**操作方法**：
1. 把段落里所有角色的名字替换为数字（角色A→"1"，角色B→"2"）
2. 给一个不知道剧情的人读这段对话
3. 问他："你能猜到这些话分别是谁说的吗？能说出理由吗？"

**判定标准**：
- 能猜到，且理由是"说话方式/用词/反应节奏不一样"→ ✅ 气质区分合格
- 能猜到，但理由是"内容提到了这个角色的名字或处境"→ ⚠️ 区分靠内容，不靠声线，需加强
- 猜不到，或猜错→ ❌ OOC，必须重写

**快速自检版**（无法找外部读者时）：
把任意两个角色的3句对话互换，如果读起来没有任何违和感→区分度不足。

## 八、配角气质快速建档（简化版身份证）

> 配角不需要完整身份证，但必须有以下最小信息集：

```
【配角快速档案：XXX】
功能定位：（对主角/剧情的作用是什么？）
表征性格关键词：（1-3个）
标志性声线特征：（用词偏好+一个具体说话习惯）
记忆钉：（1个）
OOC红线：（这个配角绝对不会做/说的1件事）
弧光预设：（这个配角会发生变化吗？如果会，触发事件是什么？）
```

配角档案要求：主要配角（戏份≥5章）必须建档；次要配角（出场≤3次）至少有声线特征和记忆钉。

## 九、底层行为逻辑（内核层——气质之下的决策引擎）

> 气质身份证管"这个人**怎么说话、什么气场**"（声线层）；本节管"这个人**凭什么做决定**"（内核层）。声线层不跑靠锚点，内核层不跑靠一句话行事准则。两层都立住，人物才既有辨识度又有自驱力。

### 9.1 一句话底层逻辑（人物自驱力的唯一来源）

与其三页纸描述"活泼开朗"，不如三句话想清楚：**这个人最核心的行事准则是什么？** 写成一句话，人物所有行为从这一句推导：

- 示例A："谁给钱谁是爹" + "任何回答自动翻译成我想要的，并强制执行" → 金主爷爷欺负金主？薅头发。金主不肯出门？整三轮车拉上街。每个行为离谱，但全部逻辑自洽。
- 示例B："扶自己的儿子上位" → 前期恶毒；儿子死后前线热血祭旗——读者惊呼"不符合人设"，细想恰恰是死守逻辑：儿子没了，她的一切失去意义。**不崩人设，正因为始终遵循底层逻辑。**

**建档三问**（微小说/盐选建人物只需这三问，30秒完成内核）：
1. 这个人是谁？（一句话身份+一句话底层逻辑）
2. 他最想要什么？
3. 他最怕失去什么？

### 9.2 出格=逻辑的自然延伸（"不按套路"的正确打开方式）

人物立住后不敢让他出格=慢性死亡。真正立住的人物恰恰因为**足够出格**——前提是出格必须是底层逻辑的自然延伸：
- 贪财的人突然大方 = 崩人设
- 贪财的人为赚更多钱做出极其离谱的事 = 意料之外、情理之中
- 检验法：这个离谱行为能否从他的一句话底层逻辑一步推出？能→写；不能→崩。
- 与 `craft/reference/narrative-ecology.md` 第3条反套路联动：剧情层躲开前3种常见接续，人物层的实现手段就是"让底层逻辑推出离谱但自洽的下一步"。

### 9.3 反差收核（反差是记忆点，散装反差是杂糅）

反差感是让读者记住人物的最快方式，但**所有反差必须收束于同一个内核**：贪财/武力爆表/脱线/不知不觉治愈男主——四个反差全部服务于"一个用自己的方式爱人的奇女子"。反差没有核=一堆矛盾标签的杂糅，不是人。
- 建档时自查：列出人物全部反差点 → 能用一句话说出它们共同服务的内核吗？说不出→砍反差或重找核。

### 9.4 外挂+软肋（张力的永动机）

完美主角杀死代入感——读者知道"反正他不会输"，紧张归零。铁律：
- 必须有一项"**无人能及**"的强项（外挂），也必须有一项"**任何努力都没用**"的软肋。
- 软肋≠小缺点（怕虫不算），是结构性的、会被剧情反复攻击的死穴（智力碾压但武力为零→每次巷子被堵读者都提心吊胆）。
- 强弱交替出现，期待感永动：这一拍用外挂赢，下一拍软肋被踩。

### 9.5 高光时刻（被铭记的精确配方）

高光≠"他做了件很厉害的事"。高光的精确定义：**所有人（包括读者）都以为他会选A的时候，他选了B，而且这个选择从他的底层逻辑看如此合理。**
- 一个这样的时刻，读者记住他；三五个，读者爱上他。
- 微小说只有一次高光机会→放在反转拍；盐选可布2-3次→分置于爆发拍与结尾。

### 9.6 短篇速造流程（微小说/盐选专用）

短篇没有篇幅养人物，内核层是唯一来得及的人物工具：
1. 三问建核（9.1）→ 2. 定一项外挂+一项软肋（9.4）→ 3. 预设一个"离谱但自洽"的行为（9.2）放在反转/爆发拍 → 4. 若有反差，一句话说出收束核（9.3）→ 5. 声线层从简：一个记忆钉+一条口吻特征即可（第六、三节的简化调用）。
全程≤5分钟内部完成，禁止外显建档过程。

### 9.7 冲突中展现性格（真空表演无效）

不要让人物在真空中"表演"自己的性格——把他放进必须做选择的处境里。人物在冲突中的选择，才是性格最清晰的显影液：
- 一个贪财的人，在钱和朋友的命之间怎么选？
- 一个懦弱的人，在退一步和进一步之间怎么站？
- 一个"扶儿子上位"的人，儿子死后怎么办？

规律：设计一个"两边都想要但只能选一个"的处境，然后让人物按底层逻辑做出选择——选择本身就是性格最有力的声明。读者记住的，永远是人物在绝境里做的选择，不是作者的描述性定义。

### 9.8 从人性出发，不从故事出发

做人物设定时，不问"这个角色在故事里需要做什么"，问"这个角色是一个什么样的人，他在这种情况下会做什么"。前者是工具人思维，后者是人物思维。工具人思维的结果是人物服务情节；人物思维的结果是情节从人物里自然长出来。

实操：建档完成后，把故事里三个关键节点拿出来，问"如果他完全按照自己的意志行事，他会怎么做？"——不依赖剧情需要。如果答案比你设计的剧情更有趣，按人物的答案改剧情。
