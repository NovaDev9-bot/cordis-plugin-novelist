## 环境判断规则

**有脚本环境**（Claude Code、本地终端）：
- 直接调用 `scripts/memory_client.py`〔仓外〕〔仓外〕 执行所有记忆操作
- 按 SKILL.md 中的 Python 代码块执行

**无脚本环境**（claude.ai 对话、API 纯文本）：
- 所有 Python 代码块改为"文件读写 + 结构化输出"模式
- 用 `novel-creation-evo-output/[书名]_追踪.md`〔模板〕〔仓外〕 作为记忆中台的平替
- 下文按各阶段给出具体替代操作

## 阶段 B：章节前记忆唤醒（对应 `client.get_chapter_pack(chapter=X)`）

**脚本版**：生成精简记忆包 JSON

**降级版**：在创作第 X 章前，从追踪文件中**手动读取并在内部复述**以下内容（不向用户展示，作为创作约束）：

```
【章节前记忆包 - 第X章】（内部执行，禁止外显）
风格 guardrails：[从追踪文件读取]
活跃人物及当前状态：[从追踪文件人物状态区读取]
活跃剧情进展：[从追踪文件剧情层读取]
未回收伏笔：[从伏笔清单读取]
上一章结尾悬念：[从追踪文件续写提示区读取]
本章 OOC 红线：[从人物行为边界读取]
```

**执行要求**：能在内部复述以上6项，视为记忆唤醒成功；无法复述任何一项，必须重新读取追踪文件。

**脚本版**：调用 `sync-chapter` 写入结构化摘要

  - [相关配角]：[变化]

- 本章回收伏笔：[内容] | 标记为：✅已回收
- 结尾悬念（原文）：[直接引用章末最后1-2句，供下章衔接用]
- 章节字数：[实际字数]
- 爽感·共鸣：压爽比[N/N] | 共鸣锚点[本章延续的情绪] | 爽点[小N/中N/大N] | 读者债[新建N/偿还N] | 上章章末钩[✅已兑现/⚠️空挂]

## 阶段 D1：风格校准（对应 `client.calibrate_style()`）

**脚本版**：`style_calibrator.py`〔仓外〕〔仓外〕 输出偏离报告

**降级版**：完成章节创作后，对照追踪文件中的"风格 guardrails"，检查以下4项：

1. 有无违反风格边界的句子（如 guardrail 是"禁止中二独白"，则搜索全文有无此类段落）
2. 对话密度是否符合风格设定（猫腻：对话精炼；孔二狗：口语密集）
3. 叙事视角是否稳定（第一人称/第三人称有无意外切换）
4. 情绪处理方式是否一致（克制风格不得出现大段心理独白）

输出格式（向用户展示）：
```
🎨 风格校准报告
- guardrail 检查：✅通过 / ⚠️偏离（[具体问题]）
- 对话密度：✅正常 / ⚠️偏高/偏低
- 叙事视角：✅稳定 / ⚠️切换（[位置]）
- 情绪处理：✅克制 / ⚠️外溢（[段落]）
修正建议：[具体1条]
```

---

## 阶段 D2：人物一致性检查（对应 `client.check_character_consistency()`）

**脚本版**：`character_consistency_checker.py`〔仓外〕〔仓外〕 输出 OOC 风险

**降级版**：创作完成后，对照追踪文件中每个活跃人物的"行为边界（OOC 红线）"：

1. 本章有无该人物"绝对不会做的事"出现
2. 人物说话方式是否符合设定（如设定"简短/反问"，有无突然出现长篇剖白）
3. 人物动机是否与档案一致（本章行为能否用档案中的"核心欲望"解释）

输出格式（向用户展示）：
```
👥 人物一致性检查
- [主角名]：✅一致 / ⚠️OOC风险（[具体行为] | 建议：[修改方向]）
- [配角名]：✅一致 / ⚠️OOC风险（[具体行为] | 建议：[修改方向]）
一致性分数：[X]/10
```

## 阶段 E：阶段性回顾（对应 `client.get_review_pack()`）

**脚本版**：生成 review_pack.json，展示漂移风险和归档候选

**降级版**：每5-10章触发，从追踪文件中扫描：

1. **漂移风险**：有无某条伏笔超过5章未回收且未标注延期原因
2. **人物漂移**：对比第1章和当前章，人物状态变化是否有合理的情节支撑
3. **归档候选**：早期章节摘要是否可压缩为一句话（"已解决内容"降权处理）
4. **剧情停滞检测**：连续3章的"核心事件"是否有实质推进（若均为"继续调查"类，标记为停滞警告）

输出格式：
```
📊 阶段性回顾报告（第[X]-[Y]章）
漂移风险：[列出] / 无
归档候选：第[X]章摘要可压缩 / 无
剧情停滞：⚠️第[X]-[X+2]章疑似停滞 / ✅正常推进
建议操作：[具体1-2条]
```

## 关键原则

- **降级不降质**：所有记忆功能通过追踪文件实现，覆盖率100%
- **读取优先于依赖对话记忆**：即使"记得"前文，每章前也必须重新读取追踪文件
- **回填即时性**：章节完成后立刻更新追踪文件，不可积压
- **OOC 红线前置**：创作开始前先在内部复述人物行为边界，而非事后检查
