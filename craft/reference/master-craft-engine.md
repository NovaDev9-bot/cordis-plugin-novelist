## 一、高概念引擎（让创意在 premise 层就赢）

**公式1：熟悉 × 陌生**
一半让读者秒懂（熟悉框架），一半让读者没见过（陌生变量）。
- 弱：「一个杀手的故事」（全熟悉）｜「一个十一维生物的情感」（全陌生，无法代入）
- 强：「杀手发现本次目标是 20 年前救过他的人」（杀手=熟悉，恩仇悖论=陌生）

**公式2：What-if 链（推三步才停）**
第一步 what-if 人人想得到，连推三步才到蓝海：
- What if 人死后记忆可以被购买？（一步，已被写烂）
- → What if 穷人靠卖临终记忆给子女留遗产？（二步，开始有味道）
- → What if 主角买到的记忆里，藏着卖家被谋杀的真相，而买家依法必须保密？（三步，规则困境+悬念+道德撕扯齐活）

**公式3：双高概念对撞**
两个独立成立的高概念强行同框，冲突自动生成：「重生」×「全员都重生了」=《大家都重生了，装新人是会被笑话的》。

**检验**：premise 一句话讲给陌生人，对方是否立刻追问"然后呢"？不追问 = 回炉。

## 二、人物四层内核（立体感的发生学）

每个重要角色落笔前定四层，**层与层必须互相矛盾**——矛盾即立体：

| 层 | 问题 | 示例（一个职场逆袭男主） |
|----|------|----|
| **欲望**（他要什么） | 表层驱动 | 升职，赢回被抢走的项目 |
| **恐惧**（他怕什么） | 行为刹车 | 怕变成自己最恨的那种领导 |
| **谎言**（他信什么假的） | 性格成因 | 「只要够强，就不会被辜负」 |
| **真相**（他需要学会什么） | 弧光终点 | 强大不是不被辜负，是被辜负后还能选择善良 |

- 欲望推着走，恐惧拖着停——角色每个重大选择都是这两股力的合力
- 谎言在故事中段被现实击碎（最痛一章），真相在结尾被验证（弧光闭合）
- **反派同构**：反派同样四层，只是他的"谎言"没人帮他击碎——这就是"可悲"维的工艺实现

## 三、冰山台词工程（对话的三层结构）

每句重要对话写之前过三层：

```
说的（台面）：他实际说出的话
想的（水下）：他真正想表达的
怕的（深水）：他绝不肯承认的
```

**实现手法**：
- **错位应答**：不接对方的话头，答非所问即潜台词。「你昨晚去哪了？」「汤要凉了。」——回避即答案
- **对抗性对话**：每场重要对话双方各有目标且互斥，对话=没有动作的打斗。没有目标冲突的对话是信息播报，删
- **沉默标点**：最重的话不说出来。用动作代替台词：「她没回答，只是把戒指摘下来放在了桌上。」
- **禁令**：角色不许把自己的心理动机说出口（"我这么做是因为我从小缺爱"= 工艺事故）。动机靠行为泄露，不靠台词广播

## 四、场景工艺三铁律

**铁律1：进晚出早**
每个场景从冲突已经发生后切入（删掉寒暄、进门、坐下），在情绪峰值后立即切出（不写收尾、告别、关门）。开头删 30%，结尾删 20%，节奏自然紧。

**铁律2：单场景三功能**
每个场景同时干三件事：推进情节 + 揭示人物 + 蓄积情绪。只干一件的场景与别的场景合并或删除。检验：这场戏删了，后文哪里会断？说不出来 = 删。

**铁律3：场景价值翻转**
每个场景结束时，至少一个关键值发生翻转：希望→绝望、信任→怀疑、安全→危险、无知→知情。开场和收场情绪值相同的场景是平的，平=读者划走。

## 五、细节炼金术（质感的最小单位）

- **具象名词 > 形容词堆叠**：「破旧的房间」(弱) →「墙皮卷边，开关上一圈黑色的指印」(强)。形容词是作者的判断，具象名词是读者的眼睛
- **五感锚点**：每个重要场景至少 2 个非视觉感官（声音/气味/触感/温度）。「消毒水味」一个词建立整个医院
- **标志性道具复用**：一个道具至少出现 3 次，每次含义递进（参见情绪阀门）——第 1 次是物件，第 2 次是线索，第 3 次是炸药
- **数字的可怕**：精确数字自带真实感与压迫感。「他等了很久」→「他等了四年零三个月，今天是第 1556 天」
- **白描时刻**：全书最痛的一幕用最平的语言写（克制是最大的残忍的工艺实现）：情绪越高，文字越冷

## 六、文字节奏波形（句子层面的呼吸控制）

- **句长波形**：紧张段用短句（≤10字连发），抒情段放长句，**长短交替制造呼吸**。连续 5 句等长 = 催眠
- **段落悬尾**：每段最后一句承担本段最大信息量或情绪量——段尾是天然的视线停留点，废话放段尾 = 浪费黄金位
- **动词军备**：一个精准动词顶三个副词。「狠狠地用力关上门」→「摔上门」。全文检索"地"字，密度过高 = 动词不够强
- **重复的刀法**：刻意重复一个短句/意象形成主题回响（每次出现语境递进），与无意识的词穷重复严格区分

## 七、改稿三遍法（创作完成≠交付，自检的工艺版）

- **第一遍砍**：删每段开头的清嗓子句、删解释情节的对白、删重复的信息点——目标砍 10%
- **第二遍换**：弱动词换强动词、形容词换具象名词、直述情绪换动作外化（"他很愤怒"→"指节捏得发白"）
- **第三遍读**：内部默读全文，凡是"读着拗口/会换气失败"的句子重写——耳朵比眼睛诚实
