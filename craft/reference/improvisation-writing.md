# 即兴发挥写作法（大纲锁死 + 踢石头采花）

> **移植件 · 外部来源（未经本仓校对）**
> 来源 = 外部技能包 novel-workshop-pro（WorkBuddy 专家，上架名「网文主编」）；原始路径 = references/improvisation-writing.md；移植日 2026-09-26。
> **取用边界**：本件可能含指标式表述（百分比／密度／配额／占比）。那类量归**审校侧与主编参考**用；
> **不得整段复制进写手派工包**——口径见 craft/author-cards/_模板与建卡纪律.md 的四分界表（进包只许「结构节拍」与「形态上限」两种形状）。
> **取用方式**：按本章场景功能取相应小节，**上限 2 节**；「相关的都塞」是禁止项（guide v7.14）。

> 核心理念：大纲决定"到哪"，章纲决定"走哪条路"，路上的踢石头采花交给大神DNA即兴发挥。

## 设计哲学

AI写网文的根本问题不是"写得不对"，而是"写得太对"——每一句都在高效推进剧情，没有任何冗余、走神、废话，读起来像一份精准的施工报告，而不是一个人在讲故事。

即兴发挥法的本质：**让AI像人类作者一样"不务正业"**。人类作者写故事时，角色会突然注意到路边的猫，会说一句无关紧要的废话，会因为天气太热而放慢节奏——这些"无用"的细节才是人味的来源。

## 四大底线（不可违反）

1. **大纲不能偏，章纲不能乱，爽点钩子不能少** —— 剧情锚点是铁轨，即兴只能在铁轨上跑
2. **每章2000字打底** —— 即兴发挥不是注水，是加料
3. **去AI铁律必须执行** —— 详见 G1 全局强制规则
4. **排版：长短句交错，不碎不堆** —— 即兴段落也要保持节奏美感

## 锚点写作法

### 什么是锚点

锚点 = 本章必须到达的剧情节点。由章纲决定，不可跳过、不可改变顺序、不可合并。

每个锚点包含：
- **事件**：发生什么（如：陆拾发现老钱头顶标签变了）
- **角色**：谁参与（如：陆拾、老钱）
- **情绪**：读者应该感受到什么（如：紧张→好奇）
- **功能**：在主线中的作用（如：推进悬念/建立关系/埋伏笔）

### 锚点之间的"路"

两个锚点之间是"路上"——这就是即兴发挥的空间。

```
锚点A：陆拾走进灵兽铺
    ↓  ← 这段"路上"可以即兴发挥
锚点B：老钱递给陆拾一只幼崽
```

"路上"可以写：
- 陆拾进门时差点被门槛绊到
- 铺子里有股说不清的腥味，像鱼市和药铺的混合体
- 老钱正在抠指甲缝里的什么东西，看到陆拾才随手擦了擦
- 一只鸡在角落里发呆，脖子上的毛少了一块

这些内容对剧情毫无推动，但让场景"活"了。

### 锚点的铁律

**绝对不能即兴的部分：**
- 锚点事件本身（必须发生）
- 关键对话的核心信息（必须传达）
- 伏笔的埋设/回收（必须到位）
- 角色出场顺序（不能乱）
- 章末钩子（必须有力）

**可以即兴发挥的部分：**
- 场景过渡中的环境细节
- 角色的无意识小动作
- 与剧情无关的碎碎念/吐槽
- 感官细节（气味、温度、触感、声音）
- 配角的"无用"行为
- 叙事者的闲笔（一句题外话再拉回来）

## "踢石头采花"清单

角色从A锚点走到B锚点的路上，可以从以下清单中挑选插入：

### 行为碎片
- 戳地上的蚂蚁/蜗牛
- 抠墙皮/抠指甲/抠桌角
- 踢路边的小石子
- 摘路边的草/花/叶子
- 踩地砖格子（踩线算输）
- 无聊地数东西（柱子/台阶/灯）
- 用手指画圈圈/在桌上乱划

### 感官碎片
- 突然闻到一股奇怪的味道
- 被太阳晃了一下眼
- 石凳凉得透屁股
- 风吹过来带着泥土味
- 远处传来模糊的声音
- 嘴里有股铁锈味

### 对话碎片
- 说了一句废话（"今天天真热"）
- 答非所问（问A答B）
- 说到一半突然停住/换个话题
- 沉默/不回应/假装没听到
- 嘟囔了一句只有自己听到的话

### 心理碎片
- 突然想到一件完全不相关的事
- 对眼前场景的内心吐槽
- 回忆一个模糊的画面（不完整，不展开）
- 一个不合时宜的念头
- 走神了，被叫回来

### 环境碎片
- 一只猫/狗/鸟突然经过
- 某个东西倒了/掉了/响了
- 光线变化（云遮住太阳/灯闪了一下）
- 某个物品的奇怪状态（裂缝/污渍/缺角）

**密度控制**：每2000字穿插3-6个碎片，不要集中堆在一起，均匀散布在锚点之间。

## 搭配大神DNA弹药库

即兴发挥不是乱写，是在大神风格框架内的即兴。

### 执行流程

1. **加载对应大神的数字人记忆库**（`craft/style-dna/_流派索引.md`）
2. **提取该大神的即兴特征**：
   - 该大神喜欢写什么样的"踢石头采花"细节？
   - 该大神的角色走神时想什么？
   - 该大神的环境描写侧重什么感官？
   - 该大神的叙事者吐槽风格是什么？
3. **加载该大神对应的手搓句式库**（如 `references/起点TOP作者手搓句式.md（本仓未移植，见源包 references/）`〔仓外〕 等）
4. **用大神的句式包装即兴内容**：不是"写一句废话"，而是"用肘子的方式写一句废话"

### 示例：同一场景，不同大神即兴

**场景**：两个锚点之间，角色走过一条巷子

- **肘子风格**：巷子里有股泔水味，混着不知道谁家的红烧肉香气。陆拾吸了吸鼻子，决定等这事了结了一定要去吃碗红烧肉。脚下踩到个什么东西，低头一看是半块烧饼，被蚂蚁包围了。
- **乌贼风格**：巷子的墙壁上长着一层青苔，但在某些角落，青苔被刮掉了，露出下面更浅色的石面。他数了数，一共七个刮痕，间距均匀——像是有人定期在这里做标记。
- **priest风格**：巷口蹲着个老头，面前摆了一盘棋，自己跟自己对弈。沈巍路过时瞥了一眼，觉得黑棋已经死了，但老头看起来胸有成竹。

### 弹药库速查

| 大神 | 即兴特长 | 手搓句式库位置 |
|------|---------|--------------|
| 肘子 | 生活化碎碎念、搞笑内心戏、接地气的比喻 | 起点TOP作者手搓句式.md（本仓未移植，见源包 references/）（肘子条目） |
| 乌贼 | 环境细节中的隐秘线索、冷幽默、理性观察 | 起点TOP作者手搓句式.md（本仓未移植，见源包 references/）（乌贼条目） |
| priest | 冷峻白描中的暗涌、配角闲笔、氛围感 | 晋江TOP作者手搓句式.md（本仓未移植，见源包 references/）（priest条目） |

其他大神同理，根据各自记忆库中的特征提取即兴风格。

## 搭配不完美注入

即兴发挥天然是不完美的——角色走神、说废话、注意到无意义的东西，这些都是"不完美"。但不能只靠即兴来覆盖不完美注入，还需要叠加 `craft/reference/imperfection-injection-rules.md` 中的规则。

### 即兴 + 不完美的结合点

| 不完美类型 | 即兴发挥中如何实现 |
|-----------|-----------------|
| 自我纠正 | 角色走神后把自己拉回来（"想什么呢，办正事"） |
| 模糊数 | "大概三四步远""好像过了好一会儿" |
| 感官错位 | 用触觉写情绪（"手心有点潮"代替"他紧张了"） |
| 节奏炸弹 | 在平静场景中突然插入一个短句（"有血。"） |
| 口语碎片 | 角色说话时结巴/重复/省略（"我、我不是那个意思"） |
| 未完成的句子 | 角色话没说完就被打断/自己停住 |

**密度要求**：每2000字中，即兴碎片3-6个 + 不完美注入8-15处，两者可重叠但不完全替代。

## 评分门槛

即兴发挥写完后，必须通过以下全部检查才能交付：

### 1. 锚点完成度检查
- [ ] 所有章纲锚点是否都已到达？
- [ ] 锚点事件是否完整发生？
- [ ] 关键对话信息是否传达到位？
- [ ] 伏笔是否按计划埋设/回收？
- [ ] 章末钩子是否有力？

### 2. 即兴碎片密度检查
- [ ] 每2000字是否有3-6个踢石头采花碎片？
- [ ] 碎片是否均匀分布（不集中在某一段）？
- [ ] 碎片类型是否多样（行为/感官/对话/心理/环境都有）？
- [ ] 碎片是否用大神风格包装（不是裸写）？

### 3. 双模式评分
- 按阶段八的双模式六维评分执行
- 读者视角综合分 ≥ 70
- 编辑视角综合分 ≥ 65
- 任一维度低于50需修改

### 4. 去AI强制检测
- 按阶段7.14的去AI检测流程执行
- 去AI打分 ≥ 8分
- 未达标则修改后重新检测

### 5. 不完美注入密度
- 按 `craft/reference/imperfection-injection-rules.md` 检查
- 每2000字 8-15处不完美元素
- 6大类分布均衡

**全部通过 → 交付。任一不通过 → 修改后重新检查。**

## 实战示例

### 背景
《功法有漏洞我能一眼看穿》第10章，飞卢风格，肘子DNA执笔。

### 锚点设计
- A: 陆拾走进灵兽铺（开场）
- B: 老钱递幼崽，陆拾看到标签（转折）
- C: 苏糖出场，三方对话（冲突）
- D: 陆拾决定接手（决策）
- E: 走出灵兽铺，暗示后续（收尾）

### 即兴发挥示范（A→B之间）

> 灵兽铺的门是半掩的，陆拾推了一把，门轴嘎吱响了一声，跟要散架似的。
>
> 铺子里光线暗，弥漫着股说不上来的味道，像鱼市和药铺搅到了一起。柜台后面的老钱正低头抠指甲缝，也不知道抠的是什么，听到动静才抬头，手上随意在围裙上擦了擦。
>
> "来了？"
>
> "嗯。"陆拾在柜台前站定。脚边有只鸡，灰扑扑的，脖子上一块毛秃了，正用一只眼睛打量他。
>
> 他差点踩到那鸡。

**分析**：
- 4个碎片：门的嘎吱声（感官）、鱼市药铺味（感官）、老钱抠指甲（行为）、秃毛鸡（环境）
- 0个锚点推进（这段路没有推动任何剧情）
- 肘子风格：接地气的细节、略带嫌弃的观察、轻幽默
- 不完美注入：感官细节替代直接形容、短句节奏、角色走神（差点踩到鸡）
