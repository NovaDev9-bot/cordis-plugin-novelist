#### 2.3 长篇小说第1章创作流程

**触发条件**：用户提出"开始第一章"、"第1章"、"从大纲开始创作"等需求

**⚠️ 硬规定：文件存在性前置检查（自动补齐模式）**

在阶段一任何步骤开始前，**必须**执行以下检查，**文件不存在时自动创建，禁止停止创作**：

- **检查项1**：确认 `novel-creation-evo-output/[小说标题]_大纲.md`〔模板〕〔仓外〕 文件存在
  - **如不存在**：**立即自动创建基础大纲文件**，包含：主题立意（待用户补充）、三幕式结构框架、人物设定模板、伏笔规划表。创建后提示用户："大纲文件已自动创建，请补充核心设定后继续。"
- **检查项2**：确认 `novel-creation-evo-output/[小说标题]_追踪.md`〔模板〕〔仓外〕 文件存在
  - **如不存在**：**立即自动创建追踪文件**，根据大纲内容初始化：章节进度表（全部标记为"未开始"）、人物状态表（提取大纲人物设定）、伏笔状态表（提取大纲伏笔规划）。创建后提示用户："追踪文件已自动创建并初始化。"
- **检查结论**：文件自动补齐后，**继续执行创作流程**，无需返回前一阶段

**⚠️ 重要说明**：本流程为长篇小说第1章创作的完整流程，包含准备、创作、输出、后续处理四个阶段。文件不存在时采用"自动补齐"策略，确保创作流程不中断。

**阶段二：正文创作**

**核心规则**：
- 字数：≥3500字
- 结构：开头（引入）→ 发展（冲突升级）→ 高潮 → 结尾（悬念）
- 章节结尾：强制使用悬念机制 + 固定引导句
- 必须遵循人性化写作规范（创作前确认规范在上下文中，若不在则必须重新读取 [craft/reference/humanized-writing.md](craft/reference/humanized-writing.md)；SKILL.md步骤3.2已内嵌核心规范）
- 必须遵循大师级能力系统（参见 [craft/reference/drama-storytelling.md](craft/reference/drama-storytelling.md)）

**章节节奏模板（爽文成瘾工程·长篇每章必执行）**

以3500字章节为基准，四段节奏模板——在「开头→发展→高潮→结尾」的结构内，每段的情绪任务如下：

```
0-300字    （开头）  │ 钩子锁注意力——冲突/危机/反常细节
                     │ 必须在300字内抛出本章核心冲突，不铺垫背景
300-2000字 （发展）  │ 压情绪——反派施压/困境加深/蓄力铺垫
                     │ 制造「替主角憋着」的读者债，每300字一个小信息点
                     │ 可有1-2次小爽点（微反击/小胜利），但不释放主压力
2000-3200字（高潮）  │ 爆发——打脸/反杀/揭秘/升级，快准狠
                     │ 这是本章唯一的「大情绪集中释放区」
                     │ 打脸需「当众+见证者反应+羞辱性」三要素同时到位
3200-3500字（结尾）  │ 新钩子——停在最揪心/最未知处
                     │ 只留问题不给答案；用3-2-1布局法中的最大钩子
                     │ 固定引导句：「输入「下一章」继续解锁」
```

**爽感参数校准（每章落笔前内部对齐）**：
- 本章压爽比是否达标（压抑铺垫约占60%，爆发约占30%）
- 本章是否安排了 `小爽×2-3 + 中爽×1-2 + 大爽×1` 的三级配比
- 若本章是高能章，前后是否有缓冲章（高能:缓冲 = 3:1或4:1）
- 同一反派本章是否已是第3次欺负主角（若是，必须安排反杀）

**创作要求**：
- 开头承接大纲设定，引入新情节，设置悬念
- 发展部分矛盾逐渐加剧，人物关系深化
- 高潮部分核心冲突爆发，主角面临挑战
- 结尾强制使用悬念机制，引导读者继续阅读
- 埋设1-2个新伏笔
- 至少包含一个意想不到的情节反转

## 阶段五：开篇三章情绪闭环标准

> 长篇第一章不是孤立的，它是前三章"产品说明书"的第一页。读者不需要马上看大结局，但他必须在前三章内看懂"这本书的爽点运行逻辑"——主角怎么赢、赢的时候读者感觉怎样。看懂了、感到爽了，才会继续往下翻。

### 前三章必须完成的情绪闭环

不论题材，前三章必须展示一个完整的情绪弧：

| 章次 | 核心任务 | 情绪目标 |
|---|---|---|
| 第1章 | 主角处境建立+第一个危机/压制 | 让读者"关心"主角（牵挂，不是仰视） |
| 第2章 | 主角获得力量/优势/信息 | 让读者感到"他有可能赢" |
| 第3章 | 主角利用优势完成第一场小胜 | 让读者体验到"这本书的核心爽感长什么样" |

**判断标准**：读完第三章，读者能否用一句话说出"这本书是写主角怎么X的，每次X的时候读者会感到Y"？能→闭环合格；不能→前三章结构需调整。

### 第1章在闭环中的定位

第1章的核心任务是"让读者关心主角+让他感受到压制"——不是展示主角有多强，是展示他面对的处境有多难或多有意思。读者第一次接触这本书，需要立刻产生牵挂（"他会怎么办"），不是仰视（"他好厉害"）。

与shuangwen-short-form.md §15.1联动：短篇要在第一段完成牵挂开场；长篇第1章要在前500字内完成同等任务，后续3500字完成压制建设。牵挂是所有篇幅共用的开篇目标，区别只是可用的字数预算。
