## 1. 为什么需要章节拆解表

大纲是骨架，拆解表是施工图。没有它，写作时容易：伏笔失控（埋了忘收）、剧情提前（写 high 把后面用了）、前后矛盾、节奏失控、角色状态漂移。

**规则**：长篇必须在大纲完成后、正式动笔前，将整卷逐章拆解。

## 2. 每章拆解 9 个必填维度

| 维度 | 内容 |
|---|---|
| 剧情目标 | 这章要完成什么（一句话，写不出来 = 这章不该存在） |
| 场景 | 时间 / 地点 / 在场角色 |
| 开场状态 | 承接上章结尾的状态 |
| 核心事件 | 本章关键事件（2–3 个，不超过 3 个） |
| 爽点/冲突 | 本章的爽点或冲突（每章必须有，否则删章） |
| 角色变化 | 角色在本章的状态/认知/关系变化 |
| 伏笔操作 | 埋哪些（F-X01）、收哪些（F-X02） |
| 章末钩子 | 具体钩子内容（不能写"留悬念"糊弄） |
| 衔接下章 | 下章开头要接住什么 |
| 禁区 | 本章不能做的事（重要伏笔/关键剧情必须标注） |

## 3. 伏笔管理铁律

- 每个伏笔必须有 ID：`F-卷号+序号`（如 `F-0101`）
- 埋设和回收必须配对：埋了必须标注在哪章回收
- 跨卷伏笔单独登记在「跨卷伏笔」表
- **伏笔不能埋而不收**：全书完结前所有伏笔必须回收

## 4. 节奏控制

- 高潮间隔：连续 2 章高潮后，必须有 1 章缓冲
- 铺垫不超过 3 章：连续铺垫 ≤ 3 章，必须有爽点释放
- 日常章占比：不超过总章数 30%
- 章末钩子类型轮换：不能连续 3 章用同类型钩子

## 5. 拆解流程

```
大纲完成 → 确定本卷章节范围 → 从大纲提取核心事件/高潮/钩子
   ↓
按节奏规则分配事件到各章 → 建立伏笔账本（埋设+回收配对）
   ↓
逐章填写 9 维度拆解表 → 标注禁区 → 自检
   ↓
保存为 novel-chapter-breakdown-v{卷号}.md → 进入停顿节点
```

## 6. 写时如何使用

**动笔前**：读本章拆解（9 维度）→ 检查禁区 → 检查伏笔操作 → 检查章末钩子。
**写完后**：核对剧情目标完成否 → 核对伏笔正确埋/收 → 更新伏笔账本状态（待埋→已埋→已收）。

## 7. 一章完整示例

```
## 第 3 章 章纲（卷一）

### 剧情目标
主角第一次正面撞上灭门仇家的眼线，被迫暴露底牌，逃亡开始。

### 场景
夜 / 旧城茶馆 / 主角、眼线赵九、跑堂阿福

### 开场状态
承接第 2 章：主角刚查出眼线在茶馆出没，假装茶客潜入。

### 核心事件
1. 主角偷听得知仇家三日后动手
2. 被赵九识破，短兵相接
3. 主角用禁术逼退赵九，暴露能力

### 爽点/冲突
冲突：身份暴露的生死危机；爽点：禁术初显威（铺垫已久的金手指第一次见血）

### 角色变化
主角：从"隐忍查探"被迫转为"主动逃亡"，决心升级

### 伏笔操作
埋：F-0301（赵九认出主角身上的旧伤疤，与灭门有关）
收：F-0201（第 2 章埋的"眼线在茶馆"）

### 章末钩子
赵九临死前笑："你以为跑得掉？你家那丫头……" —— 悬念+信息双钩

### 衔接下章
主角意识到家人也被盯上，连夜赶回

### 禁区
本章不能揭露仇家真名（卷三才揭）；不能让主角秒杀赵九（需付出代价）
```

## 8. 自检

- [ ] 每章都有剧情目标（一句话能说清）？
- [ ] 每章都有爽点/冲突（否则已删章）？
- [ ] 每个伏笔有 ID 且配对回收章？
- [ ] 节奏无连续 3 章同型钩子 / 连续 2 章高潮无缓冲？
- [ ] 禁区已标注？
