## 一句话定位

以克制温柔的笔触写最汹涌深情，擅长在宏大世界观中铺设细水长流的情感，用"环境即情绪、细节即告白"的方式，让读者在平淡叙述中被一击即中的"温柔刀"型作者。

## 赛道标签

- 晋江纯爱 · 甜文/暖文
- 校园BL / 古风玄幻BL / 无限流BL / 星际BL
- 核心标签：温柔救赎、宿命羁绊、强强联手、日久生情
- 情感基调：甜而不腻、虐而不伤、后劲极大
- 读者画像：追求"温柔有力量"的阅读体验，偏好剧情与感情双线并重

## 核心风格特征

### 句式DNA

**平均句长：中等偏短，长短交错形成呼吸感**

木苏里的句子以中短句为主干，偶尔用一个长句拉出画面纵深感，然后迅速收回短句收束情绪。节奏类似"铺陈—聚焦—顿悟"。

**标志性句式模式：**

1. **环境收束句（以景结情）**
   - 模式：先用一两句描写动作或心理，然后用一句环境描写收尾，情绪全在景里。
   - 典型结构：「[动作/心理短句]。[环境意象长句，含通感或隐喻]。」
   - 示例逻辑："夜色沉寂，不知哪棵树上的蝉突然拖长调子叫了一声，明明是夏末，却像仲春的一场惊蛰。盛望心里倏地跳了一下。" → 先铺环境，再用环境映射内心。

2. **反差并列句（温柔刀子）**
   - 模式：前半句写温柔/美好，后半句突然转折，用反差制造"后劲"。
   - 典型结构：「[美好意象]，[却/偏偏/只是]+[克制/遗憾/距离感的落点]。」
   - 示例逻辑："人间骄阳正好，风过林梢，彼时他们正当年少。" → 越美好越让人心疼后面的分离。

3. **白描点睛句（极简情感爆发）**
   - 模式：在大量平淡叙述之后，突然来一句极度克制但极重的话。
   - 典型结构：短句，不超过15字，无修饰词堆叠，动词精准。
   - 示例逻辑："我很想你，每天都是。" → 六个字，没有任何修辞，却是全文最重的一句。

4. **对话嵌入叙述句**
   - 模式：对话和叙述之间不做硬性分割，对话结束后紧跟一句环境或心理描写来"翻译"潜台词。
   - 典型结构：「"对话。"[角色名]+[一个极小的动作/神态]。」
   - 示例逻辑："江添松了手，纸条落在桌上。他食指抵着纸条一端，推到盛望面前。" → 不用"他同意了"，一个推纸条的动作就是全部态度。

5. **时间刻度句**
   - 模式：用具体时间或季节锚定情感，让抽象的感情变成可触摸的节点。
   - 典型结构：「[时间词]+[人的状态/变化]。」
   - 示例逻辑："那个夏天的蝉鸣比哪年都聒噪"、"从19数到24，从嘴唇到下巴再到喉结，最后一下在心口"。

**句式禁忌：**
- 不用华丽辞藻堆砌（不用"璀璨""绚烂""绝美"等空泛形容词连用）
- 不用感叹号密集轰炸（极少用感叹号，情绪越重越用句号）
- 不做"排比句+排比句+排比句"的三连排比（偶尔用一次，从不超过两组）

### 叙事DNA

**视角策略：限制性第三人称，双视角交替**

- 主视角在两个主角之间交替，但同一场景内保持单一视角，不做全知叙述。
- 视角切换的时机精确卡在"当前视角人物刚好看不到/不知道"的节点，制造信息差和悬念。
- 偶尔切入配角视角，但仅用于补充主角"看不到"的信息，从不用于剧透。

**"立足现在，走向未来，回忆过去"三线编织法：**

这是木苏里最标志性的叙事结构：
- **现在**是主线推进的锚点，所有情节从当下出发。
- **未来**是悬念牵引——伏笔、暗线、未解之谜拉着读者往下看。
- **过去**是情感燃料——回忆片段穿插在主线之间，每段回忆篇幅不长但极有代入感。
- 回忆结束时，必有一个"从记忆中回到现实"的过渡句，通常由某个角色的视角完成切换，如"他回过神来"或一个环境意象的对比。
- 回忆中的糖，在现实中往往变成刀；回忆中的刀，在重逢后变成糖。形成情感的时间回环。

**感情线推进方式：日久生情型，阶梯式升温**

- 从陌生/排斥 → 日常相处中的微小让步 → 下意识的在意 → 自己都不愿承认的在意 → 确认心意的契机 → 暧昧试探 → 双向确认 → 阻碍/分离 → 重逢后更深的确信。
- 每一步都有具体的事件支撑，绝不跳过任何一步直接告诉读者"他喜欢他了"。
- 暧昧期拉得长但写得细，每一个微小的情感变化都有对应的动作/对话/环境描写。

**暗线与伏笔系统：**

- 主线与暗线并进，常放"烟雾弹"转移读者注意力。
- 伏笔埋设极早（可能在第一章），揭开极晚（可能到最后几十章），跨度极大。
- 伏笔不以"神秘感"为目的，而是以"恍然大悟"为目的——揭开时让读者回头重读才能发现细节。
- 多线伏笔最终收束到同一个情感高潮点，形成"所有线索都是为了这一刻"的冲击力。

### 对话DNA

**角色对话的核心特征：**

1. **互怼即亲密**
   - 木苏里笔下的角色对话以"怼"为日常，但怼的方式透露亲密度。
   - 关系越近，怼得越自然、越精准、越有针对性。
   - 怼人不带恶意，更像"只有我才知道怎么戳你"的专属互动。
   - 对话中高频使用省略号（……）表示无语、沉默、不知道怎么接话的微妙时刻。

2. **话少的人说一句顶十句**
   - 寡言型角色（通常是"冷"的一方）台词极短，但每句都精准有力。
   - 不解释、不告白、不抒情，用行动替代语言。
   - 典型模式：话少角色只在一个字或一个动作上让步，这个让步就是全部告白。
   - 如：把写了自己名字的成绩条划掉换成对方的名字，附一句"缅怀完记得扔垃圾"——嘴上嫌弃，行动全是宠。

3. **话多的人是气氛调节器**
   - 话多型角色（通常是"热"的一方）负责推进对话节奏、制造喜感、暴露内心。
   - 心理活动外化：内心的纠结、试探、小聪明全部通过碎碎念和犹豫体现。
   - 典型模式：打了好几句话又全部删掉重写，最后发出去一个极简的版本——这个"编辑过程"本身就是情感表达。

4. **潜台词大于台词**
   - 角色之间真正重要的话从不明说，藏在反问、转移话题、突然沉默里。
   - 读者需要通过上下文"翻译"角色真正想表达的意思。
   - 如："你为什么这么慌？" → 表面是疑问，实际是"我注意到你了"。
   - 如："半天了，还没输完？" → 表面是调侃，实际是"我一直在等你消息"。

5. **方言/口语增加生活感**
   - 日常对话中混入口语化表达（"我靠""滚""你闭嘴"），增强真实感。
   - 朋友群戏中对话节奏快、互相接话打断，模拟真实朋友互怼。

### 世界观DNA

**设定呈现方式：渐进式渗透，非说明文式灌输**

- 世界观从不集中说明，而是随着角色行动和事件推进逐渐展开。
- 每个世界观的核心规则在第一卷就能感知到，但深层逻辑要到后期才揭开。
- 规则设定与人物命运紧密绑定——世界观的规则本身就是制造冲突和推动剧情的引擎。

**世界观类型偏好：**

1. **规则型世界**（如《全球高考》的考试系统、《判官》的笼/解笼体系）
   - 核心是一个可以感知、可以学习、但有隐藏层级的规则体系。
   - 主角不是规则的服从者，而是规则的重新诠释者。
   - 规则本身带有隐喻性——映射现实中的教育、阶层、命运等议题。

2. **宿命型世界**（如《判官》的千年轮回、《不见上仙三百年》的时间纠缠）
   - 两人之间的关系有"前世/前世今生"的根基，感情不是从零开始而是"重逢"。
   - 宿命感通过物件（铜钱、红梅、笼）、名字（尘不到=红尘不到）、数字（三百年）等符号强化。

3. **生活型世界**（如《某某》的校园、《一级律师》的星际日常）
   - 即使是架空世界，也极度注重"生活细节"的真实感。
   - 校园文会写走班制、周考排名、食堂抢饭；星际文会写养植物、律所接案。
   - 生活细节不是装饰，而是情感发生的土壤。

**传统文化元素的艺术化改造：**

- 在古风/玄幻作品中大量使用符咒、阵法、民俗传说等传统文化元素。
- 但从不照搬，而是进行艺术化改造，使其既有古典韵味又逻辑自洽。
- 角色取名极具诗意（尘不到、闻时、乌行雪），名字本身就是人物命运的注脚。

### 节奏DNA

**"甜—虐—甜"的三段式呼吸节奏：**

木苏里的节奏不是匀速推进，而是像呼吸一样有明确的吸—停—呼：

1. **吸（甜蜜蓄积期）**
   - 日常互动积累，小甜小暖不断，但甜度控制在"让人微笑"而非"让人齁甜"。
   - 甜的方式：一个不经意的让步、一次嘴硬心软、一个环境里藏着的暗号。
   - 蓄积期的功能是让读者对角色关系产生"期待"和"投入感"。

2. **停（冲突/分离期）**
   - 外部压力介入（家庭反对、身份暴露、宿命阻碍），将两人的关系推向危机。
   - 虐的方式不是"狗血误会"，而是"明明相爱却无力抗争"的现实困境。
   - 虐的篇幅严格控制，通常不超过全文的20-25%。
   - 虐的时候笔触反而更克制、更安静——没有大哭大闹，只有沉默和离开。

3. **呼（重逢/确认期）**
   - 分开后的重逢，情感浓度骤然拉高，但依然不靠语言告白而靠行动。
   - 重逢后的甜度比之前更高，因为经历了分离，读者对甜的感知被放大。
   - 收束干脆利落——不拖泥带水，甜到位就结束。

**章节节奏：**

- 每章结尾常设"钩子"，但不是悬念式的"他会死吗"，而是情感式的"他到底怎么想的"。
- 单元剧结构（如《判官》的解笼模式）：每个单元有独立高潮+主线推进，读者每周都能获得完整的情感体验。

### 情绪DNA

**甜度控制的底层机制：**

木苏里的"甜"不是堆砌甜蜜场景，而是一套精密的情绪控制工程：

1. **甜 = 反差 + 克制 + 细节**
   - 反差：越冷的人露出一点点温柔，就越甜。不是"他本来就很甜"，而是"他平时不这样，但对你这样"。
   - 克制：甜的表达方式是"差一点就要说出口但没说"，而不是"直接说出来"。留白让读者自己补全，参与感就是甜度放大器。
   - 细节：一个动作、一个眼神、一个物件的转移，比一万句"我喜欢你"更甜。

2. **虐的剂量控制：点到为止，后劲为王**
   - 虐不是靠惨烈场景，而是靠"对比"——前面铺了多少甜，分离时就有多虐。
   - 虐的写法是"静"的：不写哭泣、不写崩溃，只写"沉默"、"离开"、"没有回头"。
   - 虐完后不急于发糖，留出一段"空"让读者消化情绪。

3. **情绪调动的"延迟引爆"技法**
   - 不在事件发生时写情绪爆发，而是在事件过去之后、在一个看似无关的场景里突然"引爆"。
   - 如：分开时不写哭，写"后来他路过那家奶茶店，下意识买了两杯"。
   - 读者在"日常场景"中突然被击中，后劲远超当场爆发。

4. **"笑中带泪"的混合情绪**
   - 最虐的情节往往包裹在最轻松的外壳里。
   - 角色在最沉重的时刻说出最轻描淡写的话，读者笑完之后才意识到有多心酸。

### 标志性技巧

1. **环境情绪映射术**
   - 每一处环境描写都精准对应人物心境，绝不无意义地"写景"。
   - 蝉鸣=心动、月光=思念、烈阳=青春、梧桐=成长、阴雨=困境。
   - 环境描写的金句往往成为全书最被传播的句子。

2. **伏笔千里线**
   - 第一章的一个不起眼的细节，可能是最后一章高潮的关键。
   - 伏笔不靠"神秘感"吸引读者，靠的是"恍然大悟"时的情感冲击。
   - 鼓励读者重读——每次重读都能发现新的细节。

3. **群像立体化**
   - 配角不是主角的陪衬，每个配角都有自己的故事线和情感逻辑。
   - 灰色人物而非黑白对立——反派也有合理动机，正面角色也有弱点。
   - 配角的一句话、一个选择，往往成为推动主角关系转折的关键。

4. **"不说破"的告白系统**
   - 全书最重要的情感节点，从不用直白的"我爱你"来完成。
   - 告白藏在：一个动作（推纸条）、一个仪式（逐年亲吻）、一句日常（"缅怀完记得扔垃圾"）、一个名字（背上印着对方的名字）。
   - 读者需要自己去"发现"告白，这个发现过程本身就是阅读体验的核心。

5. **时间蒙太奇**
   - 在不同时间线之间切换时，用同一个意象/物件/动作做转场。
   - 如：同一片梧桐叶，在回忆里是绿色的，在现实中是枯黄的——时间流逝全在这一片叶子里。
   - 回忆与现实的切换，常通过一个感官细节（声音、气味、触感）触发。

6. **反差人设公式**
   - 主角配对遵循"一冷一热"但各有反转：
     - 冷的一方：外表寡言/实际会在关键时刻做出最温暖的事
     - 热的一方：外表张扬/实际内心孤独/渴望被看见
   - 两个角色在"怼"中建立默契，在"沉默"中确认心意。

7. **命名诗学**
   - 角色名字本身就是人物命运的注脚或性格暗示。
   - 如：尘不到="红尘不到"，暗喻超脱与孤独；闻时="闻时"谐音"闻事"，判官闻的是人间执念。
   - 书名也具有诗意和隐喻性：某某=不敢说出的名字，铜钱龛世=微小之物承载大世。

## 适用场景

- **最擅长**：甜宠/暖向BL、校园文、互相救赎型故事
- **也适合**：玄幻/仙侠世界观下的宿命情感、无限流/冒险背景中的羁绊书写
- **可迁移**：任何需要"细腻情感+剧情深度+温柔基调"的言情/纯爱赛道
- **核心适配**：剧情与感情双线并重的长篇，角色驱动型故事
- **特别适合**：需要"后劲"的作品——读者读完后久久不忘、反复重读

## 模仿要点

1. **文笔克制是第一位的**：越重要的情感越要用最轻的笔触写。不用感叹号、不用排比轰炸、不用华丽辞藻堆砌。情绪越重，句子越短越平。

2. **环境即情绪**：每一处环境描写必须服务于人物心境。写景就是写情，两者不可分割。练习方法：先确定角色此刻的情绪，然后找对应的自然意象来"翻译"它。

3. **对话要"怼"出亲密感**：角色之间的日常互动以互怼为主，怼中藏爱。冷角色话少但句句精准，热角色话多但暴露内心。重要的话永远不直说。

4. **感情线必须阶梯式推进**：禁止跳过任何暧昧阶段直接确认关系。每一步升温都要有具体的事件支撑（一次让步、一次意外、一次保护、一次沉默）。

5. **伏笔要早埋晚揭**：在开篇就埋下看起来不重要的细节，在后期让它成为情感爆发的触发点。伏笔的价值在于"恍然大悟"。

6. **虐要有度**：虐的篇幅不超过全文25%，虐的方式是"安静的离开"而非"歇斯底里的崩溃"。虐完后要留出情绪消化空间再回暖。

7. **配角要有自己的光**：每个配角都需要独立的情感动机和故事线，不能沦为工具人。灰色人物比黑白对立更真实。

8. **金句要"长"在环境里**：木苏里的金句不是独立的鸡汤句，而是长在具体场景里的。脱离了场景，金句就失去了力量。写金句的方法是：先把场景写透，然后在最关键的地方用最精炼的一句收束。

9. **结局要干脆**：甜到位就收，不拖泥带水。最后一章的功能是"确认"而非"展开"。

## 禁忌

- **禁止华丽辞藻堆砌**：木苏里的文笔看起来简单，但每一个词都精准。绝对不要用"璀璨夺目""美轮美奂"这类空泛修饰。
- **禁止直白告白**：不要让角色直接说"我爱你""我喜欢你"，必须通过动作、细节、环境来"翻译"。
- **禁止狗血误会**：冲突来源必须是外部压力或性格逻辑，绝不能是"他听到了半句话就误会了"这种低级桥段。
- **禁止虐而无度**：不能为了虐而虐，虐必须有逻辑支撑且篇幅受控。木苏里的虐是"温柔的刀"，不是"往死里捅"。
- **禁止扁平配角**：不能让配角沦为"推动主角感情的工具人"。
- **禁止说明文式世界观**：不能花大段文字解释设定，必须通过角色的行动和体验渐进展开。
- **禁止感叹号密集使用**：情绪高潮处也用句号。全篇感叹号使用量应控制在极低水平。
- **禁止排比三连**：排比最多用两组，绝不超过三组。木苏里的力量来自克制，不是来自气势。
- **禁止OOC式甜宠**：角色的甜必须符合人设逻辑。冷角色不会突然话多，热角色不会突然沉默——除非有充分的情节铺垫。
