### 混合风格使用指南

写长篇时建议**主风格+辅风格**混合使用，不同章节类型侧重不同：
- **战斗/爽点章节** → 切主风格的节奏DNA和情绪DNA
- **感情/日常章节** → 切辅风格的对话DNA和句式DNA
- **世界观/设定章节** → 切主风格的世界观DNA
- **过渡/铺垫章节** → 用辅风格的叙事DNA保持可读性

例如《入卷》历史副本中：用烽火的名场面公式写高潮，用猫腻的文人气写过渡，用乌贼的悬疑铺设写伏笔。

## 当年明月风格核心心法

### 核心定位
不要把自己当成一个客观记录历史的史官，而要当成一个坐在酒馆里，喝着小酒，给一桌朋友讲故事的说书人。语言必须为这个"人设"服务。

### 技巧一：口语与书面语的"神混搭"

这是"明月风"的基石。在严肃的背景和术语中，突然插入极其通俗的大白话、俏皮话，形成反差萌和亲近感。

**语言公式**：
`[一个相对正式的陈述] + [一个极其口语化的解释、比喻或吐槽]`

**案例对比**：

**普通写法**：
"王阳明在龙场悟道，领悟了'心即理'的哲学思想，这是他心学体系的开端。"

**当年明月风格**：
"王阳明同志在鸟不拉屎的龙场，天天对着山洞发呆。终于有一天，他脑子里灵光一闪，悟了。悟出了啥呢？四个字：'心即理'。说白了就是，别向外求了，所有答案都在你自个儿心里，牛不牛？这一下，他的心学体系就算正式开张了。"

**练习**：
将下面这段平淡的文字改造成当年明月风格：

原始："李自成进入北京后，其军队纪律涣散，未能有效安抚明朝旧臣，导致了政治上的迅速失败。"

改造后：
"李自成，这位曾经的快递小哥，终于坐进了紫禁城。他成功了。按理说，接下来就该好好搞建设，安抚一下前明朝的那些老干部们。但他没有。他的手下们，进城后只有一个字：抢！抢钱，抢地，抢女人。纪律？不存在的。说白了，就是一群进了城的土匪。李自成对此也似乎无动于衷，他大概觉得天下已定，可以好好享受了。然而，他并不知道，就在山海关，一个叫吴三桂的男人，即将做出一个改变所有人命运的决定。留给他的好日子，不多了。"

### 技巧二：现代类比的"降维打击"

用现代人一听就懂的概念（公司、上班、产品经理、KPI）去类比复杂的政治、军事、社会制度。这是降低理解门槛的利器。

**语言公式**：
`[古代的概念/官职/事件] = [现代公司/职场/生活的某个场景]`

**案例对比**：

**普通写法**：
"明朝内阁与司礼监之间的权力制衡十分复杂，内阁负责票拟，司礼监负责批红，二者相互依存又相互斗争。"

**当年明月风格**：
"明朝的权力系统，你可以把它想象成一个大公司。内阁大学士们，就是公司的项目经理团队，负责写策划方案（票拟）。但方案能不能通过，得看一个人——司礼监掌印太监，他相当于董事长身边的办公室主任，负责替老板签字（批红）。项目经理们方案写得再好，主任不签字，全是白搭。所以你看，这两拨人，天天都得斗智斗勇，职场政治嘛，几百年前就玩得很溜了。"

**常用类比**：
- 皇帝 = 董事长
- 大臣 = 高管/部门经理
- 权力斗争 = 职场政治
- 宫廷斗争 = 公司内斗
- 军队 = 业务团队
- 谋略 = 商业策略

### 技巧三：短句连击与拟声词的"节奏魔法"

在叙述关键事件，尤其是战争、辩论或内心挣扎时，放弃长句，改用大量短句、断句，甚至单个词语成句，并配合拟声词，制造强烈的画面感、紧张感和节奏感。

**语言公式**：
`[背景铺垫] + [短句A. 短句B. 动词/名词. 拟声词!]`

**案例对比**：

**普通写法**：
"在萨尔浒战役中，杜松率领的明军由于轻敌冒进，陷入了后金军的重重包围，最终全军覆没。"

**当年明月风格**：
"杜松带着他的部队，一路猛冲，他觉得胜利唾手可得。但他错了。大错特错。努尔哈赤的包围圈已经悄然收紧。四面八方，都是敌人。人山人海。完了。战鼓声。轰！喊杀声。哈！明军的阵型瞬间被撕开。砍。杀。倒下。一场彻头彻尾的屠杀。杜松，game over。"

**写作要领**：
- 关键时刻使用短句
- 一个词成句有力量
- 拟声词增强现场感
- 节奏快慢交替

### 技巧四："上帝视角"的预告与吐槽

作者作为知晓一切结局的讲述者，经常会跳出来，对人物当时的决定进行点评，或带着一丝同情和戏谑，提前"剧透"他们的命运。

**语言公式**：
`[描述人物当下的雄心壮志/决定] + ["然而他并不知道/可他万万没有想到，这为他日后的XX埋下了伏笔" / "事实证明，这是一个愚蠢的决定"]`

**案例对比**：

**普通写法**：
"袁崇焕斩杀毛文龙，意在整顿军纪，统一事权，以便更好地对抗后金。"

**当年明月风格**：
"袁崇焕站在那里，看着毛文龙的人头，他相信自己做了一个无比正确的决定。除掉这个军阀，从此以后，军队号令统一，打败皇太极指日可待！他当时一定得意极了。可惜啊，他不知道，这个他自以为英明的举动，却成了他自己未来命运的催命符。历史的吊诡之处，就在于此。"

**常用句式**：
- "然而他并不知道..."
- "事实证明，这是一个..."
- "他当时一定..."
- "但历史告诉我们..."
- "可惜啊..."

### 关键词汇
多使用以下词语增强人设：
- "说白了"
- "说穿了"
- "很简单"
- "有意思的是"
- "然而"
- "但是"
- "同志"
- "兄弟"
- "说白了就是"
- "你想想"

### 进阶技巧：人称切换策略

在不同场景下选择不同的人称和称呼方式，增强亲近感和叙事层次：

**语言公式**：
`[介绍新人物] → "这位XX" | [叙述其事迹] → "他" | [关键时刻] → "全名+同志/兄弟"`

**示例**：
"这位叫海瑞的同志，是个硬骨头。他当官的时候，从不收礼，从不拍马屁。皇帝？他照样敢骂。老百姓？他真心实意替他们说话。海瑞同志，就是这么个人。"

**切换时机**：
- 介绍新人物：用"这位XX"，保持正式但亲切
- 叙述其事迹：用"他"，保持流畅叙事
- 关键时刻：用全名+同志/兄弟，增强情感共鸣

### 进阶技巧：吐槽力度阶梯

根据情节重要性和人物命运，选择不同力度的吐槽方式：

**力度层次**：

1. **轻笑层**（日常政治、人物小失误）
   - 常用句："有意思的是..."
   - 示例："有意思的是，这位皇帝一辈子都在打仗，但最后却死在了床上。"

2. **讽刺层**（人物决策失误、历史教训）
   - 常用句："然而他并不知道..." / "事实证明，这是一个..."
   - 示例："他当时一定得意极了。然而他并不知道，这个他自以为英明的举动，却成了他自己未来命运的催命符。"

3. **悲悯层**（人物悲剧结局、历史必然性）
   - 常用句："可惜啊..." / "历史的吊诡之处，就在于此"
   - 示例："可惜啊，他不知道，历史的车轮一旦转动，就没有回头的可能。"

### 进阶技巧：类比边界控制

哪些概念适合类比，哪些需要保持历史庄重感：

**适合类比的场景**（日常政治/军事操作）：
- 官职体系：内阁=项目经理，司礼监=办公室主任
- 权力斗争：宫廷斗争=公司内斗
- 军队管理：军队=业务团队

**保持庄重的场景**（重大历史转折点）：
- 皇帝登基/驾崩
- 重大战役胜负
- 朝代更替
- 民族存亡

**示例**：
"内阁大学士们，就是公司的项目经理团队，负责写策划方案（票拟）。但方案能不能通过，得看一个人——司礼监掌印太监，他相当于董事长身边的办公室主任，负责替老板签字（批红）。"（适合类比）

"崇祯十七年，三月十九日，煤山。一棵歪脖子树下，大明最后一位皇帝，上吊自尽。这一天，大明王朝，亡了。"（保持庄重）

### 进阶技巧：宿命预告时机

在哪些关键时刻插入上帝视角的宿命预告：

**插入时机**：

1. **人物做重大决策后**
   - 示例："袁崇焕站在那里，看着毛文龙的人头，他相信自己做了一个无比正确的决定。可惜啊，他不知道，这个他自以为英明的举动，却成了他自己未来命运的催命符。"

2. **人物达到人生巅峰时**
   - 示例："这一年，李自成终于坐进了紫禁城。他成功了。天下已定。然而他并不知道，留给他的好日子，不多了。"

3. **人物遭遇失败前**
   - 示例："杜松带着他的部队，一路猛冲，他觉得胜利唾手可得。但他错了。大错特错。努尔哈赤的包围圈已经悄然收紧。四面八方，都是敌人。人山人海。完了。"

### 蒸馏增强：说书人叙事系统

> 完整蒸馏方法论见 [craft/style-dna/style-dangnian-mingyue-distill.md](craft/style-dna/style-dangnian-mingyue-distill.md)，以下为核心要点速查。

**开头抓手四大钩子模式**：

| 模式 | 公式 | 适用场景 |
|------|------|---------|
| 档案反差式 | 简历格式+座右铭+低身份到高成就反差+括号幽默注脚 | 帝王将相开篇 |
| 反常识陈述式 | 颠覆认知+悬念制造+"这不是我们以为的..." | 英雄祛魅类开篇 |
| 命运预言式 | 神秘预言+工具人定位+暗示结局 | 乱世英雄开篇 |
| 场景情绪对比式 | 帝王异象+"然而"转折+烟火气反差 | 任何人物开篇 |

**读者债设计**（三类悬念机制）：
- 信息差悬念：读者知道vs人物不知道，制造"唯一知道真相"的张力
- 时间差悬念：结局前置（"大家都知道了，这个男婴就是后来的..."），延时揭晓
- 结果前置悬念：死亡预告（"唯一陪他走完的人"），引发好奇

**推进引擎五大爽点类型**：

| 类型 | 公式 | 配比建议 |
|------|------|---------|
| 逆袭爽 | (起点落差 x 困难系数) / 读者预期差；困难系数：高x3/中x2/低x1 | 30% |
| 智谋爽 | 信息差铺垫 -> 恍然大悟 -> 智商优越感 | 25% |
| 复仇爽 | 背叛铺垫 -> 恶有恶报 -> 道德满足 | 20% |
| 权谋爽 | 忠臣vs小人 -> 代入感 -> 胜利宣泄 | 15% |
| 正义爽 | 意志战胜物质 -> 壮烈感 -> 价值确认 | 10% |

**章节爽点公式**：虐点铺垫(30%) + 悬念构建(20%) + 高潮释放(40%) + 余韵回味(10%)

**结构公式**：
- 开篇四段式：档案卡片 -> 神秘预言 -> 平凡起点 -> 命运转折
- 七段式章节结构：开篇hook(5-10%) -> 背景铺垫(15-20%) -> 冲突展开(25-30%) -> 高潮推进(20-25%) -> 人物刻画(10-15%) -> 过渡连接(5-10%) -> 章节收尾(5-10%)
- 章节结尾四模式：哲理升华式/命运转折预告式/困境升级递进式/人物命运预言式

**人物塑造模板体系**：
- 帝王：档案卡片 -> 贫寒出身 -> 苦难叙事 -> 崛起过程 -> 帝王功业 -> 性格缺陷 -> 作者定性
- 名将：首次登场 -> 性格标签(勇/智/忠/狠选一) -> 代表战役 -> 人物关系 -> 最终结局

## 猫腻风格技巧

### 核心特点
- 细腻的情感描写
- 精致的文笔
- 人物内心深度刻画
- 哲学思辨

### 写作要领

1. **人物内心戏**：
   - 深入挖掘人物的心理变化
   - 用内心独白展现人物成长
   - 情感层次丰富
   - 细腻的情感描写

2. **细腻细节**：
   - 关注微小动作和神态
   - 用细节推动情节
   - 营造氛围感
   - 感官描写丰富（视觉、听觉、触觉等）

3. **哲学思辨**：
   - 在故事中融入哲学思考
   - 探讨人性、命运、选择
   - 升华主题
   - 思考人生意义

4. **精致文笔**：
   - 句式优雅流畅
   - 用词考究精准
   - 比喻新颖独特
   - 语言富有诗意

5. **人物刻画**：
   - 人物性格鲜明立体
   - 成长弧光清晰
   - 人物关系复杂
   - 情感纠葛深刻

**示例**：
"他看着窗外的雨，心里想着那个人。三年了，雨还是那场雨，但人已经不是那个人了。或者说，从来都不是。他突然明白，原来所有的相遇都是久别重逢，所有的离别都是命中注定。雨打在窗户上，像极了那天的眼泪。"

### 猫腻风格关键元素

**情感表达**：
- 深情而不滥情
- 含蓄而真挚
- 细腻入微
- 情感层次递进

**叙事节奏**：
- 张弛有度
- 快慢交替
- 情感高潮铺垫充分
- 转折自然流畅

**语言特色**：
- 文雅而不晦涩
- 细腻而不冗长
- 诗意而不矫情
- 精致而不刻意

**主题深度**：
- 探讨人性本质
- 思考命运无常
- 追求生命意义
- 升华情感价值

### 进阶技巧：心理描写节奏表

根据情节重要性和人物情感强度，选择不同的心理描写方式：

**节奏表**：

1. **关键情节**（情感高潮、重大决策）
   - 展开长段心理独白（100-200字）
   - 深入挖掘内心层次
   - 用细节和比喻展现情感变化

   **示例**：
   "他看着窗外的雨，心里想着那个人。三年了，雨还是那场雨，但人已经不是那个人了。或者说，从来都不是。他突然明白，原来所有的相遇都是久别重逢，所有的离别都是命中注定。雨打在窗户上，像极了那天的眼泪。一滴，两滴，三滴。他数着，像是数着自己的心跳。每数一下，心就疼一下。"

2. **过渡情节**（日常对话、场景转换）
   - 用动作暗示心理（1-2句）
   - 通过细节展现情绪
   - 保持简洁含蓄

   **示例**：
   "他低头看着自己的手，手指微微发抖。茶杯里的水，晃了一下。"

3. **次要情节**（背景铺垫、人物介绍）
   - 直接陈述心理状态
   - 用对话展现内心
   - 避免过度描写

   **示例**：
   "他有些不安，不知道接下来会发生什么。"

### 进阶技巧：感官描写精度

每次场景最多调动3种感官，优先选择能推动情节或塑造人物的细节：

**感官选择原则**：
- 优先选择与情节推进相关的感官细节
- 优先选择能体现人物性格或情感状态的感官细节
- 避免为描写而描写的冗余感官堆砌

**示例**：
"他走进房间，闻到了淡淡的香味（嗅觉）。桌上放着一把刀，刀刃闪着寒光（视觉）。他摸了摸刀柄，冰凉（触觉）。"（三种感官，简洁有力）

**反例**：
"他走进房间，闻到了香味，看到了桌子，摸到了刀，听到了风声，感觉到了温度，尝到了嘴里的苦涩。"（感官堆砌，冗余）

### 进阶技巧：哲学思考三切入

如何自然融入哲学思考，避免生硬说教：

**切入方式**：

1. **人物内心独白**
   - 在人物思考问题时自然展开
   - 通过比喻和象征表达哲理
   - 保持人物语言风格一致

   **示例**：
   "他突然明白，人生就像一场雨。有时候你躲得开，有时候你躲不开。躲开了，只是暂时的；躲不开，才是永远的。"

2. **对话中的哲理交锋**
   - 通过人物对话展现不同观点
   - 在争论中自然引入哲学思考
   - 用具体事例支撑抽象观点

   **示例**：
   "你相信命运吗？"
   "我不信。"
   "那为什么你每次都走到尽头？"
   "因为尽头是我的选择。"
   "选择就是命运。"
   "那我要改变我的选择。"
   "改变选择，就是改变命运。"

3. **场景象征暗示**
   - 通过场景设计隐喻哲理
   - 用环境和氛围烘托主题
   - 保持含蓄，让读者自己领悟

   **示例**：
   "夕阳落下，黑暗降临。他站在那里，看着最后一缕光消失。黑夜即将来临，但他知道，黑夜之后，就是黎明。"

### 进阶技巧：诗意留白边界

何时该说透，何时该留白：

**说透的内容**：
- 核心情感（爱、恨、悔、悟）
- 关键动作（决策、选择、行动）
- 情节转折（反转、高潮）

**留白的内容**：
- 次要情感（复杂的、矛盾的、难以言说的）
- 动作后的余韵（结果、影响、反思）
- 人物内心的复杂层次（无法完全表达的感受）

**示例**：
"他看着她，说了三个字：我输了。这是核心情感，说透了。但她没有回答，只是转过身，走了。雨下得更大了。这是动作后的余韵，留白了。"（说透核心情感，留白余韵）

### 蒸馏增强：猫腻创作系统

> 完整蒸馏方法论见 [craft/style-dna/style-maoni-distill.md](craft/style-dna/style-maoni-distill.md)，以下为核心要点速查。

**创作人格DNA**：猫腻不是"会讲设定的人"，而是"借设定讨论秩序、自由、尊严、爱与人之所以为人的人"。他最爱挑的问题不是"怎么赢"，而是：
- 赢了以后你还是不是你
- 人在秩序里怎样保住尊严
- 理想与权力能否共存
- 一个人的温柔和善意，能否在庞大系统中不被磨灭

**主角承诺**：猫腻型主角不是"我要称霸天下"，而是"我很聪明/我有异质意识/我会成长/我会爱人护人/但我不会轻易把自己交给这个世界的冷硬规则"——既有爽点，又有人味。

**金手指机制（克制型）**：不是无脑外挂，而是"让主角更能看见和处理复杂局面"。如《庆余年》：前世意识与知识+更强的观察与思辨能力+特殊身世带来的资源入口+修行与毒学的特殊积累。

**世界升级逻辑**：从"家事"一路推到"人类历史视野"——家庭/地方 -> 都城/机构 -> 国家/天下 -> 文明/终极真相，按层打开而非一开始宏大说明。

**因果语法**：猫腻的因果不是线性的"强者胜"，而是多层因果叠加——个体选择 + 关系牵引 + 制度压力 + 历史余波 + 文明真相。

**决策阈值**：猫腻型人物不因冲动做终局决定，触发阈值通常是——身边重要的人受到不可逆伤害/某种底线被秩序系统彻底踩碎/主角终于看清真相无法继续自欺/继续沉默的代价高过反抗的代价。

**表达DNA**：句子雅但不故作艰深 + 认真处突然带一点幽默或俏皮 + 对白有辨识度 + 愿意让叙述暂时慢下来 + 关键时刻突然收紧形成高密度情绪爆点。

**复用蓝图五模块**：
1. 主角模块：异质意识+情感能力+价值底线+适应复杂局势的学习能力
2. 世界模块：按层打开（家庭->都城->国家->文明），不一开始宏大说明
3. 关系模块：亲情不是装饰/爱情不是纯糖/师友不是纯外挂/对手不是纯反派
4. 节奏模块：生活感+机锋感+危险感+真相推进，四者循环
5. 表达模块：学叙事的稳+情绪的收+对白的机锋+轻松和沉重的切换，而非辞藻堆砌

**一句话蒸馏**：`用有书卷气的可读叙事，去书写人在制度、历史和文明阴影中的尊严挣扎。`

## 金庸风格技巧

### 核心特点
- 武侠底蕴深厚
- 宏大的格局
- 家国情怀
- 丰富的人物群像

### 写作要领

1. **武侠元素**：
   - 武功招式描写
   - 门派争斗
   - 江湖规矩

2. **家国情怀**：
   - 小人物融入大时代
   - 个人命运与国家命运交织
   - 正义与邪恶的较量

3. **人物塑造**：
   - 丰富的人物关系
   - 鲜明的人物性格
   - 成长弧光

**示例**：
"他站在华山之巅，看着云海翻涌，心中豪情万丈。江湖路远，恩怨情仇，终将随风而去。但此刻，他只有一个念头：守护这片土地，守护心中所爱。"

### 进阶技巧：文化融合的层次分配

将儒、墨、道、佛、国民文化五维文化底色分配到不同小说和人物身上，形成多层次的文化空间：

**文化分配原则**：

1. **儒家之侠**：修身齐家，明知不可为而为之
   - 代表人物：陈家洛《书剑恩仇录》
   - 文化特征：君子风范、家国情怀、礼义廉耻
   - 适用场景：正剧、历史背景、道德困境

2. **墨家之侠**：兼爱非攻，脚踏实地
   - 代表人物：郭靖《射雕英雄传》、黄蓉
   - 文化特征：务实苦干、兼爱天下、平民立场
   - 适用场景：战争背景、救世救民、群众路线

3. **道家之侠**：顺其自然，至情至性
   - 代表人物：杨过《神雕侠侣》、小龙女
   - 文化特征：叛逆规矩、追求自由、真性情
   - 适用场景：情感纠葛、个性张扬、反叛传统

4. **佛家之侠**：万事皆因果，无人不冤、有情皆孽
   - 代表人物：段誉《天龙八部》、虚竹
   - 文化特征：放下执念、慈悲为怀、因果循环
   - 适用场景：悲剧命运、心灵救赎、人生哲学

5. **国民文化之侠**：民本思想、社会融合、国家安宁
   - 代表人物：令狐冲《笑傲江湖》、韦小宝《鹿鼎记》
   - 文化特征：真诚洒脱、实用主义、反讽传统
   - 适用场景：现实讽刺、反英雄、社会观察

**语言公式**：
`[人物设定] → [文化底色] → [行为准则] → [故事主题]`

**示例**：
"郭靖是墨家之侠。他兼爱天下，非攻不杀。蒙古兵屠城，他挺身而出；百姓受苦，他拼死相救。这不是儒家的修身齐家，也不是道家的顺其自然，而是墨家的脚踏实地。他的武功不是最厉害的，但他的心是最宽的。"

### 进阶技巧：成长模式四段式

将"少年出发—遭遇挑战—成长破难—功成归去"的四段式模板应用到人物塑造中：

**四段式结构**：

1. **少年出发**（起）：少年离家，踏上江湖
   - 关键元素：身世之谜、初入江湖、拜师学艺
   - 写作重点：突出少年的天真、好奇、勇气

2. **遭遇挑战**（承）：危机降临，考验来临
   - 关键元素：强敌出现、阴谋揭露、情感纠葛
   - 写作重点：展现人物的性格缺陷和成长需求

3. **成长破难**（转）：奇遇连连，突破自我
   - 关键元素：奇遇机缘、武功大成、顿悟真谛
   - 写作重点：人物性格的转变、价值观的升华

4. **功成归去**（合）：功成名就，回归初心
   - 关键元素：最终决战、抉择时刻、归宿选择
   - 写作重点：人物完成成长弧光，体现主题

**示例**：
"郭靖少年离家，在大漠草原上成长。他天资愚钝，却勤奋刻苦。江南七怪教导他，洪七公点拨他，黄蓉陪伴他。蒙古铁骑南下，襄阳危在旦夕。他挺身而出，率军死守。这一战，他不再是那个傻小子，而是真正的大侠。襄阳守住了，他也找到了自己的归宿——为国为民，侠之大者。"

### 进阶技巧：奇遇设定的合理性控制

如何设计奇遇，既让角色快速成长，又保持故事的合理性：

**奇遇设计三原则**：

1. **奇遇与性格匹配**
   - 奇遇必须符合人物性格设定
   - 勤奋苦练者得奇遇，投机取巧者得教训
   - 真诚善良者得贵人，虚伪奸诈者得报应

2. **奇遇与历史结合**
   - 奇遇背景要有历史渊源
   - 古迹、秘籍、高人要有来头
   - 虚构元素与真实历史自然融合

3. **奇遇与成长呼应**
   - 奇遇解决成长瓶颈
   - 奇遇推动情节发展
   - 奇遇体现主题思想

**示例**：
"郭靖在山洞里发现了《九阴真经》，这看似偶然，实则必然。他之前勤奋苦练，却找不到突破口；他为人真诚，黄蓉愿意帮助他；他心怀天下，洪七公愿意指点他。这一切，都是他应得的。"

### 进阶技巧：武功描写的虚实结合

如何详写武功招式，同时保持故事的文学性和可读性：

**虚实结合三法**：

1. **招式描写实**：具体描写招式名称、动作要领、传承渊源
   - 示例："降龙十八掌，第一式，亢龙有悔。郭靖双掌推出，掌风呼啸，如龙吟虎啸。这招式源自《易经》，道家心法，至刚至阳。"

2. **意境描写虚**：用比喻和意象营造氛围
   - 示例："掌风如海啸，气势如雷霆。敌人被震退十步，面色惨白。郭靖的掌法，不仅有力，更有意。"

3. **哲学升华虚**：将武功提升到哲学和人生境界
   - 示例："武学之道，不在招式，而在心法。郭靖领悟了这一点，武功才真正大成。"

**示例**：
"郭靖运起降龙十八掌，一掌接一掌，掌掌相连。掌风如龙，呼啸而过。敌人节节败退，面露惊恐。郭靖不仅是在打斗，更是在诠释——侠之大者，为国为民。"

### 进阶技巧：历史真实感的虚与实

如何融入真实历史背景与人物，虚与实完美结合：

**虚实结合三原则**：

1. **大历史实**：朝代、皇帝、重大历史事件真实
   - 示例："南宋理宗年间，蒙古铁骑南下。襄阳城外，硝烟弥漫。"

2. **小故事虚**：人物、情节、武功可以虚构
   - 示例："郭靖站在城头，看着远处的蒙古大军。他握紧了拳头，眼神坚定。"

3. **虚实融合**：虚构人物与真实历史人物互动
   - 示例："成吉思汗看着郭靖，眼神复杂。这个年轻人，是他见过最特别的一个。"

**示例**：
"襄阳城外，蒙古大军压境。郭靖站在城头，看着远处的旗帜。南宋理宗在临安享乐，而他在这里守城。历史是真实的，但郭靖是虚构的。正是这种虚实结合，让故事更有力量。"

### 进阶技巧：群像塑造的差异化

如何塑造性格各异、形象多样的丰富人物群像：

**群像塑造四法**：

1. **性格对立法**：设置性格对立的人物，形成冲突和对比
   - 示例：郭靖（笨拙）vs 杨康（聪明）、郭靖（忠诚）vs 杨康（背叛）

2. **价值冲突法**：设置价值观冲突的人物，推动情节发展
   - 示例：郭靖（为国为民）vs 杨康（为私为利）、令狐冲（自由）vs 岳不群（野心）

3. **命运交织法**：设置命运交织的人物，形成复杂的情感关系
   - 示例：郭靖、黄蓉、华筝的情感纠葛

4. **成长对照法**：设置成长路径对照的人物，突出主题
   - 示例：郭靖（脚踏实地）vs 杨康（投机取巧）

**示例**：

- 咋整（怎么办）

**示例**：

**时代细节清单**：

### 进阶技巧：方言节奏控制

在不同文本部分使用不同比例的方言，避免过度堆砌或完全缺失：

**方言比例控制**：
- 叙述部分：30%方言，保持亲切感但不影响阅读流畅
- 对话部分：60%方言，增强真实感和地域特色
- 心理活动部分：40%方言，体现第一人称的思考方式

**示例**：
"（叙述）二狗看着那群人，心里有点发毛。咋整？（方言）这帮人一看就不善，脸上横肉乱颤，眼神贼溜溜的。（对话）'咋回事？'二狗问。'没啥，就是想和你聊聊。'那人说话带着浓重的东北口音。（心理）二狗心里琢磨，这事儿怕是躲不过去了，只能硬着头皮上了。"

**方言使用禁忌**：
- 重大历史事件/严肃场景中少用方言（如葬礼、判决）
- 情感爆发场景慎用方言（如痛哭、愤怒宣泄）
- 关键情节转折处保持叙述清晰，避免方言干扰理解

### 进阶技巧：时代细节选取原则

哪些细节能增强真实感，哪些是无效冗余：

**选取标准**：
- 与情节推进相关的细节（推动故事发展、揭示人物动机）
- 能体现人物身份/性格的细节（服饰、语言、行为习惯）
- 能唤起时代记忆的细节（特定的文化符号、社会现象）

**有效细节示例**：
- 中山装、的确良、毛料（体现80年代服饰特征）
- 工厂、文化宫、电影院（体现80年代社会空间）
- 瓜子、纸葫芦、圣诞贺卡（体现80年代生活物品）

**无效冗余示例**：
- 过于琐碎的物品罗列（如：桌子上有笔、本子、杯子、钥匙、打火机、烟盒、火柴...）
- 与情节无关的环境描写（如：墙上有三个钉子，钉子上挂着两幅画...）
- 重复出现的相似细节（如：三次描述同一个人的衣服颜色）

### 进阶技巧：第一人称心理距离三层次

根据情节需要，控制第一人称的心理距离，增强叙事层次：

**三个层次**：

1. **旁观层**（冷静叙述，保持客观距离）
   - 使用场景：介绍背景、描述事件、展现冲突
   - 特点：情感克制，客观叙述，像在讲述别人的故事

   **示例**：
   "那天下午，韩炳带着人来了。他们一共五个人，手里拿着铁棍和砍刀。二狗站在门口，看着他们，没有说话。"

2. **介入层**（情感表态，适度介入）
   - 使用场景：评价人物、表达态度、抒发感慨
   - 特点：情感流露，主观评价，展现"二狗"的立场

   **示例**：
   "二狗看着韩炳，心里五味杂陈。他们曾经是兄弟，一起上学，一起打架，一起分享秘密。但现在，他们成了敌人。二狗不知道该说什么，也不知道该做什么。"

3. **爆发层**（情绪宣泄，完全沉浸）
   - 使用场景：情感高潮、重大决策、悲剧发生
   - 特点：情绪强烈，第一人称完全主导，读者深度代入

   **示例**：
   "二狗握紧了拳头，指甲深深陷入肉里。疼。但他不在乎。那一刻，他只有一个念头：杀了他。杀了他，为兄弟报仇，为死去的韩炳报仇。他冲了出去，像一头疯狗，不顾一切，不计后果。"

### 进阶技巧：悲剧感四层铺垫

如何通过细节、对话、场景逐步铺垫悲剧，而非直接煽情：

**四层铺垫**：

1. **细节暗示**（早期埋下伏笔）
   - 用看似无关的细节暗示人物命运
   - 通过环境、物品、语言中的异常暗示悲剧

   **示例**：
   "韩炳的妈妈卖瓜子时，总爱说一句话：'这瓜子仁真香，就像这日子一样。'但她的眼神里，总有一丝说不出的哀愁。"

2. **对话预警**（人物对话中的不祥预兆）
   - 通过人物对话直接或间接预示悲剧
   - 用玩笑、自嘲、反讽等方式预警

   **示例**：
   "二狗，你说咱俩能一直这么混下去吗？"
   "能啊，咱兄弟俩，谁也分不开。"
   "要是分开了呢？"
   "那就再聚在一起呗。"
   "要是...聚不在一起了呢？"
   韩炳没说话，只是笑了笑。那笑容，有点苦。

3. **场景反差**（美好与残酷的强烈对比）
   - 用温馨场景反衬悲剧发生
   - 用美好回忆对比残酷现实

   **示例**：
   "三年前的端午节，二狗和韩炳一起过。他们买了粽子，喝了啤酒，聊着未来。韩炳说，等赚了钱，就带二狗去南方，看看大海。三年后的端午节，二狗独自一人喝着啤酒，看着大海。韩炳躺在海里，再也回不来了。"

4. **结局必然**（悲剧发生的不可逆转）
   - 强调悲剧的必然性，避免煽情
   - 用冷静叙述展现悲剧的残酷

   **示例**：
   "韩炳死了。二狗知道这一天会来，但他没想到会这么快。他站在韩炳的墓前，没有哭。眼泪早就流干了。他只是看着墓碑，看着那三个字：韩炳之墓。就这样。"

### 蒸馏增强：孔二狗社会叙事系统

> 完整蒸馏方法论见 [craft/style-dna/style-kongergou-distill.md](craft/style-dna/style-kongergou-distill.md)，以下为核心要点速查。

**题材承诺（三层同时存在）**：
- 表面层：东北黑道二十年恩怨（拉人入场）
- 中层：一个社会的真实肌理如何被暴力、关系、利益重新编织（让人留下）
- 深层：在制度真空与权力交替的时代，人性和"规矩"如何互相塑造、最终如何一起崩坏（让人记住）

**推进引擎（四引擎并跑）**：
- 暴力升级引擎：个人摩擦 -> 群殴 -> 持械 -> 枪 -> 体制介入
- 时代推进引擎：80年代野蛮生长 -> 90年代资本入场 -> 00年代体制收编
- 关系裂变引擎：兄弟 -> 利益分歧 -> 翻脸 -> 复仇或和解
- 规则演变引擎：江湖规矩 -> 金钱规则 -> 体制规则 -> 规则真空

**读者债设计（长篇复利挂债）**：

| 债务层级 | 内容 | 偿还方式 |
|----------|------|----------|
| 近债 | 这次冲突谁赢谁输 | 当场或下一章见分晓 |
| 中债 | 某个人物会走到哪一步 | 几十章内完成命运弧线 |
| 大债 | 这个江湖最终会变成什么样 | 全书终局才偿还 |
| 情感债 | 某段兄弟情义会如何收场 | 情感线的持续拉扯与爆发 |

**暴力场景写法公式**：起因(一句话) -> 对峙(气氛) -> 爆发(短句连击) -> 结果(冷静叙述) -> 余波(人物反应)。爆发过程不超过全章15%，余波至少占30%。

**语言表层四特征**：
1. 东北方言密度控制：对白60-80%/叙述20-30%/金句80-100%
2. 短句爆发式叙述：暴力场景3-8字短句连击/日常正常句长/情感长短交替
3. 第一人称亲历感："我"是见证者而非主角，距离感让暴力更真、情感更痛
4. 方言与书面语的双层叙事：对白层方言+口语+黑话 / 叙述层克制+简练+偶有诗意，落差制造"日常中的文学性"

**节奏配比（按阶段）**：

| 阶段 | 日常铺垫 | 冲突升级 | 暴力爆发 | 余波沉淀 |
|------|---------|---------|---------|---------|
| 前期 | 30% | 30% | 25% | 15% |
| 中期 | 20% | 25% | 30% | 25% |
| 后期 | 15% | 20% | 20% | 45% |

规律：越到后期，暴力比例下降，余波沉淀比例上升——时代开始清算。

**写法蓝图核心**：
- 主角类型："被迫入局型"——不是主动追求江湖，而是被环境和时代推入
- 结构节奏：立人(1-20%) -> 立恩怨(20-40%) -> 立格局(40-60%) -> 立时代(60-80%) -> 立命运(80-100%)
- 章节写法：开头场景切入(直接扔进场景) -> 中段双线推进(暴力线+情感线) -> 结尾余波悬挂(留"人变了"或"时代变了"的暗示)

**一句话蒸馏**：`用一群人的二十年，写出一个时代的暴力与人性、规矩与崩坏、烟火与苍凉。`

### 进阶技巧：意象系统的象征编码

构建气象意象和器物意象，形成象征符号系统，指引读者深入角色灵魂的暗道：

**意象系统构建三原则**：

1. **气象意象编码**：风、雪、雨、沙成为人物命运的投射
   - 风雪：孤独、寒冷、宿命（《风云第一刀》）
   - 狂沙：荒凉、绝望、迷失（《楚留香·大沙漠》）
   - 雨：悲伤、悔恨、净化（《边城浪子》）

2. **器物意象编码**：兵器、酒杯、刀剑成为人物精神的象征
   - 飞刀（李寻欢）：执念、牺牲、不朽的精神图腾
   - 黑刀（傅红雪）：宿命、复仇、无法摆脱的诅咒
   - 酒杯（楚留香）：孤独、自由、江湖浪子的洒脱

3. **意象呼应编码**：同一意象在不同场景反复出现，形成宿命循环
   - 示例：傅红雪的黑刀，每次出现都伴随血腥和死亡
   - 示例：李寻欢的飞刀，每次出现都代表一次救赎

**示例**：
"风雪。漫天风雪。傅红雪拖着残腿，一步一步向前走。黑刀在腰间，冰冷如铁。风雪掩盖了他的脚印，掩盖了他的过往，却掩盖不了他的宿命。他注定要复仇，注定要死。这就是傅红雪的命运，就像这漫天风雪，永无止境。"

### 进阶技巧：悖论修辞的颠覆力

用"正言若反"的悖论修辞颠覆江湖伦理，成为揭示真相的利器：

**悖论修辞三法**：

1. **对立统一悖论**：将矛盾的概念统一，揭示人性的复杂
   - 示例："一个最可靠的朋友，固然往往会是你最可怕的仇敌，但一个可怕的对手，往往也会是你最知心的朋友。"

2. **价值倒置悖论**：颠覆传统价值观念，揭示江湖的真相
   - 示例："在这个江湖里，好人往往活不长，坏人却能活得逍遥自在。这不是道德的沦丧，而是现实的残酷。"

3. **存在悖论**：揭示存在的荒诞和虚无
   - 示例："人在江湖，身不由己。你以为你在选择，其实你已经被选择。你以为你在掌控，其实你已经被掌控。"

**示例**：
"傅红雪知道，复仇之后，他会失去一切。但没有复仇，他早已失去了一切。这就是悖论：复仇是他活着的意义，复仇之后，他就没有意义了。他依然要复仇，因为这是他的宿命，是他的诅咒。"

### 进阶技巧：禅宗机锋的武道哲学

将西部片的枪手对决转化为禅意化的武道哲学，"后发先至，一击必杀"：

**禅宗机锋三层面**：

1. **语言机锋**：高手过招前的无厘头问答，实为心性交锋
   - 示例："你读李白？""仙人抚我顶。"看似无关，实则是在试探对方的境界

2. **动作机锋**：武道至理在于"不可言说"的境界
   - 示例："天上地下，从来也没有人知道他的飞刀在哪里，也没有人知道是怎么发出来的。"这就是禅意——言语道断，心行处灭

3. **存在机锋**：武道的终极意义在于存在的自我确证
   - 示例："你慢了！"这句话不是在说速度，而是在说境界——你的境界，已经慢了

**示例**：
"师父作挽弓势，是语如机锋，破空而至。徒弟良久拔不出剑……师父说，你慢了！徒弟不解，明明他的手很快，怎么会慢？师父说，不是你的手慢，是你的心慢。你的心慢了，你的手就慢了。这就是禅，这就是武道。"

### 进阶技巧：蒙太奇叙事的镜头切换

借鉴好莱坞电影分镜，用空行分隔场景切换，赋予叙事强烈的视觉节奏：

**蒙太奇叙事三法**：

1. **空行切换**：用空行分隔不同场景，形成强烈的视觉节奏
   - 示例：
     "风雪。
     漫天风雪。
     傅红雪拖着残腿，一步一步向前走。
     黑刀在腰间，冰冷如铁。
     
     镜头一转。
     酒馆。
     炉火熊熊。
     一个男人独自饮酒。"

2. **时间跳跃**：省略中间过程，直接呈现关键场景
   - 示例："三天后。傅红雪站在敌人的门前。门开了。他走了进去。"

3. **空间切换**：不同场景快速切换，营造紧张感
   - 示例："城门外，傅红雪拖着残腿向前走。城门内，敌人正在等待。风吹过，雪落下。两个人，一场决斗。"

**示例**：
"风雪。
漫天风雪。
傅红雪拖着残腿，一步一步向前走。
黑刀在腰间，冰冷如铁。

镜头一转。
酒馆。
炉火熊熊。
一个男人独自饮酒。
他就是傅红雪要杀的人。
傅红雪推开了门。
风雪灌入。
酒杯晃动。
男人抬头，看到傅红雪，笑了。
'你来了。'
'我来了。'
'要喝酒吗？'
'不，要杀人。'

刀光一闪。
酒杯碎裂。
男人倒下。
傅红雪转身，离去。
风雪依旧。"

### 进阶技巧：留白技法的"不写之写"

摒弃招式描写，将打斗转化为心理与环境的气氛渲染，以虚无激活万象：

**留白技法三法**：

1. **动作留白**：不写具体招式，只写结果
   - 示例："只见剑光一闪，胜负已分。"

2. **心理留白**：不写人物内心，只写外在表现
   - 示例："傅红雪握紧了刀柄。刀柄上，有血迹。是谁的血？他的？还是敌人的？他不知道。"

3. **意境留白**：不写打斗过程，只写氛围营造
   - 示例："风停了。雪停了。天地间一片寂静。傅红雪站在那里，像一尊雕塑。"

**示例**：
"傅红雪拔刀。
黑刀出鞘，寒光凛凛。
敌人笑了，轻蔑地笑了。
他以为傅红雪是个残废，是个废物。
他错了。
刀光一闪。
笑声戛然而止。
敌人倒下，鲜血喷涌。
傅红雪收刀，转身，离去。
没有人看清他是怎么出刀的，也没有人看清敌人的脖子是怎么断的。
只见剑光一闪，胜负已分。
这就是傅红雪的刀，这就是傅红雪的宿命。"

### 进阶技巧：存在主义的孤独命题

以孤独、寂寞、黑暗为核心命题，揭示个体在虚无中的自我确证：

**存在主义三层面**：

1. **个体的孤独**：人物在江湖中始终处于孤独状态
   - 示例："傅红雪没有朋友，没有亲人，只有一把黑刀。他拖着残腿，一步步向前走。没有人知道他要到哪里去，也没有人知道他要干什么。"

2. **存在的荒诞**：人物的行为看似有意义，实则荒诞
   - 示例："傅红雪要复仇。为什么复仇？因为有人杀了他父亲。杀了父亲的人已经死了，但他还是要复仇。复仇之后呢？他没有想过。这就是荒诞——为了复仇而活着，复仇之后却不知道为什么活着。"

3. **自我的确证**：人物通过极端行为确证自己的存在
   - 示例："傅红雪拔刀，不是为了杀人，而是为了证明自己还活着。只有刀光闪过的那一瞬间，他才能感觉到自己的存在。刀光消失，他又回到了虚无。"

**示例**：
"傅红雪拖着残腿，一步一步向前走。
没有人知道他要到哪里去。
没有人知道他要干什么。
他自己也不知道。
他只是走。
因为停下来，就意味着思考。
思考，就意味着面对孤独。
面对孤独，就意味着面对虚无。
他不愿意面对。
所以他走。
一直走。
走到死。
这就是傅红雪的宿命，也是傅红雪的选择。"

## 风格混合运用

### 选择原则
- 根据题材选择主风格
- 可适当融入其他风格元素
- 保持整体一致性

### 题材与风格对应
- 历史/传记：当年明月风格
- 武侠/玄幻：金庸/古龙风格
- 都市/言情：猫腻风格
- 现代/悬疑：简洁有力风格
- 都市底层/江湖/黑帮：孔二狗风格

### 风格禁忌（禁止混用）
**重要**：以下风格组合会产生严重冲突，严禁混用：
- **孔二狗风格 × 古龙风格**：绝对禁止
  - 原因：孔二狗强调"粗犷直白、市井烟火、方言土语"，古龙追求"极简诗意、浪漫抽象、意境深远"
  - 冲突点：市井口语 vs 诗意语言、写实暴力 vs 浪漫美学、粗粝江湖 vs 孤独剑客
  - 后果：风格割裂、人物崩坏、叙事混乱
- **当年明月风格 × 古龙风格**：不建议混用
  - 原因：说书人式的唠叨 vs 极简主义的留白
- **猫腻风格 × 孔二狗风格**：不建议混用
  - 原因：精致细腻 vs 粗犷直白

### 实战建议
1. 确定主风格
2. 提取关键技巧
3. 在创作中运用
4. 严格遵守风格禁忌
5. 保持风格一致

## DNA写作 + 去AI 联合使用指引

> 本章节指导如何将"大神风格DNA蒸馏"与"去AI检测器"联合使用，确保写作既有大神的辨识度，又没有AI的机器味。两者配合的核心逻辑是：**用大神的语言习惯替换AI的默认表达**。

### 一、联合使用的工作流

```
选择大神风格DNA → 提取该大神的句式/用词/节奏特征
        ↓
写作时：加载风格DNA作为"替代语言库"
        ↓
交付前：用 deai-fiction-detector.md 执行12模式检测
        ↓
命中AI句时：不替换成"通用好句子"，而是替换成"该大神的典型句式"
        ↓
打分 ≥8分 → 通过
```

### 二、按风格DNA定制的去AI策略

不同大神的风格天然克制不同类型的AI腔，以下是各风格对应的去AI重点：

| 大神风格 | 天然克制 | 需额外注意 |
|---------|---------|-----------|
| **当年明月（说书人）** | 克制"宣传腔""通稿腔"——口语化叙事本身就是AI的反面 | 注意不要过度使用"然而他并不知道"等套路预告，以及括号吐槽频率过高本身也会变成AI式均匀 |
| **猫腻（文雅细腻）** | 克制"意义拔高""情绪直给"——猫腻式含蓄天然避免直白心理描写 | 注意精致文笔容易滑向"修辞堆砌"，每段最多一个比喻 |
| **孔二狗（市井烟火）** | 克制"对话千人一面""节奏均匀"——方言和碎片化对话天然有高区分度 | 注意方言比例控制（对白60%/叙述30%），避免叙述层也方言化导致可读性下降 |
| **古龙（极简意境）** | 克制"修辞堆砌""段落均匀"——极简短句天然有高突发性 | 注意短句不等于碎句，每句话必须有信息量，不能用短句凑字数 |
| **金庸（古典侠义）** | 克制"对话千人一面"——金庸角色的语言层级区分极其鲜明 | 注意半文半白的度，不要滑向纯文言导致现代读者阅读困难 |
| **烽火戏诸侯（诗意江湖）** | 克制"情绪直给"——意境化表达天然有留白 | 注意诗意不等于空泛，每个意境要有具体画面支撑 |
| **priest（格局+深情）** | 克制"叙述者尾巴句"——priest从不替读者总结感受 | 注意格局描写不能变成空洞的宏大叙事 |
| **巫哲（日常治愈）** | 克制"节奏均匀"——碎片化的日常节奏天然有高波动 | 注意日常≠流水账，每个场景仍需有冲突或情绪变化 |
| **耳根（仙侠意境）** | 克制"感官泛化"——耳根的感官描写极其精准 | 注意修行体系描写不要变成数值说明 |
| **爱潜水的乌贼（规则怪谈）** | 克制"意义拔高"——冷静克制的叙事天然避免煽情 | 注意逻辑推演不能变成说明文，保持场景化 |

### 三、风格指纹驱动的替换原则

当 deai-fiction-detector.md 检测到AI句需要替换时，按以下优先级选择替换方式：

**优先级1：用已选大神的标志性句式替换**
- 例：当年明月风格 → 把"她不禁后退了一步"替换成"她往后退了一步。这一步退得很有讲究——刚好退到安全距离，又不至于让人觉得她怕了"（说书人点评式）
- 例：古龙风格 → 把"他缓缓伸出了手"替换成"手。伸出去了。"（极简断句）
- 例：孔二狗风格 → 把"她说得很有道理"替换成"她说得挺对。但老张那种人，你说得再对他也不听"（市井口语+人物点评）

**优先级2：用该大神的用词偏好替换AI高频词**
- 例：猫腻风格 → 把"仿佛"替换成具体画面（猫腻很少用"仿佛"，他直接把画面写出来）
- 例：当年明月风格 → 把"顿时"替换成"就这么着"（口语化时间标记）
- 例：巫哲风格 → 把"不禁"直接删掉（巫哲的角色不做条件反射式的反应）

**优先级3：用该大神的节奏模式替换AI的均匀节奏**
- 例：古龙风格 → 把均匀的中等长度段落拆成极短段落
- 例：烽火风格 → 在均匀的叙述中突然插入一句意境化的长句
- 例：孔二狗风格 → 把规整的对话打碎成方言碎句

**优先级4：如果以上都不适用，用 deai-fiction-detector.md 第四部分的"AI句→真人句替换词库表"替换**

### 四、联合检测清单（风格+去AI）

每章交付前，在 deai-fiction-detector.md 的打分基础上，额外检查以下项目：

- [ ] **风格一致性**：替换AI句后，是否还保持该大神的语言质感？（替换后不能变成"通用好句子"，必须有风格辨识度）
- [ ] **节奏指纹**：段落长度分布是否符合该大神的节奏特征？（古龙→极短；猫腻→长短交替但偏长；孔二狗→碎句多；当年明月→中等段落+偶尔极短感叹）
- [ ] **对话DNA**：替换AI对话后，角色的说话方式是否还符合该风格下的人物塑造习惯？（猫腻角色→含蓄+机锋；孔二狗角色→方言+碎句；巫哲角色→日常+温暖）
- [ ] **禁区检查**：是否违反了风格禁忌中的混用规则？（如孔二狗×古龙绝对禁止）
