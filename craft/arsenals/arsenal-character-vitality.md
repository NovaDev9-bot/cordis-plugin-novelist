## 核心六维度（每个活人角色必备）

1. **语癖系统**：句式偏好 + 信息密度 + 特殊语言标记（口头禅/黑话）。蒙名测试：遮住名字能分出谁是谁。
2. **行为锚点**：2–3 个标志性小动作（紧张/思考/撒谎各不同）。如：撒谎时摸耳垂、思考时转笔。
3. **随身物件**：绑定一个有记忆点的随身物品（可不解释，后续揭晓）。如：总揣着半块玉佩。
4. **矛盾面**：至少一个与表面性格矛盾的内里特质（拒绝纸片人）。如：杀手怕猫、毒舌其实心软。
5. **处事风格**：遇事第一反应 + 决策方式（冲动/分析/赌徒/拖延）。
6. **出场设计**：第一次出场的画面 + 标志台词 + 反差细节。

## 层级鲜活度要求

| 层级 | 鲜活度 | 卡片详度 |
|---|---|---|
| 主角 | 六维全满 | 完整角色卡 |
| 对手/反派 | 六维全满 + 灵魂档案 | 完整卡 + 反派灵魂档案 |
| 核心配角 | ≥5 维 + 独立处事风格 | 完整卡 |
| 次要配角（3–5 次） | ≥3 维（语癖+行为锚点+矛盾面） | 简版卡 |
| 龙套（1–2 次） | ≥1 记忆点 | 一句话人设 |

## 角色区分自检表（每章写后过）

- [ ] 遮住角色名，本章对话能否分辨谁在说？（声线 ≥4 维不同）
- [ ] 每个出场角色的行为是否符合其六维设定？
- [ ] 有无两个角色"撞声音"（语癖/节奏雷同）？
- [ ] 新出场角色是否给了 ≥1 记忆点？

## AI 腔雷区

- 全员一个声线（都像作者说话）
- 角色靠"标签"活（只喊口号不行动）
- 配角是工具人（只在需要时出场推进剧情）

## 禁忌

- 不让反派缺"可恨/可笑/可悲"三维记忆点之一（见 villain-engine.md）
- 不写 OOC（无铺垫的性格突变，见 8.6 OOC 检测）
