## 产出物：章级执行方案模板

```
## 第 X 章 · 编剧执行方案
### 章节类型判定：战斗/对话/日常/悬疑/情感/转折/过渡
### 场景规划：地点/时间/在场人物/核心冲突（2–4 个）
### 节奏曲线：开头(承钩+定调) → 铺垫 → 推进 → 高潮 → 收尾+钩子
### 信息投喂计划：读者新知/主角新知/读者知主角不知/主角知读者不知
### 对话规划：占比目标 + 双功能场景 + 声线提醒
### 名场面设计：≥1 个截图瞬间 + 金句锚点(有/无)
### 弹药库调用清单：本章需加载的 2–3 个 arsenal
```

## 核心技法

1. **锚点锁死**：章纲拆为剧情锚点（A→B→C），锚点是铁轨不可跳过/改序；锚点间"路上"用流派 DNA 即兴（见 improvisation-writing.md）。
2. **信息投喂节奏**：控制"读者知/主角知"的差，制造紧张与好奇。
3. **名场面预埋**：每章至少 1 个让读者想截图的瞬间。
4. **弹药库懒加载**：只列本章需要的 2–3 个 arsenal，不全开（见 7.1 Step 2）。

## AI 腔雷区

- 章纲太空（无 500 字铁律，见 scene-goal-structure.md）
- 锚点间无即兴空间（写成死脚本）
- 信息投喂一次性倒完（无悬念）

## 禁忌

- 不写无剧情目标的场景
- 不让执行方案脱离章节拆解表（见 chapter-breakdown-table.md）
