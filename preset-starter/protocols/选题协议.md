# 选题协议（v1.1 · 2026-09-16 修订）

> 武行理念：**选题依旧是最重要的**——文风提示词都靠后。开书前必走本协议；
> 选题=权责级，呈 Owner 拍板（编辑部只呈报不定案）。
> **〔v1.1 · Owner 2026-09-16 裁定〕扫榜升级为可持续选题数据账本**（vault/market/选题数据/）：每期扫榜快照+结论存档、跨书积累趋势；**用户不需要知道本流程——开书轮由主编主动提议并带队走完本协议**（两座位制：策划职能已并入主笔/主编）。

## 一、输入四件

1. **扫榜数据（可持续账本）**：主笔（开书轮）经 web 读番茄/起点榜单页，快照+结论落 `vault/market/选题数据/扫榜-YYYY-MM-DD.md`（目录=跨书趋势积累：题材涨落/断层/新贵，每期对比上期）；JS 重页面读不全→挂事项板评估浏览器工具插件。
2. **题材边界**：该赛道什么能写/什么不能写（平台红线+读者预期，出处=你自己的题材档案库）。
3. **竞争密度**：榜单前 50 里同题材占位、头部断层情况。
4. **自身差异化**：拆书资产卡支撑的差异化主张（对锚书"学什么/不学什么"）。

## 二、选题报告格式（editorial/reports/选题-日期.md）

| 项 | 内容 |
|---|---|
| 候选方向 ×2-3 | 各带：赛道热度证据 / 竞争密度 / 差异化主张 / 锚书资产支撑（卡名） |
| 推荐方向 | 一句话理由 + 风险两问（最可能扑的点 / 番茄审查敏感点） |
| 首卷假想 | 主角+金手指+第一卷承诺（不展开，一段话） |

## 三、流程

开书轮：主编主动提议走本协议 → 主笔产报告 → 主编汇总取舍 → **Owner 拍板**（ask 或对话呈报）→ 拍板结果回写
board/issue-NNN + 拆书方向锁定 → 走开书流程（novel_init ask 门）。

## 四、纪律

- 扫榜结论必须带榜单快照坐标（日期+页面），榜单类信息自带时效（规则会变）。
- 不做"我觉得会火"裸结论；每个候选至少 1 本锚书资产卡背书。
